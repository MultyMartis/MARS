# Наблюдение

Когда один и тот же проход генерации **одновременно** пытается:

- улучшать **SEO**;
- усиливать **UX**;
- повышать **conversion density** (насыщенность офферами, доказательствами, CTA);
- добавлять **visual effects**,

то **вёрстка и композиция секций начинают «разваливаться»**, с особой заметностью на **mobile**: конфликтующие цели тянут блок в разные стороны без явного приоритета.

# Вывод (рабочая формулировка)

Имеет смысл принцип уровня секции: **«one dominant optimization target per section»** — на одну секцию один доминирующий таргет оптимизации (или явная иерархия таргетов в blueprint), чтобы остальные цели не конкурировали в одном экране без человеческого arbitration.

# Ограничения записи

Это **наблюдение из практики**, не утверждённое правило governance и не изменение контрактов Website Factory. Перевод в норму — только по отдельному решению оператора (в т.ч. через `/decision` или правки фабрики).
