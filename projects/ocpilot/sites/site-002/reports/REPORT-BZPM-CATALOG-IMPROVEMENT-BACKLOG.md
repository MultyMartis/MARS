## Executive summary

Каталог после M9.7E **коммерчески жизнеспособен** как B2B-витрина производителя: навигация по 5 веткам согласована (главная / hub / megamenu), фильтры по профилям работают, PDP содержит цену, корзину, документы, доставку и гарантию.

Главные пробелы — **не архитектура**, а **коммерческие и SEO-слои**: слабые meta на ветках, отсутствие B2B-CTA «Получить КП», PLP-карточки без ключевых габаритов, «мёртвые» подкатегории в фильтре ванн, placeholder-текст и нерелевантные «Похожие товары» на PDP.

Ниже — только **HIGH IMPACT / LOW RISK** улучшения, без M10/M11 и без рефакторинга ради рефакторинга.

## TOP-10 — максимальная польза для бизнеса

| # | Изменение | Зона | Почему в TOP-10 |
|---|-----------|------|-----------------|
| 1 | **CTA «Получить коммерческое предложение»** на PDP и в sticky/mobile header | Лидогенерация | B2B-покупатель редко покупает «в корзину»; КП — основной канал сделки для HoReCa/производств |
| 2 | **2–3 ключевых атрибута на PLP-карточке** (Д×Ш×В, материал столешницы / число секций ванны) | CRO / UX | Сокращает клики до PDP; соответствует паттерну плотности Trapeza/Юниторг (operator MI) |
| 3 | **Скрыть пустые подкатегории в фильтре «Моечные ванны»** (13 шт., EC-01) | UX / доверие | Пользователь выбирает фильтр → 0 товаров → потеря доверия; fix уже аудирован, точечный |
| 4 | **Meta description + title с брендом на ветках** (Столы, Подтоварники, Тележки — сейчас пусто или только H1) | SEO | Быстрый контентный win; улучшает CTR из поиска без изменения вёрстки |
| 5 | **Исправить релевантность «Похожие товары»** (ванна ПРЕМИУМ-3 → сейчас котломойки ВКС) | CRO | Вводит в заблуждение; теряется cross-sell внутри серии |
| 6 | **Убрать placeholder mini-description на PDP** («…надо сделать дополнительным мини-описанием…») | Доверие / CRO | Видимый черновик на reference SKU снижает профессиональное восприятие |
| 7 | **Обновить SEO-текст hub «Нейтральное оборудование»** — убрать стеллажи/полки/шкафы из description | SEO / навигация | Meta описывает категории, которых нет в Launch Mode → расхождение с UX |
| 8 | **Короткий intro-блок на branch PLP** (1–2 абзаца: для кого, типовые задачи) | SEO + доверие | Ветки без category description; упущенный long-tail и контекст для закупщика |
| 9 | **og:description + canonical** на каталоговых страницах | SEO / шеринг | Сейчас og:description отсутствует везде; canonical не обнаружен — риск дублей при UTM/параметрах |
| 10 | **Счётчик SKU на hub/home карточках** (как в megamenu «419 шт.») | UX / коммерция | Покупатель видит глубину ассортимента до клика; megamenu уже показывает — hub/home нет |
