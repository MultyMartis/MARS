## System name

**NOVA**

## Full name

**Mobile Application Factory**

## Mission

NOVA is a documentation-first production methodology system for mobile, PWA, AI-powered, and business applications. It defines shared reality vocabulary (product classification, lifecycle, decisions, contracts, workflow, roles, tools, agents, and automation compression) so that human-operated production can proceed with consistent language and boundaries — without claiming runtime, orchestration, or autonomous agents until explicitly chartered in later phases.
