# NOVA — Mobile Application Factory

**Lane:** B · External Systems  
**Foundation status:** Complete (v1) · **Implementation:** Not started

---

## What NOVA is

NOVA is a **documentation-first production methodology** for mobile, PWA, AI-powered, and business applications within the MARS ecosystem. It provides a complete RBM vocabulary chain — from product reality through automation compression — so that future human-operated production can share consistent language, boundaries, and descent order.

NOVA is the **mobile counterpart** to Website Factory: same philosophy (design before runtime, human authority preserved), different product domain.

---

## What NOVA is not

- **Not a runtime** — no orchestration, no agent engine, no workflow automation product
- **Not implemented** — foundation artifacts are design-only; no agent cards, no pilot, no production path yet
- **Not a governance system** — vocabulary and methodology documentation, not policy enforcement
- **Not expanded beyond RBM v1** — no new ontology work authorized without explicit charter
