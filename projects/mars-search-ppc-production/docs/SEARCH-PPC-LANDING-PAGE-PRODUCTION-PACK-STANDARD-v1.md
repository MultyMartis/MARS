# Search PPC landing page production pack standard v1

## Two deliverable families (never collapse)

| Family | Role | Audience |
|--------|------|----------|
| `FINAL_PAGE_COPY` | Publication-ready text | Client / site |
| `IMPLEMENTATION_PRODUCTION_BRIEF` | Structure, forms, analytics, SEO, restrictions | Developer (Roman) |

## Rule: ONE LANDING PAGE = ONE FILE

Each LP has its own DOCX in each family.

## Content model (production brief)

- Page passport
- Target audience
- Search intents
- Campaign/group mapping
- Actual page copy reference
- Structure / sections
- CTA
- Forms
- Analytics
- SEO
- Commercial claims
- Prohibited claims
- Open confirmations
- Client status
- Developer notes

## Corvonero packs

| Family | Storage pack |
|--------|--------------|
| FINAL_PAGE_COPY | `CORVONERO-FINAL-LANDING-PAGES-TEXT-DOCX-PACK-2026-07-01` (5/5) |
| IMPLEMENTATION_PRODUCTION_BRIEF | `CORVONERO-ROMAN-LANDING-PAGES-DOCX-PACK-2026-07-01` (5/5) |

## Mapping

`CORVONERO-CAMPAIGN-GROUP-TO-LANDING-MAP-v1.json` — every group exactly once across 5 LPs.

Do not auto-create one landing page per campaign group.
