## Shared rules for all directions

**CTA direction (conceptual):** describe the task / leave a request / discuss the scope. Not “buy now”, not “гарантируем срок”.

**Proof/credibility angle (safe):** work as a 1C specialist service for business; existing site pages; contract-based work **only if** the operator later reconfirms the claim. Do not invent client logos, case metrics, or partner badges.

**What not to promise (all directions):** партнёр 1С; сертификация; 100% результат; круглосуточная поддержка; фиксированный срок; фиксированная цена без осмотра задачи; бесплатный аудит; обучение; продажа лицензий; чужая техподдержка вендора.

**LOCAL variant notes:** Новосибирск / местный сценарий / возможный выезд — only as a planning note; live geo and visit claim remain TO_CONFIRM.

**REMOTE variant notes:** удалённый сценарий / работа по России / без привязки к Новосибирску и без обещания выезда.
