# CORVONERO — RSY manual image upload checklist v0.3

This checklist is for later operator work. It does not create upload-ready artefacts in this task.

1. Generate images from operator-approved prompts only.
2. Review each generated image for false claims or unsupported promises.
3. Confirm no protected logos are visible.
4. Confirm no fake UI, certificates, seals, or official badges are visible.
5. Check text readability if a text-on-image variant is used.
6. Check image ratio and format against current Direct requirements before upload.
7. Rename files by group code using a proposed naming convention only.
8. Upload images manually to Direct later.
9. Map each uploaded image to the correct RSY group.
10. Save evidence screenshots if needed.
11. Do not launch without final approval.
12. For Roman-photo variants, generate only after a real photo arrives and likeness use is approved.

Proposed naming convention only:
- `corvonero-rsy-<group-code>-img-01.png`
- `corvonero-rsy-<group-code>-roman-img-01.png`
