## Visual build guidelines (all blocks)

| Guideline | Recommendation |
|-----------|----------------|
| Desktop hierarchy | Clear H1 → H2 progression; CTA visible without excessive scroll on first screen |
| Mobile ≤1024px | Stack columns; phone click-to-call in header or hero |
| Min viewport | 320px — form and buttons usable |
| Max text width | ~60–75 characters per line on desktop body copy |
| Visual density | Restrained business style; clarity over decoration |
| Card rows | 2–3 cards per row desktop; 1 column mobile for service/config blocks |
| FAQ | Accordion; one panel open at a time; H2 «Частые вопросы» |
| Sticky mobile CTA | Optional — phone or primary CTA only if non-intrusive |
| Price emphasis | Bold «от 3 000 ₽ в час» and «Минимальный заказ — 2 часа» |
| Remote vs on-site | Clear visual separation (two columns or two cards) |
| Buttons | Accessible contrast; min ~44px tap target on mobile |
| Brand | Reuse existing Corvonero Tilda identity where available; prioritize readability over decorative match |
