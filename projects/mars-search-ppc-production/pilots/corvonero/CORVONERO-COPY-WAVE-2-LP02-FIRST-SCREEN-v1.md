## Variant A — service-literal

**H1:** Сопровождение и обслуживание 1С для компаний и ИП

**Lead:** Поддерживаем рабочую базу 1С: помогаем пользователям, обновляем конфигурацию, устраняем ошибки и сопровождаем учёт. Удалённо по России, с выездом в Новосибирске.

**Primary CTA:** Обсудить задачу  
**Secondary CTA:** Получить оценку

**Intended intent:** сопровождение 1с, обслуживание 1с, абонентское сопровождение, поддержка пользователей (ca-02-support-and-maintenance)

**Mismatch risk:** низкий — прямое соответствие основной группе (137 фраз)

---

## Variant B — problem/result

**H1:** 1С перестала работать или требует постоянной поддержки?

**Lead:** Восстановим работу базы, устраним ошибки и настроим регулярное сопровождение 1С — разово или на постоянной основе. Удалённо по России, выезд в Новосибирске.

**Primary CTA:** Обсудить задачу  
**Secondary CTA:** Заказать звонок

**Intended intent:** программа 1с не работает, ошибки, troubleshooting (ca-02-troubleshooting-not-working)

**Mismatch risk:** средний — сильнее для проблемных запросов; для чистого «абонентского сопровождения» может звучать слишком реактивно

---

## Variant C — commercial/order

**H1:** Заказать сопровождение и обслуживание 1С

**Lead:** Подключим поддержку вашей базы 1С: разовые обращения или абонентский формат. Согласуем объём работ и стоимость после уточнения задачи.

**Primary CTA:** Получить оценку  
**Secondary CTA:** Заказать звонок

**Intended intent:** услуги по сопровождению 1с, стоимость часа сопровождения (ca-02-direct-service-order, ca-02-price-intent)

**Mismatch risk:** низкий для заказных запросов; может быть суховато для информационного трафика

---

## Draft recommendation

**Recommended default:** Variant A — наилучшее message match для 137 фраз группы ca-02-support-and-maintenance и H1-direction из Phase 6.2 requirements.

**Not operator-approved** — требует подтверждения оператором перед экспортом.
