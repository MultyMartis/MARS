## 2. Подготовка

1. Открыть Яндекс Директ Коммандер (актуальная установленная версия).
2. Убедиться, что выбран **тестовый или рабочий аккаунт Corvonero** по внутренней политике (без публикации).
3. **Не** импортировать остальные четыре XLSX в этом же тесте — только CA-01.
4. При наличии предыдущего локального черновика с тем же содержимым — удалить или переименовать, чтобы не смешивать результаты.
5. Заполнить форму результата: `CORVONERO-COMMANDER-CA01-MANUAL-IMPORT-TEST-RESULT-FORM-v1.md`.

## 3. Имя кампании в интерфейсе Коммандера

Транспортный XLSX **не содержит поддерживаемого поля имени кампании** для импорта. Имя **не встроено** в книгу и **не** будет автоматически восстановлено из файла.

После импорта оператор должен **задать или проверить** имя кампании в UI Коммандера:

```text
Корво Неро | Поиск | Программист 1С | Новосибирск
```

Зафиксировать в форме результата фактическое отображаемое имя, если оно отличается.

## 4. Ожидаемое содержимое после импорта

| Параметр | Ожидание |
|----------|----------|
| Локальных кампаний | 1 |
| Групп | 3 |
| Ключевых фраз | 404 |
| Основных объявлений | 3 |
| Начальная ставка по фразам | **500 RUB** |
| Рекламные сети | отключены / без таргетинга в сетях |
| Быстрые ссылки | **отсутствуют** |
| Уточнения (callouts) | по утверждённому набору CA-01 (см. ниже) |

### 4.1. Идентификаторы групп (slug / UTM)

В URL используются slug групп. В XLSX имена групп отображаются в человекочитаемом виде; оператор сверяет **три отдельные группы** и соответствие slug в UTM:

| group_slug (utm_content) | Отображаемое имя группы в XLSX |
|--------------------------|--------------------------------|
| `ca-01-specialist-search` | Программист / специалист 1С — specialist search |
| `ca-01-price-intent` | Программист / специалист 1С — Price / cost intent |
| `ca-01-direct-service-order` | Программист / специалист 1С — direct service order |

Ожидаемое распределение фраз (для выборочной сверки): specialist search — 384; price intent — 16; direct service order — 4.

### 4.4.2. Уточнения CA-01

Должны присутствовать (все четыре):

```text
Удалённо по России
Выезд в Новосибирске
Работа по договору
Минимальный заказ 2 часа
```

### 4.3. Минус-фразы

**Общие утверждённые (shared):**

```text
вакансия
работа программистом
резюме
сертификация
кряк
зарплата
стань программистом
становится программистом
скачать
```

**Минус-фразы кампании CA-01:**

```text
купить 1с
лицензия 1с
```

**Кросс-минус-фразы:** none (не ожидаются).

В метаданных XLSX минус-фразы кампании записаны в одной ячейке блока метаданных (строки 1–13, лист «Тексты»).

### 4.4. URL и UTM

**Базовый URL:**

```text
https://lk.corvonero.ru/programmist-1s/
```

**Ожидаемые UTM-параметры:**

```text
utm_source=yandex
utm_medium=cpc
utm_campaign=corv_programmist_1s
utm_content=<group_slug>
```

Пример для группы specialist search:

```text
https://lk.corvonero.ru/programmist-1s/?utm_source=yandex&utm_medium=cpc&utm_campaign=corv_programmist_1s&utm_content=ca-01-specialist-search
```

**Не должно быть:**

- `utm_term`
- макроса `{keyword}`
- якорей фрагмента (`#...`)

## 5. Порядок импорта в Коммандере

1. Меню импорта → выбрать XLSX CA-01 (путь см. §1).
2. Дождаться окна результата импорта.
3. **Не** подтверждать отправку на сервер.
4. Открыть дерево кампании и проверить структуру локально.
5. Задать/проверить имя кампании (§3).
6. Пройти чек-лист §6 и заполнить форму результата.

2. Показал ли ошибки или предупреждения при импорте?
3. Сколько кампаний создано локально?
4. Сколько групп?
5. Сколько ключевых фраз?
6. Сколько объявлений?
7. Все ли ставки по фразам равны **500 RUB**?
8. Разделены ли все три группы корректно?
9. Заголовки и тексты попали в правильные поля?
10. URL полные, не обрезаны?
11. Отображаемые ссылки (display path) корректны?
12. Импортировались ли уточнения (callouts)?
13. Импортировались ли общие и кампанийные минус-фразы?
14. Быстрые ссылки отсутствуют?
15. Показ в сетях отключён или не разрешён?
16. Есть ли неожиданные строки автотаргетинга?
17. Есть ли пустые обязательные поля?
18. Есть ли проблемы кодировки кириллицы?
19. Есть ли дубли фраз?
20. Позволяет ли Коммандер оставить локальную кампанию **неотправленной**?

## 8. Критерии итога теста

| Итог | Условие |
|------|---------|
| **PASS** | Импорт локально успешен; структура 1 / 3 / 404 / 3; ставки 500 RUB; callouts и минус-фразы на месте; сети не активированы; отправка на сервер **не** выполнялась |

| **FAIL** | Отказ импорта, критические ошибки, неверные счётчики, утечка `{keyword}` / `utm_term`, отправка на сервер, или активация кампании |
