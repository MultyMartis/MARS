## Minimum homepage changes before any fallback test could be considered

1. Dedicated service section or URL per P1 campaign family (RD-02).
2. Service-specific H1 and first-screen message matching ad intent.
3. Explicit **Новосибирск + Новосибирская область** service statement.
4. Service-specific CTA (not generic «Услуги» anchor only).
5. Clear separation from `/products` catalog (RD-04).

**Operator must explicitly authorize any fallback test after changes — not covered by Phase 6.2.**
