## Перед стартом

1. Убедись, что Laragon запущен (Apache + MySQL).
2. Открой браузер (Chrome / Edge).
3. Ширина окна ≈ **1440px** (или полный экран на обычном мониторе).
4. Папка для скриншотов — любая удобная (например Desktop / `Screenshots/iseo-hub`).
5. Держи рядом блокнот или этот файл — пиши замечания сразу под именем скрина.

## Жёсткие «не нажимать»

На всём проходе **не** нажимай:

- Сохранить / Создать / Обновить (формы)
- Применить сборку (Apply)
- Финализировать / Открыть снова / На проверку
- Создать снимок / Создать HTML / Создать PDF
- Создать ссылку / Отозвать ссылку
- Удалить (если где-то видно)

Можно: открывать страницы, листать, раскрывать `<details>`, делать скриншоты.

## Маршрут (по порядку)

### 1. Вход
- Открой: `http://iseo-report-hub.test/login`
- Скрин: `…-01-login.png`
- Войди под тестовым логином.

### 2. Главная
- Должен открыться dashboard `/`
- Скрин: `…-02-dashboard.png`
- Смотри: меню слева, заголовки, статусы, нет лишнего английского.

### 3. Список периодов / отчётов
- Слева: **Отчетные периоды** → `/reporting-periods`
- Скрин: `…-03-reporting-periods.png`

### 4. Месячный отчёт id 1
- Открой период с отчётом (обычно период `2026-07` / ссылка на месячный отчёт)  
  или прямо: `http://iseo-report-hub.test/monthly-reports/1`
- Скрин первого экрана: `…-04-monthly-report-1.png`
- Прокрути до блока **Работы за месяц**
- Скрин работ: `…-05-work-entries-1.png`

### 5. Создать работу (только открыть форму)
- Нажми **Добавить работу** (или `/monthly-reports/1/work-entries/create`)
- Скрин: `…-06-work-entry-create.png`
- **Не сохраняй.** Вернись назад.

### 6. Изменить работу (только открыть форму)
- На карточке любой работы нажми **Изменить**  
  (пример: `/monthly-report-work-entries/1/edit`)
- Скрин: `…-07-work-entry-edit.png`
- **Не сохраняй.**

### 7. Сборка черновика
- Открой: `/monthly-reports/1/assembly-preview`  
  (кнопка «Собрать черновик из работ»)
- Скрин: `…-08-assembly-preview.png` (лучше полный длинный экран, если получается)
- **Не жми Apply / Применить.**

### 8. Клиентский предпросмотр
- Открой: `/monthly-reports/1/preview`
- Скрин: `…-09-client-preview.png` (желательно полный документ)
- Проверь: выглядит как отчёт клиенту, без админ-панелей.

### 9. Печать
- Открой: `/monthly-reports/1/preview/print`
- Скрин: `…-10-client-preview-print.png`

### 10. Файлы отчёта
- Слева **Файлы отчета** или `/report-snapshots/1/exports`
- Скрин: `…-11-exports-list.png`
- **Не создавай** новые HTML/PDF.

### 11. Export 4
- Открой: `/report-exports/4`
- Скрин: `…-12-export-4.png`
- Не копируй checksum/token в чат.

### 12. Ссылки для клиента
- Слева **Ссылки для клиента** или `/report-exports/4/shares`
- Скрин: `…-13-export-shares.png`
- **Не создавай / не отзывай** ссылки. Токены в заметки **не** писать.

### 13. Пустой draft (полезно)
- Открой: `/monthly-reports/5`
- Скрин: `…-14-monthly-report-5-empty.png`
- По желанию preview: `/monthly-reports/5/preview` → `…-15-preview-5-empty.png`

### 14. Ошибка 404 (по желанию)
- Открой: `http://iseo-report-hub.test/no-such-page-qa`
- Скрин: `…-16-not-found.png`

### 15. Конец
- Можно **Выйти** (`/logout`).
- Собери скрины + короткие замечания (формат ниже / в intake-доке).
