## 5. Demo Summary

### Pages

1. **Dashboard** (`index.html`) — assigned projects, deadlines, KPI overview, action items, prototype banner, quick links
2. **Project / Cycle** (`project.html`) — client meta, checkpoint strip, KPI snapshot, evidence, Topvisor card, quick actions
3. **Weekly Editor** (`weekly.html`) — week selector, checklist, metrics, blockers, evidence, Topvisor, internal notes, review/publish toggles
4. **Monthly Editor** (`monthly.html`) — executive summary, KPI, traffic/positions/leads blocks, work rollup, weekly summary, risks, plan, evidence, validation panel
5. **Client Report** (`client-report.html`) — calm client-facing layout, KPI, chart placeholders, works, Topvisor, risks, plan, collapsible evidence
6. **Review Queue** (`review.html`) — inbox table, quick review panel, approve/revision demo actions, comment thread

### Visual direction

- Clean B2B admin style: light background, restrained blue accent, card/table layouts
- Admin pages denser; client report calmer and less chrome
- Russian UI text throughout
- Prototype / Demo markers visible on admin screens

### Demo data

- Client: Demo Industrial Tools
- Site: demo-tools.example
- Project: SEO продвижение интернет-магазина
- Profile: E-commerce
- Period: Июль 2026
- KPIs, weekly statuses, works, blockers, and plans per task charter

### Limitations

- No data persistence; form controls are visual only
- Chart blocks are placeholders
- Approve/publish/submit actions show demo feedback only
- No responsive polish beyond basic client-report breakpoints
- Final i-SEO brand tokens not locked — tone exploration only
