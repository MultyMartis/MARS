# I-SEO Report Hub — инструкция для SEO-специалиста (черновик)

> **Черновик. Локальная демо-версия. Не финальная инструкция для боевой версии.**

**Версия:** v0.1  
**Аудитория:** SEO-специалист i-SEO  
**Среда:** только локальная демо (`http://iseo-report-hub.test/`) — **не** боевой сайт для клиентов

---

## 1. Для чего нужен Report Hub

Report Hub помогает **собрать месячный SEO-отчёт** в одном месте:

- зафиксировать **выполненные и запланированные работы**;
- подготовить **тексты для клиентского отчёта**;
- **посмотреть превью**, как отчёт увидит клиент, до отправки.

Сейчас это **учебная/demo-версия** для проверки процесса. PDF, публичная ссылка и реальная отправка клиенту **ещё не готовы**.

---

## 2. Базовый порядок работы

1. Войти в систему.
2. Открыть **отчётные периоды**.
3. Выбрать **текущий месяц** (отчёт «в работе»).
4. Добавить или обновить **список работ** за месяц.
5. Открыть **«Тексты отчёта»**.
6. Заполнить **шесть секций** текста отчёта.
7. При необходимости использовать **подсказки из работ** («Подставить в поле»).
8. Открыть **превью для клиента** и проверить текст.
9. Вопросы и замечания — **ответственному менеджеру / руководителю**, не клиенту напрямую из демо.

---

## 3. Как добавить работу

На странице месячного отчёта нажмите **добавить работу**.

Основные поля:

| Поле | Зачем |
|------|-------|
| **Название / описание работы** | Что делали или планируете |
| **Каталог (если есть)** | Можно выбрать типовую работу — необязательно |
| **Статус** | Выполнено / в процессе / запланировано и т.п. |
| **Роль в периоде** | Как работа относится к отчётному месяцу |
| **Комментарий для клиента** | Текст, который может попасть в отчёт |
| **Внутренняя заметка** | Только для команды |
| **Заметка о доказательствах** | Пока текстом: ссылка на скрин, файл, сервис мониторинга (см. раздел 6) |

Сохраните работу, когда поля заполнены.

---

## 4. Как подготовить тексты отчёта

Кнопка **«Тексты отчёта»** открывает шесть секций:

| Секция | О чём писать |
|--------|----------------|
| **Краткое резюме** | Короткий итог месяца |
| **Что сделали** | Основные выполненные работы |
| **Результаты** | Цифры, динамика, достижения |
| **Ключевые выводы** | Главные выводы для клиента |
| **Риски и блокеры** | Что мешает или требует внимания |
| **План на следующий месяц** | Что планируете дальше |

У каждой секции — **сохранить раздел** отдельно. После сохранения проверьте **превью**.

Подсказки из списка работ можно раскрыть и нажать **«Подставить в поле»** — текст подставится в поле; при необходимости отредактируйте и сохраните.

---

## 5. Чего не трогать / что ещё не готово

- **PDF** — не готов.
- **Публичная ссылка для клиента** — не готова.
- **Реальная отправка клиенту** через эту демо — **нельзя**.
- **Сырые технические страницы** редактирования блоков — недоступны; используйте только «Тексты отчёта».
- **Финализированные отчёты** (например, прошлый закрытый месяц) — **только просмотр**, правки запрещены.

---

## 6. Скриншоты и доказательства

**В этой демо-версии отдельные поля для загрузки скриншотов, файлов и внешних ссылок ещё не реализованы.**

Пока что:

- укажите в **заметке о доказательствах** или **внутренней заметке**, что у вас есть (скрин, ссылка на Topvisor/Вебмастер и т.д.);
- **файлы и скрины отправляйте менеджеру отдельно** (почта, мессенджер, общая папка).

В будущей версии появятся отдельные поля: скриншот, файл, внешняя ссылка, видимость «клиенту / только внутри».
