# Reminder Natural Acceptance Checklist

Use this checklist for natural reminder observation. Do not use it to claim PASS from configuration alone.

- [ ] CONFIG has reminders enabled.
- [ ] Reminder time is `10:00`.
- [ ] Reminder timezone is `Europe/Moscow`.
- [ ] Weekday gate is Monday-Friday.
- [ ] Candidate selection includes still-actionable pending real leads.
- [ ] Monday candidate selection includes weekend pending backlog.
- [ ] Candidate selection excludes processed.
- [ ] Candidate selection excludes spam.
- [ ] Candidate selection excludes tests.
- [ ] Candidate selection excludes archive/legacy non-production.
- [ ] Natural reminder fires at expected time.
- [ ] Notification content is useful to manager/operator.
- [ ] No lifecycle mutation occurs.
- [ ] Evidence records natural observation timestamp.
- [ ] If not naturally observed, status remains PENDING OBSERVATION.
