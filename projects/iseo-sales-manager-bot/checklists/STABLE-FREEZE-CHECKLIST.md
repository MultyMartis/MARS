# Stable Freeze Checklist

- [ ] Stable designation is named.
- [ ] Production status is accepted by operator.
- [ ] Freeze commit is recorded.
- [ ] Active n8n workflow IDs are recorded.
- [ ] Inactive/legacy workflows are recorded separately.
- [ ] AI state is recorded.
- [ ] Persistence reality is recorded.
- [ ] Gmail intake contract is recorded.
- [ ] RAW/CLEAN authority is recorded.
- [ ] Telegram actions are recorded.
- [ ] Reminder rules are recorded.
- [ ] Known pending observations are explicitly marked.
- [ ] No pending observation is claimed PASS without evidence.
- [ ] Evidence folder is linked.
- [ ] No secret values or raw PII are stored.
- [ ] Post-freeze changes require a new explicit phase.
