# Руководство Оли — работа с лидами (v1)

> Phase 3D.8 access note: intended guide recipient is currently **revoked by operator choice**. This remains a future moderator guide; do not restore access from this document.

Новые заявки приходят в **личный чат** с ботом Sales Manager.

1. Откройте карточку лида.
2. Скопируйте контакт и при необходимости готовый ответ (ответ клиенту бот сам не отправляет).
3. После связи с клиентом нажмите **✅ Отметить обработанным** или **🚫 Отметить как спам**.
4. Статус **общий** для всей команды: если коллега нажал кнопку раньше, ваш повторный клик не перезапишет статус.
5. Кнопки на всех копиях карточки синхронизируются.

Команды: `/start`, `/help`, `/my_status`.
