# CANONICAL LEAD VIEW ADAPTER v1

Single adapter for Admin lead-reading surfaces.

**Precedence**

- Lifecycle: `lifecycle_status` → compat `manager_status` → never force pending when processed known.
- Service: `resolved_service_label` → code map → `—` only if absent.
- Request: `client_comment` → `request_summary` → `—`.
- Source display: `source_display` → website-form map `Сайт i-seo.su` → safe channel fallback.

No positional column indices as business values.
