# REVOKED / BLOCKED STATUS v1

## Revoke
Для `moderator / revoked` `/my_status` сохраняет только публичную видимость:

```text
Ваш статус

Роль: бывший модератор
Рабочие права: отозваны

Публичные команды остаются доступны.
Для восстановления прав обратитесь к администратору.
```

Callback-действия запрещаются сразу; повторное добавление восстанавливает доступ.

## Block
Для `blocked` команда допустима только как безопасное status-only исключение:

```text
Ваш статус

Доступ к боту ограничен.
```

Все остальные команды блокируются. Explicit ACCESS_CONTROL revoked/blocked всегда имеет приоритет над CONFIG allowlists.
