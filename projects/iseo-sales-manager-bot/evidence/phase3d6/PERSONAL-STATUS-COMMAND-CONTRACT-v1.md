# PERSONAL STATUS COMMAND CONTRACT v1

## Назначение
`/my_status` — публично достижимая персональная команда. Источник роли и статуса — **ACCESS_CONTROL**; поиск выполняется по `telegram_user_id`. Команда не раскрывает чужие записи, идентификаторы или служебные поля.

## Точные ответы
| Состояние | Ответ |
|---|---|
| public | `Ваш статус` → `Роль: обычный пользователь` / `Рабочие права: не выданы`; доступны `/start`, `/help`, `/my_status`; для прав — обратиться к администратору |
| pending | `Ваш статус` → `Роль: обычный пользователь` / `Заявка на рабочий доступ: ожидает подтверждения` / `Администратор ещё не выдал права модератора.` |
| moderator active | `Ваш статус` → `Роль: модератор` / `Статус: активен`; доступны карточки и отметки «Обработан»/«Спам»; административные настройки недоступны |
| admin active | `Ваш статус` → `Роль: администратор` / `Статус: активен` / `Доступны административные команды и управление модераторами.` |
| revoked moderator | `Ваш статус` → `Роль: бывший модератор` / `Рабочие права: отозваны`; публичные команды остаются доступны |
| blocked | `Ваш статус` → `Доступ к боту ограничен.` |

При технической недоступности реестра Admin bootstrap получает статус восстановления; остальные пользователи получают безопасный ответ о временной недоступности, без fail-open.
