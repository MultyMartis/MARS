# COPY-FRIENDLY FIELDS ACCEPTANCE v1

**Parse mode:** HTML  
**Fields:** name / phone / email / messenger / site as separate `<code>` blocks when present.  
**Harness:** cases 5–9 PASS.  
**Note:** Telegram clients support tap-to-copy on `<code>`/`<pre>` in current mobile/desktop clients; if a client lacks tap-copy, long-press still works.
