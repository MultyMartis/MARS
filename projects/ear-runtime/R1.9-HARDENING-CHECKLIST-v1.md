## Purpose

Consolidate all R1.8 / R1.8E recommendations and safety guarantees into a single hardening verification checklist for the first mock Store implementation. **Review only** — execution of automated tests is deferred to a future implementation phase.

## Hardening checklist

### Immutability

| ID | Check | Expected | R1.9 review status |
|----|-------|----------|-------------------|
| I-01 | Second persist same `snapshot_id` | `PersistenceError`; no file overwrite | **DESIGNED** — code evidence; live re-run not executed |
| I-02 | `snapshot_dir` pre-exists | Fail before write | **VERIFIED (code)** |
| I-03 | Target JSON pre-exists | `PersistenceError` per file | **VERIFIED (code)** |
| I-04 | `mkdir(..., exist_ok=False)` | Race: second caller fails | **VERIFIED (code)** |
| I-05 | Partial write then retry | Dir exists → fail closed (may leave orphan dir) | **NOTED** — see H-09 |

### Collision handling

| ID | Check | Expected | R1.9 review status |
|----|-------|----------|-------------------|
| C-01 | Duplicate `snapshot_id` under same `output_root` | Fail closed | **VERIFIED (code)** |
| C-02 | Same `acquisition_id`, different `snapshot_id` | Allowed (new snapshot dir) | **VERIFIED (design)** |
| C-03 | Different `output_root`, same `snapshot_id` | Independent trees (operator responsibility) | **ACCEPTED** — not deduplicated globally |
| C-04 | `snapshot_id` path-segment injection (`/`, `\`, `..`) | Reject or contain under `output_root` | **GAP NOTED** — no explicit id sanitization |

### Output root validation

| ID | Check | Expected | R1.9 review status |
|----|-------|----------|-------------------|
| O-01 | `output_root` missing / empty in config | Fail at config load or validation | **VERIFIED** — config_loader + validator |
| O-02 | `output_root` outside `EAR_BULK_ROOT` | Validation error; no write | **VERIFIED (code)** |
| O-03 | `output_root` with `..` in config string | `ConfigValidationError` at load | **VERIFIED** — `config_loader._reject_path_traversal` |
| O-04 | Symlink / junction escape | **SAFE UNKNOWN** — `resolve()` used; junction behavior OS-dependent |

### Path validation

| ID | Check | Expected | R1.9 review status |
|----|-------|----------|-------------------|
| P-01 | `snapshot_dir` under resolved `output_root` | `relative_to` or `PersistenceError` | **VERIFIED (code)** |
| P-02 | `paths.*` keys present and non-empty | Validator | **VERIFIED (code)** |
| P-03 | `paths.snapshot_dir` matches layout formula | Charter alignment | **NOT VALIDATED** — D-07 accepted |
| P-04 | Writes only to three declared JSON paths | Loop over fixed filenames | **VERIFIED (code)** |

### Store integrity

| ID | Check | Expected | R1.9 review status |
|----|-------|----------|-------------------|
| S-01 | Three files written atomically as set | All or fail closed on retry | **PARTIAL** — no transaction; mid-write orphan possible |
| S-02 | Cross-file `snapshot_id` / `store_state` / `created_at` | Consistent in observed artefact | **VERIFIED (on-disk)** |
| S-03 | JSON schema / required field validation on write | Not required R1.8 | **N/A** — layout builder only |
| S-04 | Read-back / checksum after write | Not implemented | **DEFERRED** |

### Fail closed

| ID | Check | Expected | R1.9 review status |
|----|-------|----------|-------------------|
| F-01 | Validation errors before mkdir | `PersistenceError` | **VERIFIED (code)** |
| F-02 | Connector catches `PersistenceError` | `validation.valid: false` | **VERIFIED (code)** |
| F-03 | CLI exit non-zero on invalid persist | Exit 1 | **VERIFIED (code)** — not re-run in R1.9 |
| F-04 | Pipeline stages invalid before persist | Return invalid validation; no store call | **VERIFIED (code)** |

| N-02 | Automated negative test suite | All cases FAIL CLOSED | **NOT EXECUTED** — design only per charter |
| N-03 | Second CLI persist same id | FAIL CLOSED | **DEFERRED** — R-01 |

### Store state consistency

| ID | Check | Expected | R1.9 review status |
|----|-------|----------|-------------------|
| T-01 | `store_state` = `stored_unpublished` in layout + all JSON | Consistent | **VERIFIED (on-disk)** |
| T-02 | Invalid `store_state` in layout | Validator error | **VERIFIED (code)** |
| T-03 | `STORE_STATE_STORED` without publish path | Not used by mock persist | **OK** — contract allows; mock path fixed |
| T-04 | `publish_state` encoding vs architecture OQ-08 | Duplicate string | **NOTED** — non-blocking |
