- generation rules for `snapshot_id`
- field transforms from Evidence Identity to Snapshot Identity
- continuity rules across R2 → R3 → R5 → R4
- drift-prevention controls (ID-R3-01–ID-R3-15)

This milestone is the **authority** for:

| Downstream | Depends on R3.2 for |

| **R3.4** Safe Unknown Propagation | Identity gaps must not invent correlation keys |
| **R3.5** HandoffContract + Candidate Snapshot Generator | `snapshot_id` creation timing, transform matrix, continuity record |

**Explicit exclusions:** generator implementation, section population, persistence, Store redesign, Validate, Publish, OCPilot, SITE-001, network.

## Identity lifecycle

### Canonical stages

```text
Evidence Identity                          Owner: R2
(acquisition_id, site_ref, connector_class)
        │
        │  R2.6 HANDOFF — read-only consumption
        ▼
Snapshot Identity                          Owner: R3
(snapshot_id, acquisition_id, site_id, snapshot_contract)
        │
        │  Candidate assembly + Store persist (R3.5)
        ▼
Validated Snapshot                         Owner: R5
(same snapshot_id — immutable; quality certified)
        │
        │  Publish gate + HITL (R4)
        ▼
Published Snapshot                         Owner: R4
(same snapshot_id — consumer citation key)
```

### Stage definitions and ownership

| Stage | Identity artefact | Key fields | Owner | Mutability |
|-------|-------------------|------------|-------|------------|
| **Evidence Identity** | `EvidenceIdentity` on `EvidencePackage` | `acquisition_id`, `site_ref`, `connector_class` | **R2** generator / quarantine | Frozen at package construction; **no** `snapshot_id` |
| **Snapshot Identity** | `SnapshotIdentity` on `SnapshotPackage` | `snapshot_id`, `acquisition_id`, `site_id`, `snapshot_contract` | **R3** assembly at Store boundary | `snapshot_id` assigned once; **immutable** after creation |
| **Validated Snapshot** | Stored candidate + R5 Validate report | Same `snapshot_id`; `package_quality_level` may change per R5 | **R5** certifies; **R3** artefact read-only | `snapshot_id` **must not** change; corrections = new acquisition → new `snapshot_id` |
| **Published Snapshot** | Consumer-visible reference | Same `snapshot_id`; optional publish metadata (R4) | **R4** Publish | `snapshot_id` **must not** change post-Publish |

### Lifecycle pipeline position

```text
Acquire (R1)
        ↓
Evidence Package — Evidence Identity (R2)
        ↓
R2 structural validation (eligibility gate)
        ↓
╔═══════════════════════════════════════╗
║  R2.6 HANDOFF (read-only)             ║
╚═══════════════════════════════════════╝
        ↓
R3 Identity Layer — Snapshot Identity created (R3.2 contract; R3.5 code)
        ↓
R3 Section Assembly (R3.3–R3.5)
        ↓
R5 Validate — identity read, not recreated
        ↓
Store — {acquisition_id}/snapshots/{snapshot_id}/ (R1.8 frozen)
        ↓
R4 Publish — consumer cites snapshot_id
```

### Namespace separation

| Identifier | Namespace | Consumer-facing |
|------------|-----------|-----------------|
| `acquisition_id` | Session / folder correlation | **No** |

## Identity continuity

### Traceability chain (normative)

```text
R1.2 Config
│  site_id (config) ─────────────────────┐
│  connector (config) ───────────────────┤
│  output_root, scope, ear_mode            │
└──────────────────────────────────────────┘
                    │
                    ▼  Runtime session start — R2 owns
            acquisition_id  ← binds {acquisition_id}/ folder
                    │
                    ▼  R2 Evidence Package
        EvidenceIdentity {
            acquisition_id,    ← SURVIVES unchanged
            site_ref,          ← TRANSFORMS to site_id
            connector_class    ← SURVIVES to acquisition-log
        }
        + EvidenceProvenance, scope_echo, artifact_index, status
                    │
                    ▼  R2.6 HANDOFF (read-only)
                    │
                    ▼  R3 Snapshot Assembly — R3 owns identity creation
        SnapshotIdentity {
            snapshot_id,       ← CREATED by R3 (new)
            acquisition_id,    ← SURVIVES (same value)
            site_id,           ← TRANSFORMED from site_ref (1:1 value)
            snapshot_contract  ← CREATED by R3 (constant)
        }
                    │
                    ▼  R1.8 Store (frozen layout)
        {output_root}/{acquisition_id}/snapshots/{snapshot_id}/
                    │
                    ▼  R5 Validate → R4 Publish
        snapshot_id immutable throughout
```

| ID | Invariant | Authority |
|----|-----------|-----------|
| ID-CONT-01 | `acquisition_id` on snapshot **equals** `acquisition_id` on source evidence | R2.6 § What survives |
| ID-CONT-02 | `site_id` on snapshot **equals** `site_ref` on source evidence (value carry; name change only) | R1-CONTRACT-MAPPING; EAR-OPENCART-SNAPSHOT-SPEC |
| ID-CONT-03 | `connector_class` on evidence **equals** `acquisition_log.connector_class` on snapshot | R3.1 `SnapshotAcquisitionLog` |
| ID-CONT-04 | Session folder `{acquisition_id}/` binds evidence quarantine and snapshot Store siblings | R1.8C; R2.5 |
| ID-CONT-05 | `snapshot_id` correlates to same session via folder layout — not by replacing `acquisition_id` | R2.6 H-OUT-04 |
| ID-CONT-06 | Identity Continuity Record maps `acquisition_id` → `snapshot_id` at assembly — format deferred to R3.5 | R2.6 H-OUT-04 |

## Snapshot ID policy

Formal policy for `snapshot_id` — authoritative for R3.5 generator and all downstream phases.

### Who creates `snapshot_id`

| Actor | Role |
|-------|------|
| **R3 Candidate Snapshot Generator** (R3.5) | **Sole creator** at Store boundary |
| **R3 Identity Layer contract** (this document) | Defines rules; **no** runtime assignment |
| **R2 Evidence Generator** | **Forbidden** — must not pre-assign |
| **R5 Validate** | **Forbidden** — reads and certifies; does not create |
| **R4 Publish** | **Forbidden** — promotes existing id |
| **Operator** | **Forbidden** — supplies approval refs, not snapshot ids |

### When `snapshot_id` appears

| Event | `snapshot_id` state |
|-------|---------------------|
| R1 session start | **Absent** — only `acquisition_id` exists |
| R2 evidence package construction | **Absent** — ID-DRIFT-01 |
| R2.6 handoff emit | **Absent** — H-OUT-04 is forward correlation only |
| R3 assembly start (pre-identity) | **Absent** — assembly may plan; id not committed |
| **R3 identity assignment** (Store boundary) | **Created** — first authoritative appearance |
| R3 Store persist | **Written** — path segment + identity block |
| R5 Validate | **Read** — immutability verified |
| R4 Publish | **Referenced** — consumer citation key |

**Timing rule (ID-R3-06):** `snapshot_id` is assigned **once**, at the moment R3 commits a candidate Snapshot Package to the Store boundary — immediately before or atomically with first write under `snapshots/{snapshot_id}/`. It must **not** be speculative, provisional, or backfilled onto evidence.

### Where `snapshot_id` is stored

| Location | Required | Notes |
|----------|----------|-------|
| `SnapshotIdentity.snapshot_id` | **Yes** | Primary logical field — R3.1 model |
| `SnapshotMetadata` echo (serialization / `metadata/`) | **Yes** | OpenCart spec requires id in metadata section |
| Store filesystem path `{acquisition_id}/snapshots/{snapshot_id}/` | **Yes** | R1.8C frozen layout |
| `acquisition-log/` cross-reference | **Optional** | Audit correlation — not replacement for identity block |
| Identity Continuity Record sidecar | **Optional** | R3.5 — format **SAFE UNKNOWN** |
| R5 Validate report | **Yes** | References validated id |
| R4 published reference | **Yes** | Consumer intake key |

### What may reference `snapshot_id`

| Consumer | Allowed use |
|----------|-------------|
| R3 `SnapshotPackage` / Store persist | Primary owner |
| R1.8 `snapshot_store.py` | Immutability check; path layout |
| R5 Validate | Contract and quality certification target |
| R4 Publish | Consumer promotion |
| Operator inspection | Audit |
| Consumer programs (post-Publish) | Citation, baseline diff, intake |
| `metadata.prior_snapshot_ref` | Supersession link to prior snapshot |

### What may NOT reference `snapshot_id`

| Artefact | Reason |
|----------|--------|
| `EvidencePackage` / `EvidenceIdentity` | ID-R3-01; ID-DRIFT-01 |
| Evidence quarantine index under `evidence/` | Pre-contract artefact |
| R2 generator output before handoff | Identity separation |
| Connector Input/Output JSON (R1.2) | Session uses `acquisition_id` only |
| Consumer paths pre-Publish | HO-FORBID-07 |
| `bulk_root` for evidence quarantine | ID-R3-02 |
| Mock R1.6 `evidence_models` | Deprecated boundary — N-R3-02 |

### Immutability rules

| ID | Rule | Authority |
|----|------|-----------|
| ID-R3-07 | `snapshot_id` **must not mutate** after creation | R1.8B § Immutability |
| ID-R3-08 | Corrections require **new** acquisition session → **new** `snapshot_id` | R1.8B § Supersession |
| ID-R3-09 | Same-day re-acquisition uses **new** sequence suffix — never reuse id | R1.8B § Supersession |
| ID-R3-10 | Store write-once per `snapshot_id` — duplicate id = fail closed | R1.9 hardening |

### Generation rules (contract only — implementation at R3.5)

#### Production format (locked per R1.8B G-05)

```
snap-{YYYYMMDD}-{site_id}-{sequence}
```

| Part | Required | Description |
|------|----------|-------------|
| Prefix | Yes | Literal `snap-` |
| `{YYYYMMDD}` | Yes | Acquisition date — anchoring event **SAFE UNKNOWN** (recommend Store persist date) |
| `{site_id}` | Yes | Consumer registry id from transformed `site_ref`; case normalization **SAFE UNKNOWN** |
| `{sequence}` | Yes | Partial-run sequence: `p1`, `p2`, … or monotonic run id |

**Examples:**

| Example | Meaning |
|---------|---------|
| `snap-20260604-SITE-001-p1` | First partial snapshot for SITE-001 |
| `snap-20260604-SITE-001-p2` | Superseding partial — new id, not mutation |

#### Mock format (R3.5 dry-run only)

```
snap-mock-{site_id}-{source}
```

| Rule | Detail |
|------|--------|
| Scope | Mock pipeline / `--contract-snapshot` dry-run only |
| Forbidden | Production Store paths; Publish; consumer intake |
| Transform | Mock ids **never** written to production storage ([R1.8B](R1.8B-SNAPSHOT-STORAGE-CONTRACT-v1.md)) |

#### Generation inputs (R3.5)

| Input | Source | Use |
|-------|--------|-----|
| `site_id` | Transform of `evidence.identity.site_ref` | Id segment |
| Date component | Assembly timestamp or Store persist time | **SAFE UNKNOWN** anchor |
| Sequence | Partial-run context, `prior_snapshot_ref`, or monotonic counter | **SAFE UNKNOWN** counter storage |
| `acquisition_id` | Evidence identity | Folder binding — **not** embedded in id string |

**No generator code in R3.2** — rules only.

## Transform rules

### Classification vocabulary

| Class | Meaning |
|-------|---------|
| **survives** | Same semantic value; may appear under different field name or section |
| **transforms** | Value carried with field rename, structural expansion, or section relocation |
| **created** | New field — no evidence source |
| **forbidden** | Must not appear on target artefact |

### Core identity transforms

| Evidence (R2) | Snapshot (R3) | Class | Rule |
|---------------|---------------|-------|------|
| `identity.acquisition_id` | `identity.acquisition_id` | **survives** | Same value; immutable |
| `identity.site_ref` | `identity.site_id` | **transforms** | 1:1 value rename per OpenCart contract |
| `identity.connector_class` | `acquisition_log.connector_class` | **survives** | Same value; relocated to audit section |
| — | `identity.snapshot_id` | **created** | R3 Store boundary |
| — | `identity.snapshot_contract` | **created** | Constant `ear-opencart-snapshot-v1` |
| — | `metadata.parent_contract` | **created** | Constant `ear-snapshot-v1` |
| `provenance.operator_approval_ref` | `metadata.operator_approval` | **transforms** | Field rename |
| `provenance.operator_approval_ref` | `acquisition_log.approved_by` | **transforms** | Same source; dual echo |
| `provenance.channel` | `acquisition_log.channel` | **survives** | Same value |
| `provenance.started_at` | `acquisition_log.started_at` | **survives** | Same value |
| `provenance.completed_at` | `acquisition_log.completed_at` | **survives** | Same value |
| `provenance.started_at` / `completed_at` | `metadata.acquisition_date` | **transforms** | Claim semantics — assembly chooses echo |
| Config echo `ear_mode` | `metadata.ear_mode` + `acquisition_log.ear_mode` | **survives** | Via provenance traceability |
| `scope_echo.approved_scope` | `acquisition_log.scope_approved` | **transforms** | Tuple carry |
| `scope_echo.attempted_scope` | `acquisition_log.scope_attempted` | **transforms** | Tuple carry |
| `status.connector_status` | `safe_unknown` topics | **transforms** | Honesty carrier — not root enum copy |
| `errors`, `warnings` | `safe_unknown` topics | **transforms** | HO-ALLOW-04 |
| `artifact_index.*` | Section payloads | **transforms** | Expansion — refs not verbatim copy |
| Evidence quarantine path | — | **forbidden** on snapshot `bulk_root` | ID-R3-02 |
| `snapshot_id` (any) | — | **forbidden** on evidence | ID-R3-01 |
| `package_quality_level` | `metadata.package_quality_level` | **created** | L0 default at assembly; not from evidence |

## Drift prevention rules

Formal identity drift controls — extends R3 Charter ID-R3-01–05 and R2.6 ID-DRIFT-01–06.

| ID | Rule | Authority |
|----|------|-----------|
| **ID-R3-01** | Do **not** store `snapshot_id` in evidence identity block or `EvidencePackage` | R2.2 INV-03; R2.6 ID-DRIFT-01 |
| **ID-R3-02** | Do **not** alias evidence quarantine path as snapshot `bulk_root` | R2.6 ID-DRIFT-04; HO-FORBID-14 |
| **ID-R3-03** | `acquisition_id` **immutable** after `EvidencePackage` construction — R3 reads only | R2.2 INV-06; R2.6 ID-DRIFT-03 |
| **ID-R3-04** | 1:N `acquisition_id` → `snapshot_id` merge policy — **SAFE UNKNOWN**; each cycle gets new `snapshot_id` | R2.6 ID-DRIFT-06 |
| **ID-R3-05** | R3 assembly consumes R2.1 `EvidencePackage` — not R1.6 `evidence_models` at boundary | R3 Charter; N-R2R-02 |
| **ID-R3-06** | `snapshot_id` assigned **once** at R3 Store boundary — not speculative on evidence | This document § When |
| **ID-R3-07** | `snapshot_id` **must not mutate** after creation | R1.8B immutability |
| **ID-R3-08** | Corrections require new acquisition → new `snapshot_id` — no in-place id repair | R1.8B supersession |
| **ID-R3-09** | `acquisition_id` ≠ `snapshot_id` — distinct namespaces, never interchangeable | R1.8B G-04 rule 2 |
| **ID-R3-10** | Do **not** rename Evidence Package as Snapshot Package | R2.6 HO-FORBID-04 |
| **ID-R3-11** | Snapshot identity uses `site_id` — never `site_ref` field name | EAR-OPENCART-SNAPSHOT-SPEC |
| **ID-R3-12** | Do **not** introduce `evidence_id` as handoff or snapshot correlation key | R2.2 INV-02 — **SAFE UNKNOWN** |
| **ID-R3-13** | Do **not** copy `snapshot_id` onto evidence quarantine index or sidecar | Q-INV semantics |
| **ID-R3-14** | Mock `snapshot_id` (`snap-mock-…`) **forbidden** in production Store or Publish paths | R1.8B mock boundary |
| **ID-R3-15** | Identity Continuity Record must not replace `SnapshotIdentity` block — supplementary only | R2.6 H-OUT-04 |
