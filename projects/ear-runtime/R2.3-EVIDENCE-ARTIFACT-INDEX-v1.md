## Purpose

Define and formalize the **Evidence Artifact Index** layer: what an artifact is, how artifacts are classified, how `artifact_ref` behaves, per-artifact status semantics, and index invariants that govern Evidence Package assembly — **without** implementing generation, validation, quarantine, or persistence.

**Explicit exclusions:** generator (R2.7), validator (R2.4), quarantine writes (R2.5), OpenCart sections (R3), acquisition-specific artifact names, filesystem checks, network.

## Artifact Model

### Definition

An **evidence artifact** (index entry) is a **logical descriptor** of one acquisition-internal item referenced by the Evidence Package. It names **what** was produced or expected, **how** it is classified, and **whether** that item is available — not the bytes of the item itself.

| Property | Meaning |
|----------|---------|
| **Logical** | Index describes intent and pointers; no I/O at model layer |
| **Pre-snapshot** | Not an OpenCart snapshot section (`file-manifest/` etc.) |
| **Connector-oriented** | Aligns with Connector Output `artifact_index` (conceptual) |
| **Inspectable** | Operator and R5 Validate use index to locate bulk in quarantine (**Future** persist) |

### Structure (R2.1 / contract)

```text
EvidencePackage
└── artifact_index → EvidenceArtifactIndex
    ├── artifact_count : int
    └── artifacts[] → EvidenceArtifact
        ├── artifact_type : str   # taxonomy class
        ├── artifact_ref  : str   # opaque logical / future storage pointer
        └── status        : str   # per-artifact availability
```

### Relationship to package blocks

| Block | Role vs artifacts |
|-------|-------------------|
| `identity` | Session correlation — **not** duplicated per artifact (no per-entry `site_ref`) |
| `provenance` | Session timestamps — artifact entries do not carry `started_at` |
| `scope_echo` | Approved vs attempted scope — orthogonal to artifact list |
| `status` | **Package-level** `connector_status` — distinct from per-artifact `status` |
| `warnings` / `errors` | Package-level carriers — may **reference** artifacts by `artifact_ref` in message text (**Future** structured links **SAFE UNKNOWN**) |

### What an artifact is **not**

| Anti-pattern | Rationale |
|--------------|-----------|
| Snapshot section payload | R3 owns OpenCart sections |
| Filesystem directory listing | Index ≠ `ls`; count is logical |
| Validated file existence | No path checks in R2.3 |
| `package_quality_level` | Forbidden at evidence stage |
| Consumer publish artefact | Evidence not published (R4) |

## Classification

Canonical **`artifact_type`** values (architecture taxonomy — **not** channel-specific filenames):

| Class | Constant | Purpose | Examples (logical, not prescriptive paths) | Lifecycle | Required? |
|-------|----------|---------|------------------------------------------|-----------|-----------|
| **identity** | `ARTIFACT_TYPE_IDENTITY` | Session binding echo inside index when connector emits separate identity sidecar | `identity:acquisition`, connector identity summary ref | Created at package assembly; immutable | **Optional** — identity block on package is authoritative |
| **manifest** | `ARTIFACT_TYPE_MANIFEST` | Primary structured inventory from listing/manifest chain | `manifest:logical`, future `manifest.json` ref under quarantine | Produced after listing; referenced in index before Validate | **Required** at evidence boundary (R2.4: ≥1 entry; typically manifest class) |
| **connector-output** | `ARTIFACT_TYPE_CONNECTOR_OUTPUT` | Structured connector emission (status sidecar, scope echo file, attestation) | `connector-status:logical`, `read_only_attestation:logical` | Terminal with connector run | **Optional** — channel-dependent |
| **log** | `ARTIFACT_TYPE_LOG` | Human or machine acquisition log fragments | `acquisition-log:draft`, stderr capture ref | Append during run; frozen at complete | **Optional** |
| **metadata** | `ARTIFACT_TYPE_METADATA` | Small structured sidecars (counts, labels, no secrets) | `manifest-meta:counts`, listing summary ref | Derived at assembly | **Optional** |
| **safe-unknown** | `ARTIFACT_TYPE_SAFE_UNKNOWN` | Explicit placeholder when shape or presence is unresolved | `artifact:unclassified`, `bulk:unknown-layout` | May be replaced after operator review — **policy SAFE UNKNOWN** | **Optional** — honesty when class unclear |
| **other** | `ARTIFACT_TYPE_OTHER` | Typed but not fitting canonical classes | Extension bucket — must not imply snapshot section | As needed | **Optional** |

**Rules:**

1. Use **canonical class strings** above; do not invent acquisition-specific types (e.g. `serp-capture`, `sftp-dump`) in architecture — those map to `connector-output`, `metadata`, or `other` at generator time (**R2.7**).
2. **Bulk binary** (ZIP, SQL dump, screenshots) is referenced via `artifact_ref` with type `connector-output` or `metadata`; binary location is quarantine (**R2.5**), not type name.
3. **Hybrid `leg_ref`** — per connector leg on index entry — **Future** (R2.8); not in R2.1 model fields yet.

### Index participation in package assembly

| Stage | Index role |
|-------|------------|
| R1.5 manifest chain | Supplies logical **manifest** entry (counts, no file yet) |
| R2.7 generator | Builds `EvidenceArtifactIndex` from manifest + connector output metadata |
| R2.4 validator | Checks invariants (count, uniqueness, required manifest, enum labels) |
| R2.5 quarantine | Persists bulk; may rewrite `artifact_ref` to storage-relative refs — **no** model change |
| R3 snapshot builder | Reads index refs to expand sections — **not** R2.3 |

```text
Manifest (R1.5)
    ↓  logical ref
EvidenceArtifact (type=manifest)
    ↓
EvidenceArtifactIndex
    ↓
EvidencePackage.artifact_index
    ↓  handoff (R2.6)
R3 Snapshot Builder (reads refs only)
```

## Reference Rules

### What `artifact_ref` **means**

| Meaning | Description |
|---------|-------------|
| **Logical reference** | Stable label within one `acquisition_id` session (e.g. `manifest:primary`, `listing:summary`) |
| **Future quarantine reference** | Relative or opaque path under `{output_root}/{acquisition_id}/evidence/` — resolved at persist (**R2.5**) |
| **Future storage reference** | External bulk root + relative path per [EAR-STORAGE-MODEL-v1.md](../../shared/external-access-runtime/EAR-STORAGE-MODEL-v1.md) |
| **Correlation key** | Join point for warnings/errors text and operator inspection |

**Canonical behavior:**

- **Opaque string** at model layer — no parsing, no normalization, no existence checks.
- **Unique within package** among index entries (invariant ART-INV-04).
- **Non-secret** — credentials must not appear in refs ([EAR-CREDENTIAL-BOUNDARY-v1.md](../../shared/external-access-runtime/EAR-CREDENTIAL-BOUNDARY-v1.md)).
- **Stable for session** — refs on frozen `EvidencePackage` do not change after construction.

### What `artifact_ref` does **not** mean

| Misinterpretation | Correction |
|-------------------|------------|
| Guaranteed filesystem path | Path semantics are **Future** quarantine layout (**SAFE UNKNOWN** filenames per N-07) |
| URI to live remote site | No network resolution in R2 model |
| Snapshot section path (`file-manifest/...`) | Snapshot paths are **R3** output |
| `evidence_id` or `snapshot_id` | Identity fields are separate blocks |
| Validation pass/fail | Validation is R2.4/R5 — ref is only a pointer |

### Examples (illustrative only)

| artifact_type | artifact_ref | status | Notes |
|---------------|--------------|--------|-------|
| `manifest` | `manifest:primary` | `present` | Mock R2.7: logical until quarantine write |
| `connector-output` | `connector-status:session` | `present` | Maps Connector Output status sidecar |
| `metadata` | `listing:summary` | `present` | Listing counts echo |
| `connector-output` | `bulk:export-root` | `unknown` | Bulk path not fixed until R2.5 |
| `safe-unknown` | `artifact:unresolved-class` | `unknown` | Honesty placeholder |

## Status Semantics

### Two status layers (no overlap)

| Layer | Field | Location | Allowed values | Semantics |
|-------|-------|----------|----------------|-----------|
| **Package** | `connector_status` | `EvidenceStatus` | `success`, `partial`, `failed` | Terminal **connector session** outcome per [EAR-CONNECTOR-CONTRACT-v1.md](../../shared/external-access-runtime/EAR-CONNECTOR-CONTRACT-v1.md) |
| **Artifact** | `status` | `EvidenceArtifact` | `present`, `missing`, `partial`, `skipped`, `unknown` | **Per-entry** availability / completeness |

**Overlap prevention:**

| Rule | Detail |
|------|--------|
| ART-ST-01 | `EvidenceArtifact.status` **must not** reuse `success` / `failed` as connector enums |
| ART-ST-02 | `connector_status: failed` may coexist with `artifact status: present` for salvageable partial artifacts |
| ART-ST-03 | `connector_status: success` does **not** require every artifact `present` — connector defines scope |
| ART-ST-04 | `package_quality_level` **forbidden** on artifact or index — snapshot/R5 only |
| ART-ST-05 | R2.4 validation pass **does not** imply snapshot quality or publish readiness |

### Per-artifact status meanings

| Status | Constant | Meaning |
|--------|----------|---------|
| **present** | `ARTIFACT_STATUS_PRESENT` | Entry logically available for Validate handoff |
| **missing** | `ARTIFACT_STATUS_MISSING` | Expected item not produced |
| **partial** | `ARTIFACT_STATUS_PARTIAL` | Incomplete item (truncated export, subset manifest) |
| **skipped** | `ARTIFACT_STATUS_SKIPPED` | Intentionally not collected (scope exclusion) |
| **unknown** | `ARTIFACT_STATUS_UNKNOWN` | Presence or shape not determined — honesty |

### Relationships

| Concern | Artifact status | Connector status | Validation (R2.4/R5) | Snapshot quality (R3/R5) |
|---------|-----------------|------------------|----------------------|---------------------------|
| Partial acquisition | `partial` / `missing` on entries | `partial` | R2.4 structural pass possible | Level 0 / `safe-unknown` until R3 |
| Failed leg | `missing` on leg artifacts | `failed` | R2.4 may fail or pass with honesty | No complete snapshot claim |
| Manifest only mock | `present` on manifest | `success` (mock) | R2.4 index checks | Still **Level 0** at Store |

## Validation (contract review)

**No runtime execution.** Structural chain verified against R2.1 model and `to_dict()` nesting:

```text
EvidenceArtifact
  artifact_type, artifact_ref, status
        ↓
EvidenceArtifactIndex
  artifact_count, artifacts[]
        ↓
EvidencePackage
  identity, provenance, scope_echo, artifact_index, status, warnings, errors
        ↓
to_dict() → nested plain dict (logging / future R2.4 schema checks)
```

| Check | Result |
|-------|--------|
| `EvidencePackage` includes `artifact_index` | **Yes** |
| Nested `to_dict()` keys | `artifact_index.artifacts[].{artifact_type, artifact_ref, status}` |
| Connector status separate | `status.connector_status` ≠ artifact `status` |
| Identity not duplicated in artifacts | **Yes** — identity block only |
| R1.6 mock pipeline uses index | **No** — flat counts until **R2.7** |
