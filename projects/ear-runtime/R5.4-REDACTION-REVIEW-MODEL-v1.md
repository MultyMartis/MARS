## Purpose

Define the canonical **Redaction Review** model — what kinds of **publication risks** R5 reviews and **how those risks are represented** — as frozen dataclass models in `runtime/shared/redaction_review_models.py`.

Representation contract only: no scanners, no detection logic, no Validate Engine, no R5-V-* rules, no Publish execution.

**Critical disambiguation (mandatory):**

| Concept | Owner | Meaning |
|---------|-------|---------|
| **R5 redaction review status** | **R5** | `CLEAR` / `REVIEW_REQUIRED` / `BLOCKED` — publication safety review outcome |
| **R5 ValidationResult status** | **R5** | `PASS` / `PASS_WITH_NOTES` / `FAIL` — aggregate EAR Validate outcome |
| **Publish gate** | **R4** + operator HITL | Consumer promotion — not redaction status |
| **Security incident status** | Operator / external IR | Not represented in this model |

**Rule:** Redaction findings **never store sensitive values** — no raw credentials, passwords, tokens, API keys, PII values, or filesystem dumps. Findings represent **risk**, not evidence content.

This milestone defines **what risks exist and how they are represented**. It does **not** define **how risks are detected**.

## Model hierarchy

```text
RedactionCategoryRegistry
└── categories[]                     → RedactionCategory
    ├── category_id                  → str (canonical constant)
    ├── title
    ├── purpose
    ├── ownership[]                  → what R5 owns for this risk class
    └── non_goals[]

RedactionCategoryReference           → lightweight pointer (category_id)

RedactionStatus                      → CLEAR | REVIEW_REQUIRED | BLOCKED
RedactionRecommendation              → NO_ACTION_REQUIRED | REDACT_BEFORE_PUBLISH | ...

RedactionFinding                     → single risk record (no sensitive values)
    ├── finding_id
    ├── category                     → RedactionCategoryReference
    ├── status                       → RedactionStatus
    ├── title
    ├── description                  → operator-facing; no secret/PII/path dumps
    └── recommendation               → RedactionRecommendation

RedactionReviewSummary
    ├── status                       → RedactionStatus
    ├── finding_count
    ├── blocked_count
    └── review_required_count

RedactionReview                      → aggregate R5 redaction review output
    ├── review_id
    ├── summary                      → RedactionReviewSummary
    ├── findings[]                   → RedactionFinding
    ├── audit                        → RedactionAudit | None
    └── recommendation               → RedactionRecommendation | None

RedactionAudit
    ├── reviewer_version
    ├── reviewed_at
    ├── reviewed_snapshot_id
    ├── operator_ref
    └── contract_ref
```

All types are **frozen** `@dataclass` instances. Immutable collections use `tuple`; `to_dict()` emits JSON-safe lists.

**Integration note:** `RedactionReview` is a standalone R5 artefact. Future R5.5/R5.7 may embed redaction findings into `ValidationResult` under `VALIDATION_CATEGORY_REDACTION` — no wiring at R5.4.

## Status semantics

R5 redaction review statuses — **not** Publish statuses; **not** security incident statuses.

| Constant | Value | Meaning |
|----------|-------|---------|
| `REDACTION_STATUS_CLEAR` | `CLEAR` | No publication risk identified at review scope — or all findings resolved |
| `REDACTION_STATUS_REVIEW_REQUIRED` | `REVIEW_REQUIRED` | Potential risk — operator review required before Publish recommendation |
| `REDACTION_STATUS_BLOCKED` | `BLOCKED` | Mandatory publication blocker — fail-closed on Validate (maps to `ValidationSeverity.BLOCKER` at R5.7) |

**Fail-closed policy (conceptual):** Mandatory redaction blockers (`BLOCKED` status on findings with `NOT_PUBLISHABLE` recommendation) must cause R5 Validate **FAIL** per R5.1 and R5 Charter — enforcement deferred to R5.7 Validate Engine.

## Recommendation semantics

R5 redaction recommendations — feed **R5 report only**.

| Constant | Value | Meaning |
|----------|-------|---------|
| `REDACTION_RECOMMENDATION_NO_ACTION_REQUIRED` | `NO_ACTION_REQUIRED` | No redaction action indicated at review scope |
| `REDACTION_RECOMMENDATION_REDACT_BEFORE_PUBLISH` | `REDACT_BEFORE_PUBLISH` | Content should be redacted before Publish recommendation |
| `REDACTION_RECOMMENDATION_OPERATOR_REVIEW_REQUIRED` | `OPERATOR_REVIEW_REQUIRED` | Human review required — inconclusive or policy-dependent |
| `REDACTION_RECOMMENDATION_NOT_PUBLISHABLE` | `NOT_PUBLISHABLE` | Must not proceed to Publish recommendation until resolved |

**Disambiguation:**

| Artefact | Relationship |
|----------|--------------|
| **RedactionRecommendation** | R5 redaction review output — **this model** |
| **ValidationRecommendation** (`ELIGIBLE` / `NOT_ELIGIBLE`) | R5 Publish Eligibility — **R5.6** |
| **R4 Publish decision** | Operator HITL + R4 execution — **not R5** |
| **Security incident action** | External IR — **not represented** |

Recommendation ≠ Publish decision. Recommendation ≠ security action.

## Ownership matrix

Classification: **R2** = evidence/quarantine; **R3** = assembly; **R5** = EAR Validate redaction review; **R4** = Publish.

| Concern | Owner | R5 redaction model role |
|---------|-------|-------------------------|
| Evidence quarantine layout policy | **R2** | Not represented — R5 reads candidate only |
| Pre-redaction secrets in quarantine | **R2** | Expected in quarantine — not R5 quarantine management |
| Quarantine persist / writes | **R2** | Not R5 |
| Assembly copy-avoidance (AR-R3-16) | **R3** | Precondition — R3 must not copy secrets |
| Candidate snapshot serialization review | **R5** — **this model** | **Authoritative representation** |
| Publication safety review | **R5** — **this model** | **Authoritative** |
| Credential exposure review | **R5** — **this model** | Findings without values |
| Unsafe publication review | **R5** — **this model** | Fail-closed blockers |
| Secret storage / rotation | **Not EAR R5** | Explicit non-goal |
| Security incident response | **Operator / external** | Explicit non-goal |
| Publish execution | **R4** | Reads R5 outcomes — does not perform redaction review |
| Automated redaction engine | **Future / operator** | Explicit non-goal |

### R5 owns (summary)

- Publication safety review on candidate snapshot
- Candidate snapshot publication risk review
- Credential exposure review (representation only)
- Unsafe publication review
- Redaction finding and review contracts

### R5 does NOT own

- Evidence quarantine management (**R2**)
- Snapshot assembly (**R3**)
- Publish execution (**R4**)
- Secret storage
- Credential rotation
- Security incident response

| Boundary | R2 / R3 role | R5 redaction model role | Invariant |
