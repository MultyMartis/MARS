## Execution boundaries

| Boundary | Rule |
|----------|------|
| **Storage role** | **Store** stage only — stored-unpublished |
| **Physical root** | Default `C:\AI MARS STORAGE\ear\store\` — [R1.8C](R1.8C-PERSISTENCE-LAYOUT-CHARTER-v1.md) |
| **Git workspace** | **No** snapshot bulk writes under `C:\AI MARS\projects\ear-runtime\` |
| **Immutability** | Write-once per `snapshot_id`; corrections = new id |
| **Store ≠ Publish** | `publish_state` / metadata marks stored-only; consumers must not treat as published |
| **Mock honesty** | `package_quality_level` 0 or explicit mock; `safe-unknown` populated |
| **dry_run** | Default or required for first operator runs until explicit non-dry_run charter |
| **On-disk EAR root** | Operator creates `ear\` subtree — R1.8 may create **under** validated `output_root` only when implementation runs; R1.8D does not create folders |
| **Human gate** | [R1-IMPLEMENTATION-DECISION-v1.md](R1-IMPLEMENTATION-DECISION-v1.md) still applies to **live/network** code — does not block mock Store persist |

## Success criteria (R1.8 complete)

1. Mock pipeline persist produces chartered folder tree under validated `output_root` in **dry_run** and non-dry_run modes (non-dry_run requires operator external root ready).
2. Production `snapshot_id` format used at persist boundary; `snap-mock-*` rejected outside dry_run.
3. `metadata/` includes contract identity fields per R1.8B (minimum L0 set + `bulk_root` + stored-only publish state).
4. `safe-unknown/` documents all unimplemented OpenCart sections for declared quality level.
5. **No** writes to git repo for bulk; **no** writes to `ocpilot\` paths.
6. **No** network calls in default test run.
7. [EAR-RUNTIME-STATE.md](EAR-RUNTIME-STATE.md) marks persistence **IMPLEMENTED (mock Store)** or equivalent honest label.
8. Redaction / secret scan passes on written artefacts.

## Stop conditions (R1.8 must halt)

| # | Condition | Action |
|---|-----------|--------|
| 1 | `output_root` outside chartered `ear\` subtree without documented override | Fail closed |
| 2 | Attempt to write to git workspace bulk paths | Abort |
| 3 | Attempt to write OCPilot consumer paths at Store stage | Abort |
| 4 | `snap-mock-*` id in non-dry_run persist | Abort |
| 5 | Overwrite existing `{snapshot_id}` tree | Abort (immutability) |
| 6 | Missing `operator_approval_ref` / required config for persist mode | Fail closed |
| 7 | Live SFTP or PILOT execution requested inside R1.8 scope | Out of scope — stop and defer |
| 8 | Publish or `consumer_target` intake automation requested | Out of scope — stop |
