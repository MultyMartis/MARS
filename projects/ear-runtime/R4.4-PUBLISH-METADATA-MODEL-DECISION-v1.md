---

## Decision

| Field | Value |
|-------|-------|
| **Question** | Is the **R4.4 Publish Metadata Model** ready as the authoritative R4 publish metadata contract? |
| **Outcome** | **PASS WITH NOTES** |
| **Scope of pass** | Frozen dataclass hierarchy; `PublishMetadataRegistry` with five canonical fields and eight invariants; mandatory six-question answers; R2/R3/R5/R4 ownership review; Store vs Publish and validation/quality boundaries preserved |
| **Explicitly not passed by this decision** | Publish Engine; Store adapter; metadata disk encoding; acquisition-log writer; `PublishResult` (R4.5); quality freeze implementation on R4.1 |

---

## Rationale

1. **Registry scope correct** — Five canonical publication-fact fields (`published_at`, `published_by`, `consumer_target`, `publish_reason`, `publish_audit_ref`); quality and validation fields explicitly excluded per PM-INV-R4-04/05.
2. **Hierarchy complete** — `PublishMetadata`, `PublishMetadataReference`, `PublishMetadataAudit`, `PublishMetadataRegistry` with per-field specs and invariants.
3. **Assignment timing explicit** — All canonical fields absent pre-Publish; assigned once at Publish (PM-INV-R4-02).
4. **Store vs Publish preserved** — Store metadata ≠ publish metadata; G3 ≠ publication record (PM-INV-R4-07).
5. **Mandatory answers complete** — All six questions documented with authority citations.
6. **Ownership verified** — R4 owns publish metadata only; no absorption of R2 evidence, R3 content, R5 validation/quality.
7. **R4.1/R4.2/R4.3 alignment** — Field subset matches R4.1 `PublishedSnapshotMetadata`; present only when `publish_state: published`; `consumer_target` ≠ visibility (PM-INV-R4-06).

**PASS WITH NOTES** (not bare **PASS**): physical metadata encoding **SAFE UNKNOWN**; R4.1 aggregate not refactored to import R4.4 registry (alignment documented); `PublishMetadataAudit` persistence deferred R4.7.

**FAIL** would apply if registry included quality certification fields, ValidationResult embed, evidence metadata, or treated `consumer_target` as visibility grant — **none apply**.
