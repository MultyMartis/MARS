| Dimension | Finding | Evidence |

| **Excluded root id** | `evidence_id` **not** in architecture evidence identity | EAR-EVIDENCE-PACKAGE-v1 (no `evidence_id`); R2-IMPLEMENTATION-CHARTER — **SAFE UNKNOWN**; R2.1 explicit exclusion |

| **R2.1 model alignment** | `EvidenceIdentity` has exactly three `str` fields matching contract names | `evidence_package_models.py` L18–31; R2.1-EVIDENCE-PACKAGE-MODEL-v1.md § Identity model |
| **Legacy mock pipeline** | R1.6 `evidence_models.py` still uses `site_id` / `connector` — **not** contract identity | R1.6; R2.1 § Relationship to R1.6; unchanged by design until R2.7 |

**Assessment:** Identity **shape** is stable and contract-aligned at R2.1. **Binding rules** are authoritative in charters but **not yet implemented** in generator code — expected; owned by R2.7 with enforcement at R2.4.

## Traceability Chain

```text
R1.2 Operator JSON (R1.2-CONFIG-INPUT-MODEL-v1.md)
│  site_id ──────────────────────────────┐
│  connector ────────────────────────────┤
│  (no acquisition_id in JSON)           │
│  output_root, scope paths, pilot_id    │  runtime-only / scope / storage
└────────────────────────────────────────┘
                    │
                    ▼  Translation boundary (documented R1-CONTRACT-MAPPING-v1;
                    │                      implementation: R2.7 EvidencePackageGenerator)
                    │
        ┌───────────┴───────────┐
        │  acquisition_id       │  ← runtime session start (UUID or structured id;
        │                       │     mock persist today: build_mock_acquisition_id)
        │  site_ref             │  ← site_id
        │  connector_class      │  ← connector
        └───────────┬───────────┘
                    ▼
R2 Evidence Package — EvidenceIdentity (R2.1 evidence_package_models.py)
│  Frozen dataclass; to_dict() under package.identity
│  Sibling: provenance, scope_echo, artifact_index, status
└────────────────────────────────────────┘
                    │
                    ▼  Validate (R5 + human) — not R2.2 scope
                    │
R3 Snapshot Package — snapshot_id, package_quality_level, OpenCart sections
│  Store: {output_root}/{acquisition_id}/snapshots/{snapshot_id}/
│  Evidence quarantine sibling: .../evidence/ (R2.5)
└────────────────────────────────────────┘
```

| Step | Artefact | Identity carried |
|------|----------|------------------|
| 1 | `sample-r1-site-001.json` | `site_id`, `connector` |
| 2 | Connector Input (conceptual) | `acquisition_id`, `site_ref`, `connector_class` + scope, channel, … |
| 3 | Connector Output (conceptual) | Echo `acquisition_id`, `connector_class`; `evidence_package_ref` |
| 4 | `EvidencePackage.identity` | Same three fields (contract-aligned model) |
| 5 | Snapshot persist (R1.8 mock) | `acquisition_id` in layout/metadata — **correlation**, not `EvidenceIdentity` type |
| 6 | Snapshot package (R3+) | `snapshot_id` — **new** identity at Store boundary |

**Connector contract alignment:** EAR-CONNECTOR-CONTRACT-v1 requires `acquisition_id`, `site_ref`, `connector_class` on **Input** and echoes `acquisition_id`, `connector_class` on **Output**. Evidence package identity matches the Input/Output correlation triple — **evidence only**, no contradiction found.

## Identity Invariants

Authoritative rules for R2.3–R2.7 (derived from architecture + R2 charters; **not** new policy).

| ID | Invariant | Authority | R2.1 model support |
|----|-----------|-----------|-------------------|
| INV-01 | `acquisition_id`, `site_ref`, and `connector_class` are **required** and **non-empty** at evidence boundary | R2-CHARTER; R2-IMPLEMENTATION-CHARTER § Validation Boundary | Typed `str` fields — enforcement deferred to **R2.4** |
| INV-02 | Identity field set is **exactly** these three at evidence identity block — **no** `evidence_id`, **no** `site_id`, **no** `package_quality_level` | EAR-EVIDENCE-PACKAGE-v1; R2.1 exclusions | **Satisfied** in `EvidenceIdentity` |
| INV-03 | **`site_ref` ≠ `snapshot_id`** — snapshot id created at R3 Store boundary | R2-IMPLEMENTATION-CHARTER binding rule 3 | N/A at model layer — handoff rule |
| INV-04 | **One** primary `EvidencePackage` per connector run unless hybrid merge implemented (**Future**) | R2-IMPLEMENTATION-CHARTER binding rule 1; R2.8 | Documented — not coded |
| INV-05 | **`acquisition_id`** correlates evidence quarantine folder and snapshot folder under same `{output_root}/{acquisition_id}/` | R1.8C; R2-CHARTER quarantine | Layout chartered; evidence folder **not** written yet |
| INV-06 | Identity values are **immutable** after `EvidencePackage` construction | Frozen `@dataclass` pattern | **Satisfied** (`frozen=True`) |
| INV-07 | **Evidence Package identity ≠ Snapshot Package identity** — validation transforms evidence; does not rename package types | EAR-EVIDENCE-PACKAGE-v1; R2-CHARTER | **Satisfied** by separate models (R2.1 vs R1.7) |
| INV-08 | Partial acquisition (`connector_status: partial`) must **not** imply snapshot completeness — identity still required | R2-IMPLEMENTATION-CHARTER binding rule 5 | Status on `EvidenceStatus`, not identity |
| INV-09 | Config **`site_id` / `connector`** must not appear on R2 evidence identity — use mapped names only | R2.1; R1-CONTRACT-MAPPING | **Satisfied** on R2 model; R1.6 mock **violates** until R2.7 migration |

| **`acquisition_id` generation algorithm** | SAFE UNKNOWN at R1.8A | **Partially resolved for mock persist only** — `acq-mock-{site_id}-{source}`; **production/session algorithm still SAFE UNKNOWN** for live path | `persistence_contract.py` — mock helper only; R1-CONTRACT-MAPPING “UUID or structured id” |

It does **not** provide enough evidence to resolve `evidence_id`, hybrid merge identity extensions, or 1:N snapshot merge policy — those stay **SAFE UNKNOWN** or **Future** without invention.
