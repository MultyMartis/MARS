| Field | Value |
|-------|-------|
| **Question** | Is the **Evidence Quarantine Layout** — storage boundary, lifecycle, ownership, reference semantics, and invariants — **defined and contract-aligned** enough to proceed with R2.6+ and future quarantine persistence? |
| **Outcome** | **PASS WITH NOTES** |
| **Scope of pass** | Canonical layout `{output_root}/{acquisition_id}/evidence/` sibling to `snapshots/`; quarantine purpose; ownership matrix; lifecycle transitions Acquire→Archive; reference semantics; Q-INV-01–Q-INV-14; model implications (no code change) |
| **Explicitly not passed by this decision** | Quarantine writer; on-disk folder creation; exact index filenames; bulk subpaths; evidence checksum registry; automated retention; `EvidenceQuarantineLayout` code module |

---

## Rationale

1. **Authoritative layout exists** — [R1.8C-PERSISTENCE-LAYOUT-CHARTER-v1.md](R1.8C-PERSISTENCE-LAYOUT-CHARTER-v1.md) PC-04 defines `{acquisition_id}/evidence/` + `snapshots/{snapshot_id}/`; R2.5 consolidates without contradicting R1.8C, R2-CHARTER, or EAR-EVIDENCE-PACKAGE-v1.
2. **Separation enforced** — evidence ≠ snapshot, evidence not published, consumer never reads quarantine, PC-08 minimum retention — mapped to Q-INV-* without inventing new policy.
3. **Reference semantics aligned** — R2.3 `artifact_ref` rules extend to quarantine/storage/snapshot layers; identity drift prevention documented; no model change required.
4. **R2.4 boundary respected** — quarantine ref existence remains optional post-persist concern, not core R2 validator; R2-V-25 unchanged.
5. **No implementation scope creep** — review only; no generator, validator, persistence, filesystem, or snapshot changes.

**PASS WITH NOTES** (not bare **PASS**): quarantine **not persisted** (expected at this milestone); exact `evidence/` index filenames remain **SAFE UNKNOWN** (N-07); retention durations and checksum registry **SAFE UNKNOWN**; `EvidenceQuarantineLayout` code deferred to R2.7 prep.

**FAIL** would apply if quarantine path contradicted R1.8C, if evidence were assigned to consumer or git paths, if evidence/snapshot merge were permitted, or if ownership contradicted EAR-STORAGE-MODEL — **none apply**.
