## Rationale

1. **Distinct artefact** — Publish Eligibility Recommendation documented separately from `ValidationResult`, `ValidateReport`, and R4 Publish per N-R5-03, N-R5I-03, PE-INV-R5-01.
2. **Three states chartered** — ELIGIBLE, ELIGIBLE_WITH_NOTES, NOT_ELIGIBLE — each with meaning, ownership, ValidationResult relationship, publish implications, non-goals (SC-R5.6-01).
3. **Fail closed** — FAIL → NOT_ELIGIBLE default mapping documented (SC-R5.6-02; PE-MAP-R5-01).
4. **R5→R4 boundary clean** — Recommendation advises; R4 executes; HITL mandatory on all paths including ELIGIBLE (SC-R5.6-03, SC-R5.6-04).
5. **Contract fields reviewed** — All eight requested fields included with required/optional semantics; `validate_report_ref` optional; `validation_result_ref` mandatory.
6. **Upstream alignment** — R5.1 status/recommendation constants; R5.5 Readiness reference completion; R3.6 VB-R3-02 lifecycle; VAL-INV-02 preserved.
7. **Ownership clean** — No leakage into R4 Publish, R3 assembly, R2 evidence, or quality certification.

**PASS WITH NOTES** (not bare **PASS**): no dataclass module yet (deferred R5.7+); recommendation builder deferred R5.7; persistence and operator override audit schema **SAFE UNKNOWN**; PASS → ELIGIBLE downgrade edge policy deferred R5.7.

**FAIL** would apply if recommendation executed Publish, replaced ValidationResult, omitted mandatory states, or certified quality — **none apply**.
