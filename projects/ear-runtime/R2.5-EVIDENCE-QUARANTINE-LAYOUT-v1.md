## Purpose

Define the **canonical Evidence Quarantine layer** — storage boundary, lifecycle, ownership, reference semantics, and invariants — **before** Evidence Package Generator (R2.7) or quarantine persistence code is written.

R1.8C chartered `{output_root}/{acquisition_id}/evidence/` as a sibling to `snapshots/` but deferred on-disk evidence writes ([R1.8E-PERSISTENCE-DECISION-v1.md](R1.8E-PERSISTENCE-DECISION-v1.md)). R2.5 resolves **what quarantine means**, **how it relates to snapshot Store**, and **who may touch it** — using architecture evidence only.

**Explicit exclusions:** generator (R2.7), validator implementation (R2.4 code), quarantine writer, filesystem creation, snapshot changes, OpenCart sections, SITE-001, SFTP, acquisition, network.

## Purpose (quarantine layer)

### Why evidence exists separately from snapshot

| Reason | Evidence (quarantine) | Snapshot (Store) |
|--------|----------------------|------------------|
| **Contract stage** | Pre-contract acquisition-internal artefact | Post-Validate governed package |
| **Shape** | Connector-oriented blobs + logical index | OpenCart section tree per snapshot contract |
| **Completeness** | May be partial; honest `connector_status` | Gaps declared in `safe-unknown` at publish |
| **Secrets** | May exist pre-redaction in external quarantine only | Must not contain secrets at publish |
| **Quality** | Not certified — no `package_quality_level` | Quality level assigned at Validate/Publish |
| **Audience** | EAR Validation + operator inspection | Consumers (after Publish) |

Validation **transforms** evidence into snapshot sections ([EAR-EVIDENCE-PACKAGE-v1.md](../../shared/external-access-runtime/EAR-EVIDENCE-PACKAGE-v1.md)); it does **not** rename Evidence Package as Snapshot Package.

Physical separation enforces the logical boundary: `{acquisition_id}/evidence/` ≠ `{acquisition_id}/snapshots/{snapshot_id}/` ([R1.8C-PERSISTENCE-LAYOUT-CHARTER-v1.md](R1.8C-PERSISTENCE-LAYOUT-CHARTER-v1.md)).

### Why evidence is not published

| Rule | Source |
|------|--------|
| Publish promotes **snapshot** reference only | R2-CHARTER § Relationships; EAR-SNAPSHOT-PUBLISHING-v1 |
| Evidence is acquisition-internal until Validate transforms content | EAR-EVIDENCE-PACKAGE-v1 |
| Forbidden: publishing to consumer bulk without validation pass | EAR-EVIDENCE-PACKAGE-v1 forbidden rules |
| Consumer role = read-only **published** snapshot | EAR-STORAGE-MODEL-v1 § Consumer role |
| EAR Store paths ≠ OCPilot `project-sites\` at Store stage | R1.8C § OCPilot relationship |

### Why evidence is not consumer-facing

| Dimension | Quarantine | Consumer intake |
|-----------|------------|-----------------|
| **Producer** | Connector / EAR generator | EAR Publish (R4) |
| **Content** | Raw/semi-raw exports, pre-redaction bulk | Contract slice + vetted bulk refs |
| **EAR role** | Hold + index for Validate | Hand off published snapshot only |
| **Git** | External bulk only | Consumer repo rules |
| **Access** | Operator + EAR Validate | OCPilot etc. — **downstream of Publish** |

Consumers **must not** read quarantine directly ([R2-CHARTER-v1.md](R2-CHARTER-v1.md) § Ownership; [EAR-STORAGE-MODEL-v1.md](../../shared/external-access-runtime/EAR-STORAGE-MODEL-v1.md)).

### What problem quarantine solves

| Problem | Quarantine response |
|---------|---------------------|
| **Risk before consumer visibility** | Raw exports inspected in external area before snapshot assembly |
| **Pre-redaction holding** | Secrets may exist in quarantine only — never git-bound |
| **Bulk decoupled from repo** | Large downloads live external; package holds refs |
| **Partial acquisition honesty** | Failed/partial connector legs visible in evidence, not silent in snapshot |
| **Validate gate inputs** | EAR reads evidence + bulk refs; redaction enforced before consumer paths |
| **Path collision prevention** | Sibling layout prevents evidence tree merge into snapshot tree |

## Layout

### Canonical acquisition subtree (relationship only)

Physical root binding per R1.8C — **no directory creation in R2.5**.

```text
{output_root}/                          ← operator JSON; default ear\store\
    └── {acquisition_id}/               ← session correlation key
            ├── evidence/               ← Evidence Quarantine (R2.5 scope)
            └── snapshots/
                  └── {snapshot_id}/    ← Snapshot Store (R1.8 — frozen scope)
```

**Default full path (recommended, not created here):**

```text
C:\AI MARS STORAGE\ear\store\{acquisition_id}\evidence\
C:\AI MARS STORAGE\ear\store\{acquisition_id}\snapshots\{snapshot_id}\
```

### Layer roles under `evidence/`

| Layer | Purpose | Owner | Required? |
|-------|---------|-------|-------------|
| **Quarantine root** | Acquisition-internal pre-contract holding | Operator placement + EAR index writer (**Future** R2.7+) | **Yes** — path chartered |
| **Logical index record** | Serialized `EvidencePackage` or sidecar index pointing to bulk | EAR generator/writer (**Future**) | **Yes** — architecture requires artifact index |
| **Bulk payload subtree** | ZIP extracts, connector dumps, screenshots — channel-dependent | Operator external; refs in index | **Optional** — bulk refs optional per contract |
| **Secrets** | Credentials | **Forbidden** under evidence tree — operator `secrets/` outside snapshot | **Forbidden** |

**Explicit non-layout (out of R2.5):**

- OpenCart section folders — under `snapshots/{snapshot_id}/` only (**R3**)
- Consumer `project-sites\` — **R4** Publish
- Git workspace (`C:\AI MARS`) — **forbidden** for evidence bulk

### Relationship to Store

| Relation | Rule | Authority |
|----------|------|-----------|
| **Sibling** | `evidence/` and `snapshots/` share `{acquisition_id}/` only | R1.8C PC-04 |
| **No merge** | Evidence tree **must not** be copied or merged into snapshot tree | R2-CHARTER; R2-IMPLEMENTATION-CHARTER prohibitions |
| **No rename** | Evidence Package is **not** renamed as Snapshot Package | EAR-EVIDENCE-PACKAGE-v1 |
| **Correlation** | Same `acquisition_id` binds evidence session to future `snapshot_id`(s) | R2-IMPLEMENTATION-CHARTER § Identity Model |
| **1:N policy** | Multiple snapshots per acquisition | **SAFE UNKNOWN** — hybrid merge Future |
| **R1.8 scope** | Mock Store writes `snapshots/{snapshot_id}/` only — three JSON files | R1.8-PERSISTENCE-MODEL-v1 |

### Path composition (conceptual)

| Artefact | Conceptual path |
|----------|-----------------|
| Evidence quarantine root | `{output_root}/{acquisition_id}/evidence/` |
| Evidence bulk (optional) | Under quarantine root or opaque external ref — exact subpaths **SAFE UNKNOWN** |
| Stored snapshot | `{output_root}/{acquisition_id}/snapshots/{snapshot_id}/` |
| Snapshot `bulk_root` metadata | Opaque reference to snapshot root — **not** evidence quarantine path |

## Ownership

| Role | Owns | May read | May write | May publish | May archive |
|------|------|----------|-----------|-------------|-------------|
| **Operator** | External `C:\AI MARS STORAGE\ear\` subtree; placement policy; post-Publish evidence disposition | Quarantine + Store | Creates external folders; disposition after Store/Publish | **No** — Publish is R4 | **Yes** — archive/delete per PC-08 policy |
| **EAR (R2+ implementation)** | Index + refs under chartered `evidence/` path | Quarantine during Acquire/Validate | Writes evidence index and bulk refs (**Future** R2.7+); **never** git-bound secrets | **No** | **No** automate — operator policy |
| **Connector / Generator** | Connector output destined for quarantine | Session output | Emits artefacts into quarantine via generator (**Future** R2.7) | **No** | **No** |
| **R5 Validate + human HITL** | Validate-stage decisions | Evidence Package + quarantine bulk for redaction review | **No** quarantine writes — transforms to snapshot inputs | **No** | **No** |
| **R3 Snapshot Builder** | Candidate snapshot assembly | Evidence index refs for section expansion | **`snapshots/{snapshot_id}/` only** — not evidence | **No** | **No** |
| **R4 Publish** | Published snapshot reference | Stored snapshot | Consumer handoff refs | **Snapshot only** — not evidence | **No** |
| **Consumer (OCPilot, etc.)** | Consumer reports and analysis | **Published snapshot only** | Consumer-owned outputs | **No** | **No** |

**Authoritative prohibitions:**

- Consumer **never** reads quarantine directly
- EAR **must not** write evidence under git workspace or OCPilot `project-sites\`
- Evidence **must not** be published to consumer bulk

## Lifecycle

### Pipeline map (authoritative transitions)

```text
Acquire
    ↓  evidence created/updated; quarantine root logically bound to acquisition_id
Evidence (quarantine)
    ↓  R2 structural validation (Future R2.4 code); evidence survives
Validate
    ↓  R5 + human: read evidence; transform → candidate snapshot; redaction enforced
Snapshot
    ↓  R3 assembles sections; R1.8 Store persists under snapshots/{snapshot_id}/
Store
    ↓  snapshot immutable; evidence retained per PC-08 minimum
Publish
    ↓  snapshot reference to consumers only; evidence stays acquisition-internal
Consume
    ↓  consumers read published snapshot
Archive
    ↓  operator may archive evidence and/or snapshot tiers separately
```

### Phase table — evidence quarantine

| Phase | Quarantine state | Transition | Evidence fate | Snapshot fate |
|-------|------------------|------------|---------------|---------------|
| **Acquire** | Created/updated by connector or mock generator | Connector completes → evidence package + index | Bulk + index written (**Future** persist) | **Not created** by evidence stage |
| **Evidence (R2 boundary)** | Inspectable logical package; optional quarantine on disk | R2 validation pass → eligible for Validate handoff | **Survives** validation — not consumed/deleted | **Not written** by R2 |
| **Validate** | Read by EAR; mapped toward snapshot sections | Validate pass + redaction → R3 inputs | **Must retain** through Validate | Candidate assembly begins (**R3**) |
| **Store** | Sibling to new snapshot tree | Successful Store of derived snapshot | **Must retain** until Store succeeds (PC-08) | Immutable under `snapshots/{snapshot_id}/` |
| **Publish** | Unchanged path; not exposed | Publish records snapshot ref only | **Not published** | Consumer receives **published** snapshot ref |
| **Consume** | Operator/audit access only | N/A for consumers | Invisible to consumers | Consumers read snapshot |
| **Archive** | Operator policy | Post-Publish recommended | **May** archive or delete — operator | **May** move to `ear\archive\` — operator |

### Minimum retention (PC-08 — evidence only)

| Window | Rule |
|--------|------|
| Acquire → Validate | **MUST retain** |
| Validate pass → Store complete | **MUST retain** |
| Post-Store, pre-Publish | **MAY retain** — default **recommend retain** |
| Post-Publish | **MAY delete or archive** — operator; EAR does not automate |
| Fixed duration / legal hold | **SAFE UNKNOWN** |

**Critical invariant:** Evidence **must not** be deleted before Validate pass **and** successful Store of derived snapshot ([R1.8C-PERSISTENCE-LAYOUT-CHARTER-v1.md](R1.8C-PERSISTENCE-LAYOUT-CHARTER-v1.md) § PC-08).

### What does **not** happen at each transition

| Transition | Forbidden |
|------------|-----------|
| Evidence → Validate | Treating evidence pass as snapshot pass or Publish approval (VAL-INV-01, VAL-INV-02) |
| Validate → Snapshot | Renaming evidence tree as snapshot; merging trees |
| Snapshot → Store | Writing evidence content into snapshot JSON mock (R1.8 three-file scope) |
| Store → Publish | Publishing evidence bulk to consumer paths |
| Any | Deleting evidence before PC-08 minimum satisfied |

## Reference Semantics

### Reference layers (prevent identity drift)

| Layer | Identifier / ref | Scope | Mutable after package freeze? |
|-------|------------------|-------|-------------------------------|
| **Session identity** | `acquisition_id`, `site_ref`, `connector_class` | One acquisition folder | **No** — identity block authoritative |
| **Artifact index** | `artifact_ref` per entry | Unique within one `EvidencePackage` | **No** on frozen logical package; **Future** persist may map logical → storage-relative |
| **Quarantine storage** | Paths under `{output_root}/{acquisition_id}/evidence/` | External bulk + index | Written at persist (**Future**); not parsed at R2.1 model |
| **Snapshot identity** | `snapshot_id` | Under `snapshots/` | Created at **R3 Store** boundary — **≠** `acquisition_id` |
| **Snapshot storage** | `bulk_root` in snapshot metadata | Points to `{snapshot_id}` root | **≠** evidence quarantine root |
| **Publish reference** | Consumer-visible ref | Published snapshot only | **No** evidence refs |

### `artifact_ref` semantics (consolidated from R2.3)

| Meaning | Description |
|---------|-------------|
| **Logical reference** | Stable label within session (e.g. `manifest:primary`) — valid before quarantine persist |
| **Quarantine reference** | Opaque path or relative pointer under `evidence/` — assigned at persist (**Future** R2.7+) |
| **Future storage reference** | External bulk per EAR-STORAGE-MODEL — outside git |
| **Correlation key** | Join for warnings/errors and operator inspection — **not** `snapshot_id` |

**Rules (ART-INV + quarantine):**

1. **Opaque at model layer** — no parsing, normalization, or existence checks in R2.1/R2.4 ([R2.3](R2.3-EVIDENCE-ARTIFACT-INDEX-v1.md) Reference Rules).
2. **Unique within package** — ART-INV-04.
3. **Non-secret** — credentials forbidden in refs.
4. **Stable on frozen package** — logical refs do not change after `EvidencePackage` construction; persist layer may **add** storage mapping without altering logical identity fields.
5. **Not snapshot section paths** — `file-manifest/` etc. are R3 **output**, not evidence refs (ART-INV-07).
6. **Not `evidence_id` or `snapshot_id`** — separate identity blocks (R2.2 INV-02).
7. **Quarantine writer (**Future**)** may rewrite `artifact_ref` from logical to storage-relative — **no** `EvidencePackage` dataclass field addition required (R2.3: "may rewrite refs — no model change").

### Snapshot references vs evidence references

| Concern | Evidence ref | Snapshot ref |
|---------|--------------|----------------|
| **Points to** | Acquisition bulk + index | Governed snapshot root / sections |
| **Created by** | Connector + R2 generator | R3 Builder + R1.8 Store |
| **Consumed by** | R2 validator (shape), R5 Validate (content), R3 (expansion) | R5 Validate, R4 Publish, consumers |
| **Published** | **Never** | After R4 gate |
| **Identity key** | `acquisition_id` folder | `snapshot_id` folder |

**Drift prevention:**

- Do not store `snapshot_id` in evidence identity block
- Do not store evidence quarantine path as snapshot `bulk_root` without explicit R3 mapping charter
- `acquisition_id` correlates folders; `snapshot_id` identifies immutable Store target only
