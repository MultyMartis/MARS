## Summary

Snapshot Package data model, builder, and validator created. Runtime can transform a validated `EvidencePackage` into an in-memory `SnapshotPackage` using the mock pipeline only. No acquisition, persistence, hashing, publishing, or output files.

## SnapshotPackage

| Field | Type | Notes |
|-------|------|-------|
| `snapshot_id` | `str` | Deterministic mock id: `snap-mock-{site_id}-{source}` |
| `site_id` | `str` | From evidence package |
| `source` | `str` | From evidence package |
| `connector` | `str` | From evidence package |
| `quality_level` | `str` | From evidence package (mock pipeline: `"mock"`) |
| `entry_count` | `int` | From `evidence.manifest_entry_count`; must be >= 0 |
| `excluded_count` | `int` | From `evidence.manifest_excluded_count`; must be >= 0 |
| `created_from` | `str` | Mock pipeline: `"mock_evidence_package"` |
| `safe_unknown` | `list[str]` | Copied from evidence; empty at R1.7 |
| `notes` | `list[str]` | Copied from evidence; empty at R1.7 |

**Method:** `to_dict()` — plain dict serialization for logging and future persistence handoff.

No hash fields. No file content. No snapshot paths. No publish metadata.

| Check | Rule |
|-------|------|

| `site_id` | Non-empty string |
| `source` | Non-empty string |
| `connector` | Non-empty string |
| `quality_level` | Non-empty string |

## Mock snapshot pipeline

`SFTPConnector.build_mock_snapshot_package()`:

```text
build_mock_listing()
  → validate_listing_result()
  → build_manifest()
  → validate_manifest()
  → build_evidence_package()
  → validate_evidence_package()
  → build_snapshot_package()
  → validate_snapshot_package()
  → summary (no writes)
```

Same synthetic 12-entry mock as R1.4–R1.6 (2 excluded). No SITE-001 data.

## Limitations

| Limitation | Notes |
|------------|-------|
| Mock only | Snapshot built from mock listing → manifest → evidence only |
| No persistence | Snapshot package not written to disk |
| No publishing | Snapshot is not published; R4 ownership |
| No hashing | No file digests or content inspection |
| Deterministic mock id | Not a production `snapshot_id` format per architecture spec |
| Empty `safe_unknown` / `notes` | Lists exist but are not populated at R1.7 |
| Connector skeleton | `SFTPConnector` still `implementation_state: SKELETON` |
| CLI banner stale | Default banner still reports `Implemented: NONE` — deferred |
