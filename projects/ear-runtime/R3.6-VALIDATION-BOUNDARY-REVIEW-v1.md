## Purpose

Define the **exact boundary** between:

- **R3 Assembly Eligibility** — preconditions and post-assembly structural checks on **candidate** Snapshot Package integrity, and  
- **R5 EAR Validate** — snapshot contract certification, quality possession (L0–L3), redaction, publish readiness, and Validate report.

This review verifies that R3 owns only assembly eligibility, identity continuity, candidate package integrity, required section presence, and safe-unknown propagation — and does **not** own quality certification, consumer readiness, publish gates, or final validation reports.

**Explicit exclusions:** R5 Validate automation, R4 Publish, Store redesign, architecture redesign, normative schema generation.

## Terminology (mandatory disambiguation)

| Term | Program | Meaning |
|------|---------|---------|
| **R2 structural validation** | R2 | Evidence Package shape and honesty — `validate_contract_evidence_package()` |
| **R3 assembly eligibility** | R3 | Handoff preconditions + candidate SnapshotPackage structural integrity — **not** EAR Validate |
| **R5 EAR Validate** | R5 | Snapshot contract certification, quality possession, redaction, publish readiness — **future** |
| **R3 pass** | R3 | Candidate package structurally eligible for R5 input — **≠** R5 pass |
| **Assembly success** | R3 | Candidate sections populated per R3 rules — **≠** Publish approval |

Per N-R3-07: all R3 docs must disambiguate **R3 assembly eligibility** from **R5 EAR Validate**.

## Authoritative validation ownership

| Stage | Program | Validator (implemented) | Input artefact | Output meaning |
|-------|---------|-------------------------|----------------|----------------|
| **Evidence structural gate** | **R2** | `validate_contract_evidence_package()` | `EvidencePackage` | Evidence contract-shaped — safe for handoff |
| **Handoff eligibility** | **R3** | `is_handoff_eligible()` in `handoff_contract.py` | `EvidencePackage` + optional R2 result | Assembly **may proceed** — not snapshot certified |
| **Candidate assembly** | **R3** | `build_candidate_snapshot_package()` | R2 evidence + config | **Candidate** OpenCart section tree — unpublished |
| **Assembly eligibility (post-build)** | **R3** | `validate_candidate_snapshot_package()` | `SnapshotPackage` (+ optional evidence) | Candidate **structurally intact** — ready for R5 input |
| **EAR Validate** | **R5** | **NOT IMPLEMENTED** | Stored candidate + evidence chain | Quality certified; publish readiness per gates |
| **Publish** | **R4** | **NOT IMPLEMENTED** | Validated stored snapshot + HITL | Consumer-visible reference |

**Critical distinction:** R3 validates **candidate assembly integrity**. R5 validates **snapshot contract adequacy and quality possession**. R3 assembly pass ≠ R5 Validate pass (HO-INV-06).

## Store Boundary Review

### Three snapshot states (normative separation)

```text
Candidate Snapshot          Validated Snapshot           Published Snapshot
─────────────────          ──────────────────           ──────────────────
Owner: R3                  Owner: R5 (+ operator)       Owner: R4
Created: assembly          Created: Validate pass         Created: Publish + HITL
Quality: L0 default        Quality: L0–L3 certified       Quality: frozen published claim
Store: optional write      Store: same snapshot_id        Store: consumer reference
Path: …/snapshots/{id}/    Immutable id                   Citation key post-Publish
Consumer access: NO        Consumer access: NO            Consumer access: YES
Validate report: NO        Validate report: YES         Publish metadata: R4
```

### Current implementation separation

| Path | Model | Persist | Validation | Stage |
|------|-------|---------|------------|-------|
| `--contract-snapshot` | R3.1 `SnapshotPackage` | **None** (in-memory) | R3 `validate_candidate_snapshot_package()` | **Candidate** |
| `--mock-snapshot` / `--persist-mock-snapshot` | R1.7 `snapshot_models.SnapshotPackage` | R1.8 mock Store | R1.7 `snapshot_validator` | **Legacy mock** — not R3 contract |
| R5 Validate | R3.1 candidate read | Reads stored | **NOT IMPLEMENTED** | **Validated** (future) |
| R4 Publish | Validated read | Promotes reference | **NOT IMPLEMENTED** | **Published** (future) |

**Key invariant:** Candidate generation (`build_candidate_snapshot_package`) **≠** validated snapshot **≠** published snapshot. Contract path does not call `persist_mock_snapshot()` — Store interaction deferred.

**R1.8 Store note:** `snapshot_store.persist_mock_snapshot()` accepts R1.7 flat model only — R3 contract persist requires future adapter (SAFE UNKNOWN wiring).
