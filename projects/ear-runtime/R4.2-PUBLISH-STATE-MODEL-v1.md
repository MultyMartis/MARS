## Purpose

Define the canonical **Publish State Model** — authoritative R4 publish lifecycle semantics for snapshots from Store placement through archive. Frozen dataclass models in `runtime/shared/publish_state_models.py`.

Model layer only: no Publish Engine, no CLI, no persistence, no Store adapter, no state transition implementation.

**Critical disambiguation (mandatory):**

| Concept | Owner | In R4.2 registry? |
|---------|-------|-------------------|
| **candidate** (R3 assembly) | **R3** | **No** — pre-Validate; referenced only in forbidden transitions |
| **validated** (R5 certification marker) | **R5** | **No** — precondition; not a publish_state value |
| **stored_unpublished** | **R1.8 Store** placement; **R4** precondition | **Yes** |
| **published** | **R4** | **Yes** — R4 target state |
| **superseded** | **R4** records | **Yes** |
| **archived** | **Operator** retention; **R4** may emit pointer | **Yes** |

R4.2 registry covers **publish_state** values only — not R3 candidate states, not R5 validation markers, not evidence lifecycle.

## Model hierarchy

```text
PublishStateRegistry
├── states[]                     → PublishState
│   ├── stored_unpublished
│   ├── published
│   ├── superseded
│   └── archived
└── transitions[]                → PublishStateTransition
    ├── PST-R4-01  stored_unpublished → published      (allowed)
    ├── PST-R4-02  published → superseded                (allowed)
    ├── PST-R4-03  published → archived                (operator_policy)
    ├── PST-R4-04  superseded → archived               (operator_policy)
    ├── PST-R4-05  stored_unpublished → archived       (operator_policy)
    ├── PST-R4-F01 candidate → published               (forbidden)
    ├── PST-R4-F02 NOT_ELIGIBLE default block          (forbidden)
    ├── PST-R4-F03 published → stored_unpublished      (forbidden)
    └── PST-R4-F04 archived → published                (forbidden)

PublishStateReference            → lightweight state_id pointer
```

All types are **frozen** `@dataclass` instances. Registry lookup via `get(state_id)`, `transitions_from(state_id)`, and `to_dict()`.

## Canonical publish states

| State | Meaning | Consumer access | Owner | R4 role |
|-------|---------|-----------------|-------|---------|
| **stored_unpublished** | Validated snapshot immutably in Store; Publish not executed | **None** | **R1.8** Store | Precondition — G3 |
| **published** | Publish gate executed; metadata + visibility grant | **Allowed** — registered consumers | **R4** | Target state |
| **superseded** | Newer published snapshot active for site | **Historical cite only** | **R4** records | Supersession marker |
| **archived** | Retention tier; not active default | **Policy-dependent** | **Operator** | May emit pointer |

|-------|-------|-----------------|-------|

## Mandatory answers

### 1. What makes a snapshot stored_unpublished

A snapshot is **stored_unpublished** when **all** of the following are true:

| # | Condition | Owner |
|---|-----------|-------|
| 1 | R5 Validate completed — `ValidationResult` outcome is not FAIL (certification recorded) | **R5** |
| 2 | Immutable snapshot tree placed at R1.8 layout `{output_root}/{acquisition_id}/snapshots/{snapshot_id}/` **or** held in-memory post-Validate with equivalent bundle pending Store | **R1.8** / Store |
| 3 | `snapshot_id` assigned — production id; not `snap-mock-*` on production path | **R3.2** / Store |
| 4 | `publish_state` is **stored_unpublished** — R1.8B conceptual field (exact disk encoding **SAFE UNKNOWN**) | **Store** |
| 5 | **No** R4 Publish execution — no `published_at`, no consumer visibility grant | **R4** not yet executed |
| 6 | Gate G3 inputs satisfied — validated artefact exists for operator/EAR | Store precondition |

**Valid terminal state:** stored-unpublished may remain indefinitely without Publish per R1.8B — Store is terminal for R1.8 at this state.

### 2. What makes a snapshot published

A snapshot is **published** when **all** of the following are true:

| # | Condition | Owner |
|---|-----------|-------|
| 1 | Prior state was **stored_unpublished** (or combined Store+Publish satisfied both gate checklists) | Store → **R4** |
| 2 | R5 `ValidationResult` PASS or PASS WITH NOTES | **R5** precondition; R4 confirms |
| 3 | R5 `PublishEligibilityRecommendation` ELIGIBLE or ELIGIBLE WITH NOTES on default path | **R5** advisory; R4 gate |
| 4 | Operator **Publish HITL approval** — distinct from Validate sign-off | **Operator** |
| 5 | R4 Publish execution completes — `publish_state` → **published** | **R4** |
| 6 | `published_at`, `published_by`, `consumer_target` assigned | **R4** |
| 7 | Certified `package_quality_level` **frozen** from R5 — no inflation | **R4** freeze |
| 8 | Consumer visibility grant issued for registered `consumer_target` | **R4** |
| 9 | Gate G4 (Publish → Consume) satisfied | **R4** |

Same immutable OpenCart section tree as validated stored snapshot — plus publish metadata and visibility grant ([R4.1-PUBLISHED-SNAPSHOT-MODEL-v1.md](R4.1-PUBLISHED-SNAPSHOT-MODEL-v1.md)).

### 3. What makes a snapshot superseded

A snapshot is **superseded** when:

| # | Condition | Owner |
|---|-----------|-------|
| 1 | Snapshot was previously **published** for a `site_id` | Prior **R4** Publish |
| 2 | A **newer** R4 Publish for the **same site** succeeds — new `snapshot_id` becomes active consumer default | **R4** |
| 3 | Prior published snapshot `publish_state` transitions to **superseded** | **R4** records |
| 4 | Prior immutable tree and `snapshot_id` **retained** — not deleted | Architecture immutability |
| 5 | Prior snapshot **must not** appear as active consumer registry target (CB-R4-02) | Consumer policy |

Supersession automation — active default pointer per site — **SAFE UNKNOWN** at implementation layer.

### 4. What makes a snapshot archived

A snapshot is **archived** when:

| # | Condition | Owner |
|---|-----------|-------|
| 1 | Operator retention or archive policy applied | **Operator** |
| 2 | Snapshot moved to archive tier — from **published**, **superseded**, or **stored_unpublished** (never published) | **Operator** |
| 3 | R4 may record `publish_state: archived` marker | **R4** optional pointer |
| 4 | Snapshot **not** active publish or intake target | Retention semantics |
| 5 | Physical tree may remain for historical cite or re-tier per policy | **Operator** bulk |

Archive from stored-unpublished (never published) is **operator policy** — R1.8B G-07 **SAFE UNKNOWN** detail.

### 5. Why stored_unpublished is not consumer visible

| Reason | Authority |
|--------|-----------|
| **Audience separation** — Store audience is operator/EAR; consumer audience requires explicit Publish gate | R1.8B § Store vs Publish |
| **Architecture rule** — Consumers consume **published snapshots only** | EAR-SNAPSHOT-PUBLISHING-v1 |
| **Lifecycle** — Acquire → Validate → Store → **Publish** → Consume; Consume has no valid entry before Publish | EAR-SNAPSHOT-LIFECYCLE-v1 |
| **Secrets and certification risk** — Pre-Publish artefact lacks consumer visibility grant and publish metadata freeze | R4-CHARTER § Consumer Boundary |
| **Registry rule** — Unpublished stored snapshot **must not** appear in consumer registry as active (CB-R4-02) | R4-CHARTER |
| **Gate semantics** — G3 (Store) satisfied ≠ G4 (Publish → Consume) executed | EAR-READINESS-GATES-v1 |

stored_unpublished is **valid and complete** for Store — absence of consumer visibility is **by design**, not a defect.

### 6. Why superseded may remain historically valid

| Reason | Authority |
|--------|-----------|
| **Immutability** — Published `snapshot_id` is immutable consumer citation key; supersession changes **active default**, not id validity | R1.8B; R3.2 ID-R3-01 |
| **Audit trail** — Reports and consumer runs may cite the `snapshot_id` that was active at execution time | EAR-SNAPSHOT-PUBLISHING-v1 |
| **No deletion semantics** — Superseded retains full OpenCart tree; R4 does not mutate section content | R4.1 PS-INV-R4-03 |
| **Historical cite access** — Consumer access becomes **historical cite only** — not active intake default | R4-CHARTER publish state model |
| **Quality claim frozen** — Published quality claim at time of Publish remains honest record | R5.3 three-stage semantics |

Superseded ≠ invalid. Superseded = **no longer the active default** for new consumer intake on that site.

### 7. Why archived is not deletion

| Reason | Authority |
|--------|-----------|
| **Retention tier semantics** — Archive removes snapshot from **active** operator/consumer paths; does not imply physical erase | R1.8B § Archive implications |
| **Historical cite** — Published snapshots in archive tier **remain citeable** from reports | R1.8B |
| **Immutability preserved** — `snapshot_id` and tree write-once policy unchanged | R1.9 |
| **Operator policy** — Deletion vs re-tier vs cold storage is **operator** decision outside R4 | R1.8B G-07 |
| **R4 role limited** — R4 may emit archived `publish_state` pointer; R4 does not delete bulk | R4 scope |
| **Forbidden reactivation** — archived → published transition **forbidden** (PST-R4-F04); new acquisition required | PST-R4-F04 |

Archive is a **lifecycle marker and retention class**, not a delete operation.

## Store vs Publish distinction

| Dimension | **Store (stored_unpublished)** | **Publish (published)** |
|-----------|-------------------------------|-------------------------|
| **Purpose** | Immutable validated placement | Consumer visibility gate |
| **Audience** | Operator, EAR | Registered consumers |
| **Prerequisite** | R5 Validate pass | R5 bundle + Store + Publish HITL |
| **Consumer access** | **None** | **Required** for Consume |
| **Primary owner** | Operator bulk; EAR metadata | Operator HITL; **R4** publish metadata |
| **R1.8 scope** | **In scope** | **Out of scope** — R4 |
| **Quality action** | Records R5 certified level | **Freezes** certified level |

Per R1.8B Task 5: Store is **terminal for R1.8** at stored-unpublished; Publish is **R4** responsibility.

## Invariants (PSM-INV-R4)

| ID | Invariant |
|----|-----------|
| PSM-INV-R4-01 | R4 registry owns **publish_state** semantics only — not candidate, validated, or evidence states |
| PSM-INV-R4-02 | Consumer intake requires **published** state — stored_unpublished **must not** be consumer-visible (CB-R4-02) |
| PSM-INV-R4-03 | Publish gate is **not reversible** — published → stored_unpublished **forbidden** |
| PSM-INV-R4-04 | candidate → published **forbidden** — Validate bypass blocked |
| PSM-INV-R4-05 | NOT_ELIGIBLE blocks default stored_unpublished → published path (R5.6 PE-MAP-R5-01) |
| PSM-INV-R4-06 | Superseded retains historical validity — not deletion |
| PSM-INV-R4-07 | Archived is retention marker — not deletion; reactivation **forbidden** |
| PSM-INV-R4-08 | R4 does **not** own snapshot content, validation, quality certification, or evidence lifecycle |

## Ownership review (R2, R3, R5, R4)

| Concern | R2 | R3 | R5 | R4 |
|---------|----|----|----|----|
| Evidence / quarantine lifecycle | **Owns** | Reads | Reads (Validate) | **No role** |
| Candidate assembly state | — | **Owns** | — | **Not in registry** |
| Validated certification marker | — | — | **Owns** | Precondition only |
| Store placement (stored_unpublished) | — | Candidate write | Validated marker | **Precondition** |
| Publish execution (→ published) | — | — | **Forbidden** | **Owns** |
| Supersession marker | — | — | — | **Owns** record |
| Archive retention policy | — | — | — | Pointer only; **Operator owns** |
| Consumer visibility semantics | — | — | — | **Owns** state definitions |
| Quality certification | Forbidden | Placeholder | **Owns** | **Freeze at Publish only** |
| Validate / redaction lifecycle | Policy | Avoid copy | **Owns** | **No role** |

**Verified:** R4 owns publish state semantics and transitions into **published**, **superseded**, and publish-side **archived** markers. R4 does **not** own snapshot content, validation, quality certification, or evidence lifecycle.
