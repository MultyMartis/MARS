**Type:** Implementation milestone

## Purpose

First persistence implementation: **Store-only** placement of mock `SnapshotPackage` artefacts under operator `output_root`. No Publish, no live acquisition, no consumer intake.

---

## Pipeline

```
Mock Listing → Manifest → Evidence → SnapshotPackage
    → Persistence Layout → Validation → persist_mock_snapshot → EAR Store
```

---

## Persistence contract

**Module:** `runtime/shared/persistence_contract.py`

| Symbol | Role |
|--------|------|
| `STORE_STATE_STORED` | Stored lifecycle marker |
| `STORE_STATE_UNPUBLISHED` | Stored-unpublished (default mock Store) |
| `DEFAULT_SNAPSHOT_SOURCE` | Mock source label |
| `DEFAULT_CREATED_FROM` | Mock provenance label |
| `ALLOWED_STORE_STATES` | Valid store states |
| `EAR_BULK_ROOT` | Chartered `C:\AI MARS STORAGE\ear\` |
| `build_mock_acquisition_id()` | Deterministic `acq-mock-{site_id}-{source}` |
| `is_valid_store_state()` / `find_store_state_violation()` | Validation helpers (no IO) |

---

## Layout builder

**Module:** `runtime/builders/persistence_layout_builder.py`

Translates `SnapshotPackage` + config to:

| Key | Content |
|-----|---------|
| `metadata` | Contract identity, `bulk_root`, `store_state`, counts, config enrichment |
| `safe_unknown` | OpenCart-shaped entries for flat runtime topics + unpopulated sections |
| `acquisition_log` | `acquisition_id`, channel, pilot, mock persist mode |
| `paths` | `snapshot_dir`, three JSON target paths |

**Layout path:** `{output_root}/{acquisition_id}/snapshots/{snapshot_id}/`

No writes.

---

## Persistence validator

**Module:** `runtime/validators/persistence_validator.py`

Checks:

- `output_root` present in config and under `EAR_BULK_ROOT`
- `acquisition_id`, `snapshot_id`, `store_state` valid
- `paths` dict complete

Returns `{ "valid": bool, "errors": [...] }`. No writes.

## Store implementation

**Package:** `runtime/persistence/`

| File | Role |
|------|------|
| `snapshot_store.py` | `persist_mock_snapshot(snapshot_package, config)` |
| `README.md` | Scope and forbidden actions |

### Written files (only)

| File | Description |
|------|-------------|
| `metadata.json` | Store metadata + `store_state` / `publish_state` |
| `safe-unknown.json` | Honesty entries array |
| `acquisition-log.json` | Session audit stub |

### Store-only behavior

- Creates directory tree under validated `output_root` only
- **No** ZIP, **no** evidence quarantine writes in R1.8 minimal scope
- **No** overwrite if `{snapshot_id}` directory exists (fail closed)
- **No** network, paramiko, socket, SFTP

## CLI

**Flag:** `--persist-mock-snapshot`

```text
py -3 cli.py --config configs/sample-r1-site-001.json --persist-mock-snapshot
```

Prints: `snapshot_id`, `acquisition_id`, `output_root`, persisted paths, validation result.

---

## Safety guarantees

| Guarantee | Mechanism |
|-----------|-----------|
| No Publish | No publish module; `store_state` = stored-unpublished only |
| No OCPilot writes | `output_root` must resolve under `ear\`, not `ocpilot\` |
| No live acquisition | Mock pipeline only in connector method |
| No network | Standard library only; connector `NETWORK_ACCESS` unchanged |
| No overwrite | `snapshot_dir.exists()` → `PersistenceError` |
| Writes bounded | `snapshot_dir` must be under resolved `output_root` |

---

## Limitations

| Limitation | Notes |
|------------|-------|
| Mock ids only | `snap-mock-*`, `acq-mock-*` — production id generator deferred |
| Three JSON files only | Section folders not populated with per-section payloads |
| No evidence persist | `evidence/` path not written in R1.8 minimal scope |
| No Publish / R4 | Consumers must not intake stored-unpublished |
| `operator_approval_ref` | Mock placeholder string at persist boundary |
| Second persist same id | Fails by design (immutability) |

---

## Explicitly out of scope

- **Publish** / OCPilot / `project-sites\`
- **SITE-001** / **PILOT-001** live execution
- **SFTP** / SSH / FTP / paramiko / socket
- Live acquisition, WPilot, Factory
- ZIP packaging, checksum registry, WORM
