## Purpose

Define the canonical **Published Snapshot** contract — the consumer-visible promotion of a validated stored snapshot — as frozen dataclass models in `runtime/shared/published_snapshot_models.py`.

Model layer only: no Publish Engine, no CLI, no persistence, no Store adapter, no Publish execution.

**Critical disambiguation (mandatory):**

| Artefact | Stage | R4 PublishedSnapshot equivalent? |
|----------|-------|--------------------------------|
| **R3 candidate** | `SnapshotPackage` assembly output | **No** — uncertified; pre-Validate |
| **R5 validated** | Stored snapshot + `ValidationResult` | **No** — certification artefact; no consumer visibility |
| **R5 recommendation** | `PublishEligibilityRecommendation` / `ValidationRecommendation` | **No** — advisory gate input only |
| **R4 Published Snapshot** | `PublishedSnapshot` | **Yes** — promotion + metadata + visibility |
| **Consumer intake** | OCPilot Run 5 / consumer programs | **No** — post-R4 execution |

## Model hierarchy

```text
PublishedSnapshot
├── identity                     → PublishedSnapshotIdentity
│   ├── snapshot_id              (unchanged — consumer citation key)
│   ├── acquisition_id
│   ├── site_id
│   ├── snapshot_contract
│   └── parent_contract
├── snapshot                     → SnapshotPackage (read-only citation — R3/R5 frozen content)
├── publish_metadata             → PublishedSnapshotMetadata
│   ├── published_at             (R4 assigns)
│   ├── published_by             (R4 assigns)
│   ├── consumer_target          (R4 assigns)
│   ├── frozen_package_quality_level   (R5 certified — R4 freeze only)
│   └── quality_claim_stage      → "published"
├── publication                  → PublishedSnapshotPublication
│   ├── publish_state            → "published"
│   ├── operator_publish_approval_ref
│   ├── validation_result_ref    (opaque citation — NOT ValidationResult)
│   ├── publish_eligibility_at_gate   (opaque citation — NOT recommendation object)
│   ├── store_placement_ref      (R1.8B layout citation — Store read only)
│   ├── bulk_root                (unchanged from validated snapshot)
│   └── published_snapshot_ref   (optional consumer registry pointer)
└── consumer_visibility          → PublishedSnapshotConsumerVisibility
    ├── consumer_target
    ├── visibility_state         → "granted"
    ├── visibility_granted_at
    ├── intake_reference_key     (= snapshot_id)
    └── consumer_registry_pointer   (optional — SAFE UNKNOWN encoding)
```

All types are **frozen** `@dataclass` instances. Immutable collections use `tuple` in upstream models; `to_dict()` emits JSON-safe lists.

## Mandatory answers

### 1. What survives from validated snapshot

| Surviving element | Owner at source | R4 behaviour |
|-------------------|-----------------|--------------|
| `snapshot_id`, `acquisition_id`, `site_id`, contract refs | R3.2 identity | **Cited unchanged** on `PublishedSnapshotIdentity` |
| Full OpenCart section tree (`SnapshotPackage`) | R3 wrote; R5 certified freeze | **Embedded read-only** on `snapshot` — no mutation |
| `package_quality_level` on metadata | R5 certified value | **Frozen** as `frozen_package_quality_level` — semantic stage becomes `published` |
| `bulk_root` | Store / snapshot metadata | **Cited unchanged** on `publication.bulk_root` |
| `safe-unknown/`, `acquisition-log/`, all sections | R3/R5 | **Unchanged** inside cited `snapshot` |
| Evidence quarantine | R2 | **Not included** — never publish target |
| `ValidationResult` findings / audit | R5 | **Not embedded** — optional opaque `validation_result_ref` only |

### 2. What is added by Publish

| Added element | Model location | Owner |
|---------------|----------------|-------|
| `published_at`, `published_by`, `consumer_target` | `publish_metadata` | **R4** |
| Frozen published quality claim | `publish_metadata.frozen_package_quality_level` | **R4** freeze |
| `publish_state: published` | `publication` | **R4** |
| Operator Publish HITL ref | `publication.operator_publish_approval_ref` | **R4** records |
| Store placement citation | `publication.store_placement_ref` | **R4** cites R1.8B |
| Gate artefact citations | `validation_result_ref`, `publish_eligibility_at_gate` | **R4** records preconditions |
| Consumer visibility grant | `consumer_visibility` | **R4** |
| Optional registry pointer | `publication.published_snapshot_ref`, `consumer_registry_pointer` | **R4** — encoding **SAFE UNKNOWN** |

### 3. What Publish must never modify

| Forbidden mutation | Authority |
|--------------------|-----------|
| OpenCart section content | R3/R5 freeze; ST-R4-06 |
| `snapshot_id` reassignment | R3.2 ID-R3-01; PS-INV-R4-02 |
| Quality certification or upgrade | R5.3; Q-INV-R5-01; ST-IC-R4-05 |
| `ValidationResult` or recommendation artefacts | R5 ownership; PR-INV-R4-01 |
| Evidence Package / quarantine | R2; CB-R4-03 |
| Store layout redesign | R1.9 frozen |
| Consumer intake execution | Consumer programs |

### 4. Why snapshot_id remains unchanged

Per [R3.2-SNAPSHOT-IDENTITY-LAYER-v1.md](R3.2-SNAPSHOT-IDENTITY-LAYER-v1.md) and [R1.8B-SNAPSHOT-STORAGE-CONTRACT-v1.md](R1.8B-SNAPSHOT-STORAGE-CONTRACT-v1.md): `snapshot_id` is assigned once at R3 Store boundary and is the **immutable consumer citation key** through Validate and Publish. Publish is **promotion**, not a new assembly — corrections require new acquisition → new `snapshot_id`. R4 cites the same id on `PublishedSnapshotIdentity` and `consumer_visibility.intake_reference_key`.

### 5. Why quality remains unchanged

R5 **certifies** `certified_quality_level` at Validate ([R5.3-QUALITY-POSSESSION-MODEL-v1.md](R5.3-QUALITY-POSSESSION-MODEL-v1.md)). R4 **freezes** that value as `frozen_package_quality_level` with `quality_claim_stage: published` — same numeric level, third semantic stage. R4 must not upgrade, downgrade, or recompute possession (Q-INV-R5-01; ST-IC-R4-05). Inflation at Publish is **forbidden**.

### 6. Why publication creates visibility but not content

Publish answers: *may this validated snapshot become consumer-visible?* — not *what does the snapshot contain?* Content was assembled by **R3** and certified by **R5** before R4 executes. R4 adds metadata (`publish_metadata`), publication record (`publication`), and visibility grant (`consumer_visibility`) around an unchanged `snapshot` citation. Consumer programs own intake execution; R4 grants reference only (CB-R4-01–05).

## Relationship review

### snapshot_id

| Layer | Relationship |
|-------|--------------|
| R3.2 | Creates `snapshot_id` — immutable after assignment |
| R5 | Validates same `snapshot_id` — `ValidationAudit.validated_snapshot_id` |
| Store (R1.8B) | Tree keyed `{output_root}/{acquisition_id}/snapshots/{snapshot_id}/` |
| **R4** | **Cites** same `snapshot_id` — never reassigns |
| Consumer | Intake references published `snapshot_id` only (CB-R4-01) |

### certified_quality_level

| Layer | Field | Semantics |
|-------|-------|-----------|
| R3 candidate | `metadata.package_quality_level` | Placeholder L0 — uncertified |
| R5 certified | `ValidationSummary.certified_quality_level` | Possession-assessed claim |
| **R4 published** | `publish_metadata.frozen_package_quality_level` | Frozen copy — `quality_claim_stage: published` |

R4 model carries **no** certification logic — only the frozen int and stage marker.

### ValidationResult

| Rule | Detail |
|------|--------|
| **Not embedded** | `PublishedSnapshot` is not a `ValidationResult` |
| **Precondition citation** | `publication.validation_result_ref` — opaque id string |
| **R4 must not** | Re-run Validate, regenerate findings, or substitute outcomes |

### PublishEligibilityRecommendation

| Rule | Detail |
|------|--------|
| **Not embedded** | Recommendation ≠ Publish (PE-INV-R5-01) |
| **Gate citation** | `publication.publish_eligibility_at_gate` — value at Publish time |
| **R4 must not** | Emit recommendation or treat ELIGIBLE as auto-Publish |

### Store

| Dimension | **Store (R1.8)** | **Published Snapshot (R4)** |
|-----------|------------------|------------------------------|
| Purpose | Immutable validated placement | Consumer-visible promotion reference |
| Audience | Operator / EAR | Registered consumers |
| Content mutation | Write-once sections | **Read-only** citation |
| R4 writes | — | Publish metadata only (future adapter) |
| Citation | `store_placement_ref` | Points to frozen layout path |

Store is **precondition** (stored-unpublished); Publish is **R4 execution** (G3 → G4).

## Immutability invariants (PS-INV-R4)

| ID | Invariant |
|----|-----------|
| PS-INV-R4-01 | Published Snapshot is promotion — not new assembly |
| PS-INV-R4-02 | `snapshot_id` unchanged from validated stored snapshot |
| PS-INV-R4-03 | Section mutability forbidden at Publish — `snapshot` read-only |
| PS-INV-R4-04 | `frozen_package_quality_level` matches R5 certified — no inflation |
| PS-INV-R4-05 | `PublishedSnapshot` ≠ `ValidationResult` ≠ recommendation ≠ consumer object |

## Three-stage comparison

| Dimension | Candidate (R3) | Validated (R5) | Published (R4) |
|-----------|----------------|----------------|----------------|
| **Quality claim** | L0 placeholder | R5 certified L0–L3 | Frozen published claim |
| **Consumer access** | **No** | **No** | **Yes** (after visibility grant) |
| **Publish metadata** | Absent | Absent | **Present** |
| **Section mutability** | R3 wrote once | Frozen at Validate | Frozen — R4 read-only |
| **Validate bundle required** | No | Self | **Yes** — precondition citations |
| **Model type** | `SnapshotPackage` | Store + `ValidationResult` | `PublishedSnapshot` |

## Ownership review (R2, R3, R5, R4)

| Concern | R2 | R3 | R5 | R4 |
|---------|----|----|----|----|
| Evidence / quarantine | **Owns** | Reads | Reads (Validate) | **No access** as publish target |
| Snapshot section content | — | **Owns** write | Certifies freeze | **Read-only** cite |
| `snapshot_id` | — | **Owns** create | Cites | **Cites** — unchanged |
| Quality certification | Forbidden | Placeholder only | **Owns** | **Freeze only** |
| `ValidationResult` | — | — | **Owns** emit | **Cites** ref only |
| Publish recommendation | — | — | **Owns** emit | **Cites** gate value only |
| Store layout / persist | — | Candidate write | Validated marker | **Cites** placement |
| Publish metadata | — | — | — | **Owns** |
| Consumer visibility | — | — | — | **Owns** grant |
| Consumer intake | — | — | — | **Forbidden** — consumer programs |

**Verified:** R4 owns metadata and visibility. R4 does **not** own snapshot content, quality certification, validation outcomes, or evidence.
