## Model structure

```text
EvidencePackage
├── identity          → EvidenceIdentity
├── provenance        → EvidenceProvenance
├── scope_echo        → EvidenceScopeEcho
├── artifact_index    → EvidenceArtifactIndex
│   └── artifacts[]   → EvidenceArtifact
├── status            → EvidenceStatus
├── warnings          → list[str] (serialized from tuple)
└── errors            → list[str] (serialized from tuple)
```

All model types are **frozen** `@dataclass` instances. Each nested type exposes `to_dict()` for plain-dict serialization.

---

## Identity model (`EvidenceIdentity`)

| Field | Type | Notes |
|-------|------|-------|
| `acquisition_id` | `str` | Session correlation key |
| `site_ref` | `str` | Consumer registry site identity (maps from R1.2 `site_id` at boundary) |
| `connector_class` | `str` | Connector type (maps from R1.2 `connector`) |

**Explicit exclusions:**

- **No `evidence_id`** — not defined in EAR-EVIDENCE-PACKAGE-v1; **SAFE UNKNOWN** per R2 Implementation Charter.
- **No `site_id`** on this model — use `site_ref` per contract.

---

## Provenance model (`EvidenceProvenance`)

| Field | Type | Notes |
|-------|------|-------|
| `channel` | `str` | Acquisition channel label |
| `started_at` | `str` | ISO 8601 string — **no datetime parsing** |
| `completed_at` | `str` | ISO 8601 string — **no datetime parsing** |
| `operator_approval_ref` | `str` | Non-secret HITL / approval pointer |

---

## Scope echo model (`EvidenceScopeEcho`)

| Field | Type | Notes |
|-------|------|-------|
| `approved_scope` | `tuple[str, ...]` | Operator-approved paths/tables |
| `attempted_scope` | `tuple[str, ...]` | What connector actually tried |

Required at evidence boundary per EAR-EVIDENCE-PACKAGE-v1. Serialized as JSON-friendly lists in `to_dict()`.

---

## Artifact index model (`EvidenceArtifactIndex` / `EvidenceArtifact`)

| Field | Type | Notes |
|-------|------|-------|
| `artifact_count` | `int` | Logical count of indexed artifacts |
| `artifacts` | `tuple[EvidenceArtifact, ...]` | Ordered index entries |

**Artifact entry (`EvidenceArtifact`):**

| Field | Type | Notes |
|-------|------|-------|
| `artifact_type` | `str` | Logical type (e.g. manifest, export) |
| `artifact_ref` | `str` | Logical or external path ref — **no existence checks** |
| `status` | `str` | Per-artifact status label |

**Not in R2.1:** OpenCart `file-manifest/` section payloads, bulk quarantine writes, file hashing.

---

## Status model (`EvidenceStatus`)

| Field | Type | Allowed values |
|-------|------|----------------|
| `connector_status` | `str` | `success`, `partial`, `failed` |

Constants exported: `CONNECTOR_STATUS_SUCCESS`, `CONNECTOR_STATUS_PARTIAL`, `CONNECTOR_STATUS_FAILED`.

**Explicit exclusions:**

- **No `package_quality_level`** — snapshot/R5 concern only.
- **No snapshot quality fields** on evidence.

`warnings` and `errors` live on **`EvidencePackage`** (not nested under `EvidenceStatus`), per connector contract carriers at package level.

---

## Evidence package aggregate (`EvidencePackage`)

| Field | Type | Notes |
|-------|------|-------|
| `identity` | `EvidenceIdentity` | Required contract identity block |
| `provenance` | `EvidenceProvenance` | Required provenance block |
| `scope_echo` | `EvidenceScopeEcho` | Required scope echo |
| `artifact_index` | `EvidenceArtifactIndex` | Required artifact index |
| `status` | `EvidenceStatus` | Required connector status |
| `warnings` | `tuple[str, ...]` | When applicable |
| `errors` | `tuple[str, ...]` | When applicable |

**Method:** `to_dict()` — nested plain dict for logging and future R2.4+ validation.

**No validation logic** in R2.1 — structural checks deferred to R2.4.
