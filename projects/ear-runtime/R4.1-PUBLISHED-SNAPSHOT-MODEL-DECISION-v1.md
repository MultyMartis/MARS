---

## Rationale

1. **Distinct artefact** — `PublishedSnapshot` scoped to R4 promotion output; does not embed `ValidationResult`, `PublishEligibilityRecommendation`, or consumer intake objects per PS-INV-R4-05 and PR-INV-R4-01.
2. **Promotion not assembly** — `snapshot` field cites read-only `SnapshotPackage`; section mutation forbidden at model contract (SC-R4.1-01, PS-INV-R4-03).
3. **Identity continuity** — `PublishedSnapshotIdentity` preserves same `snapshot_id` as validated stored snapshot (SC-R4.1-02, PS-INV-R4-02).
4. **Quality freeze only** — `frozen_package_quality_level` with `quality_claim_stage: published`; no certification logic (SC-R4.1-04; Q-INV-R5-01).
5. **Store citation without ownership** — `store_placement_ref` cites R1.8B layout; R4 does not redesign Store (G-09).
6. **Visibility grant separate** — `PublishedSnapshotConsumerVisibility` models logical permission; not credential handoff or OCPilot execution.
7. **Serialization demonstrable** — `PublishedSnapshot(...)` → `to_dict()` → `json.dumps()` succeeds at model layer.

**PASS WITH NOTES** (not bare **PASS**): full `publish_state` lifecycle enum deferred R4.2; consumer registry pointer encoding **SAFE UNKNOWN**; Publish Engine and Store metadata write remain **NOT IMPLEMENTED**; gate citation fields are opaque strings — enforcement deferred R4.5/R4.7.

**FAIL** would apply if model embedded validation outcomes, certified quality, mutated sections, or conflated Store placement with Publish execution — **none apply**.
