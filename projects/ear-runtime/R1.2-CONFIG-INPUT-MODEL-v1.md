## Config fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `site_id` | string | yes | Site identifier (e.g. `SITE-001`) |
| `pilot_id` | string | yes | Pilot identifier (e.g. `PILOT-001`) |
| `track` | string | yes | Must equal `connected` |
| `mode` | string | yes | Must equal `mode_2` |
| `connector` | string | yes | Must equal `sftp_readonly` |
| `environment` | string | yes | Environment label (e.g. `TEST`) |
| `snapshot_target` | string | yes | Must equal `level_1` |
| `credential_ref` | string | yes | External reference label — **not resolved in R1.2** |
| `remote_root` | string | yes | Remote scope root — non-empty placeholder allowed |
| `allowed_paths` | list[string] | yes | Allowed path prefixes (may be empty) |
| `excluded_paths` | list[string] | yes | Excluded path patterns |
| `output_root` | string | yes | External output root — non-empty placeholder allowed |
| `dry_run` | boolean | yes | Must be `true` in R1.2 |

## Validation rules

| Rule | Behavior |
|------|----------|
| Required fields | All fields in schema must be present |
| `dry_run` | Must be JSON `true` — non-dry-run rejected |
| `connector` | Must equal `sftp_readonly` |
| `mode` | Must equal `mode_2` |
| `track` | Must equal `connected` |
| `snapshot_target` | Must equal `level_1` |
| `remote_root` | Non-empty string |
| `output_root` | Non-empty string |
| `credential_ref` | Non-empty; password-like patterns rejected |
| Path traversal | `..` rejected in `remote_root`, `output_root`, and list path entries |
| JSON shape | Root must be object; list fields must be lists of strings |
| Symlink configs | Config path symlinks rejected |

On failure: `ConfigValidationError` raised; CLI exits non-zero with message on stderr.

---

## Security rules

| Rule | Enforcement |
|------|-------------|
| No inline secrets in config | Password-like patterns in `credential_ref` rejected |
| No credential resolution | Loader reads JSON only — does not open external credential stores |
| No secrets in CLI output | `credential_ref` printed as `REDACTED` |
| No path traversal | `..` segments rejected in path fields |
| Symlink rejection | Config file path must not be a symlink |
| Sample fixtures | Committed samples use `SAFE_UNKNOWN_*` placeholders only |

---

## No-access guarantees

| Capability | R1.2 status |
|------------|-------------|
| SFTP / paramiko | **NOT USED** |
| SSH / FTP | **NOT USED** |
| Credential file reading | **NOT IMPLEMENTED** |
| Remote listing | **NOT IMPLEMENTED** |
| Output directory creation | **NOT IMPLEMENTED** |
| Manifest generation | **NOT IMPLEMENTED** |
| Evidence package | **NOT IMPLEMENTED** |
| Network access | **NONE** |

Config load is **local file read + validation only**.

## CLI behavior

**Without `--config`:** skeleton banner unchanged from R1.1.

**With `--config <path>`:**

```text
Config loaded:
  site_id: ...
  pilot_id: ...
  connector: ...
  mode: ...
  snapshot_target: ...
  dry_run: ...
  credential_ref: REDACTED
```

Exit `0` on valid config; non-zero on validation failure.
