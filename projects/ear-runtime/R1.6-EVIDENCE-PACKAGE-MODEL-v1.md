## Summary

Evidence Package data model, builder, and validator created. Runtime can transform a validated `Manifest` plus config into an in-memory `EvidencePackage` using the mock pipeline only. No acquisition, persistence, hashing, or output files.

## EvidencePackage

| Field | Type | Notes |
|-------|------|-------|
| `source` | `str` | Origin label (mock pipeline: `"mock"`) |
| `site_id` | `str` | From runtime config |
| `connector` | `str` | From runtime config |
| `manifest_entry_count` | `int` | Total manifest entries; must be >= 0 |
| `manifest_excluded_count` | `int` | Excluded manifest entries; must be >= 0 |
| `quality_level` | `str` | Mock pipeline: `"mock"` |
| `safe_unknown` | `list[str]` | Placeholder for unknowns; empty at R1.6 |
| `notes` | `list[str]` | Placeholder for notes; empty at R1.6 |

**Method:** `to_dict()` — plain dict serialization for logging and future snapshot handoff.

No hash fields. No file content. No snapshot paths.

| Mapping | Rule |
|---------|------|
| `Manifest.source` | → `EvidencePackage.source` |

| `Manifest.entry_count` | → `EvidencePackage.manifest_entry_count` |
| `Manifest.excluded_count` | → `EvidencePackage.manifest_excluded_count` |

## Evidence Validator

Module: `runtime/validators/evidence_validator.py`  
Function: `validate_evidence_package(evidence: EvidencePackage) -> dict`

| Check | Rule |
|-------|------|
| `source` | Non-empty string |
| `site_id` | Non-empty string |
| `connector` | Non-empty string |
| `manifest_entry_count` | Must be >= 0 |
| `manifest_excluded_count` | Must be >= 0 |
| `quality_level` | Non-empty string |
| `safe_unknown` | List must exist |
| `notes` | List must exist |

**Returns:** `{ "valid": bool, "errors": list[str] }`

No runtime execution. No remote access.

## Mock evidence pipeline

`SFTPConnector.build_mock_evidence_package()`:

```text
build_mock_listing()
  → validate_listing_result()
  → build_manifest()
  → validate_manifest()
  → build_evidence_package()
  → validate_evidence_package()
  → summary (no writes)
```

Same synthetic 12-entry mock as R1.4/R1.5 (2 excluded). No SITE-001 data.

```text

py -3 cli.py --config configs/sample-r1-site-001.json --mock-listing

```

`--mock-evidence` loads config, validates connector config, runs full mock pipeline through evidence package, prints counts and validation result. No files written.
