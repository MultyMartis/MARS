## Decision

| Field | Value |
|-------|-------|
| **Question** | Is the **R4.3 Consumer Visibility Model** ready as the authoritative R4 consumer visibility semantics contract? |
| **Outcome** | **PASS WITH NOTES** |
| **Scope of pass** | Frozen dataclass hierarchy; `ConsumerVisibilityRegistry` with four canonical visibility states, twelve rules, three targets; mandatory seven-question answers; R2/R3/R5/R4 ownership review; Store vs Visibility distinction preserved; publish_state mapping from R4.2 |
| **Explicitly not passed by this decision** | Publish Engine; consumer registry implementation; access control implementation; visibility grant emission; physical registry pointer write; OCPilot integration |

---

## Rationale

1. **Registry scope correct** — Four canonical visibility states (`not_visible`, `visible`, `restricted`, `historical`); orthogonal to but mapped from R4.2 `publish_state`.
2. **Rules explicit** — CB-R4-01–05 charter rules plus CV-R4-01–07 visibility invariants documented with publish dependency.
3. **Targets defined** — Operator, OCPilot, and registered_consumer audiences with allowed/forbidden access lists — intake execution deferred to consumer programs.
4. **Store vs Visibility preserved** — Store precondition (not_visible) distinct from Publish visibility grant (visible); G3 ≠ G4 explicit.
5. **Mandatory answers complete** — All seven questions documented with authority citations.
6. **Ownership verified** — R4 owns visibility semantics only; no absorption of R2 evidence, R3 content, R5 validation/quality, or consumer implementation.
7. **R4.1/R4.2 alignment** — `granted`/`none` grant markers map to `visible`/`not_visible`; `visibility_state_for_publish_state()` binds publish lifecycle.

**PASS WITH NOTES** (not bare **PASS**): consumer registry physical encoding **SAFE UNKNOWN**; access control enforcement deferred; active-default supersession automation **SAFE UNKNOWN**; R4.1 grant constants remain separate from canonical visibility state ids (mapping documented).

**FAIL** would apply if registry included quality certification, Validate execution, access control implementation, or evidence quarantine as consumer-visible — **none apply**.
