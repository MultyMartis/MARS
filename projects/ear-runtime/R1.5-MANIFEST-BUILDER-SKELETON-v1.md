## ManifestEntry

| Field | Type | Notes |
|-------|------|-------|
| `path` | `str` | Remote-relative path; must be non-empty |
| `entry_type` | `str` | `file` or `directory` |
| `excluded` | `bool` | Whether path is excluded from acquisition scope |

No `size`, `modified`, or hash fields at this phase.

---

## Manifest

| Field | Type | Notes |
|-------|------|-------|
| `source` | `str` | Origin label (mock pipeline: `"mock"`) |
| `entry_count` | `int` | Total entries; must equal `len(entries)` |
| `excluded_count` | `int` | Excluded entries; must match excluded flag count |
| `entries` | `list[ManifestEntry]` | Ordered manifest entries |

**Method:** `to_dict()` — plain dict serialization for logging and future evidence handoff.

---

## Manifest Builder

Module: `runtime/builders/manifest_builder.py`  
Function: `build_manifest(listing_result: ListingResult) -> Manifest`

| Mapping | Rule |
|---------|------|
| `ListingEntry.path` | → `ManifestEntry.path` |
| `ListingEntry.entry_type` | → `ManifestEntry.entry_type` |
| `ListingEntry.excluded` | → `ManifestEntry.excluded` |
| `ListingResult.source` | → `Manifest.source` |
| `ListingResult.entry_count` | → `Manifest.entry_count` |
| `ListingResult.excluded_count` | → `Manifest.excluded_count` |

No additional enrichment. No filesystem access. No hashing. No timestamps.

---

## Manifest Validator

Module: `runtime/validators/manifest_validator.py`  
Function: `validate_manifest(manifest: Manifest) -> dict`

| Check | Rule |
|-------|------|
| `source` | Non-empty string |
| `entries` | List must exist |
| `entry_type` | Must be `file` or `directory` |
| `path` | Non-empty string per entry |
| `entry_count` | Must equal `len(entries)` |
| `excluded_count` | Must equal count of entries with `excluded=True` |

**Returns:** `{ "valid": bool, "errors": list[str] }`

No runtime execution. No remote access.

py -3 cli.py --config configs/sample-r1-site-001.json --mock-listing

`--mock-manifest` loads config, validates connector config, builds mock listing → manifest, prints counts, first five paths, and validation result. No files written.

## Limitations

| Limitation | Notes |
|------------|-------|
| Mock only | Manifest built from mock listing only |
| No exclusion engine | `excluded` inherited from mock listing; config `excluded_paths` not applied |
| No persistence | Manifest not written to disk |
| No evidence package | Manifest is not packaged for R2 contracts |
| No hashing | No file digests or content inspection |
| Connector skeleton | `SFTPConnector` still `implementation_state: SKELETON` |
