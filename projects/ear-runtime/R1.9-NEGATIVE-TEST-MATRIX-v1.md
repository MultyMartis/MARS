# R1.9 — Negative Test Matrix v1

**Type:** Test design — **no** execution, **no** automation in R1.9  
**Phase:** R1.9 — Store Hardening & Immutability Verification  
**Date:** 2026-06-04  
**Subject:** Mock Store (`persist_mock_snapshot`)  
**Expected universal outcome:** **FAIL CLOSED** (no partial publish, no overwrite, no writes outside chartered bulk)

---

## Purpose

Define negative scenarios for Store hardening. Each case documents trigger, injection point, expected runtime behavior, and expected on-disk state. **No tests were executed** in R1.9.

---

## Legend

| Column | Meaning |
|--------|---------|
| **Trigger** | How the negative condition is introduced |
| **Gate** | First layer that should stop the operation |
| **Exception / return** | Observable failure mode |
| **On-disk** | Filesystem state after failure |

## Matrix

### NT-01 — Duplicate `snapshot_id`

| Field | Value |
|-------|-------|
| **Case** | Second `--persist-mock-snapshot` with unchanged config after successful first persist |
| **Trigger** | Same `snap-mock-SITE-001-mock` under same `output_root` |
| **Gate** | `snapshot_store.persist_mock_snapshot` — `snapshot_dir.exists()` |
| **Exception / return** | `PersistenceError`: `snapshot_id already exists (immutable store)`; connector `validation.valid: false`; CLI exit **1** |
| **On-disk** | First persist unchanged (three JSON files); **no** overwrite |
| **FAIL CLOSED** | **YES** (code evidence; execution deferred) |

---

### NT-02 — Missing / empty `acquisition_id` (layout)

| Field | Value |
|-------|-------|
| **Case** | Layout dict with `acquisition_id` missing, empty, or non-string |
| **Trigger** | Hypothetical tampered layout **or** future direct API call — normal CLI path always sets id via `build_mock_acquisition_id()` |
| **Gate** | `validate_persistence_layout` |
| **Exception / return** | `validation.valid: false`; error `acquisition_id must be a non-empty string`; store not called if connector validates first; direct `persist_mock_snapshot` → `PersistenceError` on validation |
| **On-disk** | **No** new writes |
| **FAIL CLOSED** | **YES** |

---

### NT-03 — Missing / empty `output_root` (config)

| Field | Value |
|-------|-------|
| **Case** | Config without `output_root` or empty string |
| **Trigger** | Invalid config JSON |
| **Gate** | `config_loader.load_config` — required field + non-empty string |
| **Exception / return** | `ConfigValidationError` before connector runs (CLI failure at load) |
| **On-disk** | **No** writes |
| **FAIL CLOSED** | **YES** |

**Note:** If `output_root` key removed **after** load but before layout (hypothetical), `build_persistence_layout` raises `KeyError` — **not** `PersistenceError`. Normal CLI path loads config once; classified as **SAFE UNKNOWN** for non-CLI callers.

### NT-07 — `snapshot_dir` resolves outside `output_root`

| Field | Value |
|-------|-------|
| **Case** | Tampered `paths.snapshot_dir` pointing outside resolved `output_root` while validator passes path string presence only |
| **Trigger** | Hypothetical bypass of layout builder (direct `persist_mock_snapshot` with crafted layout) — **not** possible via normal connector path which rebuilds layout internally |
| **Gate** | `snapshot_dir.resolve().relative_to(output_root)` in `snapshot_store` |
| **Exception / return** | `PersistenceError`: `snapshot_dir must resolve under configured output_root` |
| **On-disk** | **No** writes |
| **FAIL CLOSED** | **YES** (store boundary); **GAP** if only validator used without store boundary check |

### NT-08 — Corrupted / incomplete layout dict

| Field | Value |
|-------|-------|
| **Case** | Missing `paths`, missing `metadata` payload keys, wrong types |
| **Trigger** | Tampered layout |
| **Gate** | Validator (`paths` keys); store assumes `layout["metadata"]` etc. — missing keys → `KeyError` (**not** fail-closed typed error) |
| **Exception / return** | Validator catches incomplete `paths`; deeper corruption may raise **unhandled** exception |
| **On-disk** | **No** writes if validation fails first |
| **FAIL CLOSED** | **PARTIAL** — typed fail-closed for declared validator fields only |
