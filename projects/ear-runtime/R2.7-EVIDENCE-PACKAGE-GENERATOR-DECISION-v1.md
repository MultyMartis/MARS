## Rationale

1. **Contract-shaped output** — Builder emits R2.1 `EvidencePackage` with identity, provenance, scope echo, artifact index, and connector status per R2.1–R2.3 charters.
2. **Identity strategy unified** — `acq-mock-{site_id}-{source}` aligns evidence `acquisition_id` with mock persist helper (R-R2.2-04); no `evidence_id`.
3. **R2 validation boundary respected** — Validator implements structural R2-V-* checks only; no R5 quality, publish, or OpenCart section checks.
4. **Mock-first discipline** — No network, no I/O, no quarantine writes; parallel R1.6 `--mock-evidence` path unchanged.
5. **CLI demonstrable** — `--contract-evidence` returns identity, artifact count, connector_status, validation PASS.
