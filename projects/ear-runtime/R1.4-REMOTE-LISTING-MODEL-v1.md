## ListingEntry

| Field | Type | Notes |
|-------|------|-------|
| `path` | `str` | Remote-relative path; must be non-empty |
| `entry_type` | `str` | `file` or `directory` |
| `size` | `int \| None` | Byte size for files; `None` for directories in mock |
| `modified` | `str \| None` | ISO-8601 timestamp string in mock data |
| `excluded` | `bool` | Whether path matches exclusion policy |

---

## ListingResult

| Field | Type | Notes |
|-------|------|-------|
| `source` | `str` | Origin label (mock: `"mock"`) |
| `entry_count` | `int` | Total entries; must equal `len(entries)` |
| `excluded_count` | `int` | Excluded entries; must match excluded flag count |
| `entries` | `list[ListingEntry]` | Ordered listing entries |

**Method:** `to_dict()` — plain dict serialization for logging and future manifest handoff.

---

## Validator

Module: `runtime/shared/listing_validator.py`  
Function: `validate_listing_result(result: ListingResult) -> dict`

| Check | Rule |
|-------|------|
| `source` | Non-empty string |
| `entry_type` | Must be `file` or `directory` |
| `path` | Non-empty string per entry |
| `entry_count` | Must equal `len(entries)` |
| `excluded_count` | Must equal count of entries with `excluded=True` |

**Returns:** `{ "valid": bool, "errors": list[str] }`

No runtime execution. No remote access.
