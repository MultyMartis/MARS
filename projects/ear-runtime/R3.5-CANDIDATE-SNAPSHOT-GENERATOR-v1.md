## Summary

First R3 implementation milestone: contract-shaped **EvidencePackage** → **SnapshotPackage** candidate transformation in memory only. Mock-first path from Config → R2 evidence → R3 candidate snapshot → R3 structural validation → CLI summary. ## Identity Generation

| Field | Source | Rule |
|-------|--------|------|
| `snapshot_id` | R3 created | Mock: `snap-mock-{site_id}-{connector_class}` via `build_mock_snapshot_id()` |
| `acquisition_id` | Evidence identity | **Survives** unchanged (ID-CONT-01) |
| `site_id` | Evidence `site_ref` | 1:1 value rename via `transform_site_ref_to_site_id()` (ID-CONT-02) |
| `snapshot_contract` | R3 created | Constant `ear-opencart-snapshot-v1` |
| `metadata.parent_contract` | R3 created | Constant `ear-snapshot-v1` |

**Production algorithm:** `PRODUCTION_SNAPSHOT_ID_ALGORITHM = "SAFE_UNKNOWN"` — not implemented at R3.5.

**Mock boundary:** Mock ids forbidden in production Store or Publish paths (ID-R3-14).

## Assembly Strategy

Minimal L0/L1 candidate assembly per R3.3 matrix — evidence echoes only; no quarantine bulk read.

| Section | Assembly approach |
|---------|-------------------|
| `metadata/` | Provenance + scope echo + config echo; `package_quality_level: 0` |
| `environment/` | Config `environment` → enum; fallback `UNKNOWN` |
| `acquisition-log/` | Provenance + identity + scope echo; `partial_run` from connector status |
| `file-manifest/` | Empty — manifest ref not expanded at R3.5 |
| `theme-info/` | Empty — no metadata expansion |
| `database-metadata/` | Empty — SFTP-only mock path |
| `seo-structure/` | Empty — no metadata expansion |
| `extension-inventory/` | Empty — L2+ deferred |
| `ocmod-inventory/` | Empty — L2+ deferred |
| `safe-unknown/` | Propagated per R3.4 matrix |

**Handoff gate:** `is_handoff_eligible()` requires non-empty identity + R2 structural pass before assembly.

## Safe Unknown Strategy

`SafeUnknownPropagator` logic in `snapshot_package_builder._propagate_safe_unknown()` — minimum entries:

| Topic | Trigger |
|-------|---------|
| `file-manifest` | Manifest ref not expanded / contract gap |
| `theme-info` | Section empty |
| `database-metadata` | Section empty (unsupported capability on SFTP mock) |
| `seo-structure` | Section empty |
| `extension-inventory` | L2+ deferred expansion |
| `ocmod-inventory` | L2+ deferred expansion |
| `partial_acquisition` | `connector_status: partial` |
| `acquisition_outcome` | `connector_status: failed` |
| `scope_echo` / `scope_delta` | Empty or mismatched scope echo |
| `acquisition-log` | `approved_at` derivation policy |
| `metadata.ear_mode` | When config lacks `ear_mode` and `mode` |

No fabricated section payloads. Candidate quality remains **0**.

---

## Validation Scope

`validate_candidate_snapshot_package()` — R3 structural checks only:

- Identity present (`snapshot_id`, `acquisition_id`, `site_id`, `snapshot_contract`)
- Acquisition continuity when evidence supplied
- Required sections present on aggregate
- `safe_unknown.entries` non-empty
- `package_quality_level == 0`
- Forbidden serialized keys scan

**Not validated:** R5 quality possession, publish gate, consumer outputs, filesystem existence.
