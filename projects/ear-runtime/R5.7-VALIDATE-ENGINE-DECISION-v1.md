## Rationale

1. **Orchestration-only scope** — Engine owns execution flow, dispatch, aggregation, emission — not quality concepts, categories, report sections, or recommendation semantics (VE-INV-R5-01; SC-R5.7-05).
2. **Inputs chartered** — Candidate Snapshot Package mandatory; R5.1–R5.6 contracts consumed; R2/R3 preconditions optional with fail-closed flags (SC-R5.7-01, SC-R5.7-03).
3. **Output bundle complete** — ValidationResult, ValidateReport, PublishEligibilityRecommendation, certified level, PossessionAssessmentRecord, RedactionReview with linkage invariants (SC-R5.7-02).
4. **Seven stages** — Preconditions → Category Evaluation → Quality Assessment → Redaction Review → Outcome Aggregation → Validate Report Assembly → Publish Recommendation Assembly (SC-R5.7-05).
5. **Category order** — Identity → Structure → Possession → Consistency → Quality → Redaction → Readiness; Quality after Possession; Readiness last before aggregation (SC-R5.7-06).
6. **Outcome mapping without scoring** — PASS / PASS_WITH_NOTES / FAIL principles; default recommendation mapping; fail closed on FAIL (SC-R5.7-07, SC-R5.7-08).
7. **Boundaries clean** — No Publish, snapshot mutation, evidence/quarantine/Store writes, acquisition, assembly, or HITL bypass (SC-R5.7-09).
8. **Upstream alignment** — R5.1–R5.6 contracts referenced; R3.6 VB-R3-01; R2.4 VAL-INV-01/02 preserved.
9. **Quality certification orchestrated** — Engine assigns certified level via Stage 3 using R5.3 registry — does not redefine L0–L3 concepts.

**PASS WITH NOTES** (not bare **PASS**): no implementation code (deferred post-R5.9); R3 assembly result required-vs-optional entry policy **SAFE UNKNOWN**; id generation and atomic bundle failure recovery **SAFE UNKNOWN**; Redaction dual-path (Stage 2 category + Stage 4 review) requires careful implementation to avoid drift; category parallelization **SAFE UNKNOWN**.

**FAIL** would apply if engine executed Publish, mutated snapshot, owned category/rule definitions, omitted mandatory candidate input, or bypassed HITL — **none apply**.
