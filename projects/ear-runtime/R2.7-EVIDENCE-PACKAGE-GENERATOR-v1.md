## Identity Strategy

| Field | Source | Rule |
|-------|--------|------|
| `acquisition_id` | Runtime-generated | `build_mock_evidence_acquisition_id(site_id, manifest.source)` → `acq-mock-{site_id}-{source}` via `build_mock_acquisition_id()` — unified with mock persist layout (R-R2.2-04) |
| `site_ref` | Config | 1:1 map from R1.2 `site_id` |
| `connector_class` | Config | 1:1 map from R1.2 `connector` |

**Explicit exclusions:**

- **No `evidence_id`** — SAFE UNKNOWN per charter; not introduced.
- **No `site_id` on R2 model** — contract rename at boundary only.

---

## Artifact Strategy

Minimum index per R2.3 taxonomy — logical refs only, no filesystem or quarantine paths:

| artifact_type | artifact_ref | status | Notes |
|---------------|--------------|--------|-------|
| `manifest` | `manifest:primary` | `present` | Required manifest-class entry (ART-INV-05) |
| `metadata` | `listing:summary` | `present` | Optional listing counts echo |

`artifact_count` equals `len(artifacts)`. No OpenCart section refs. No path existence checks.

---

## Provenance Strategy

Mock-safe fixed timestamps aligned with `mock_listing` convention:

- `channel` ← `manifest.source` (`mock`)
- `started_at` / `completed_at` ← fixed ISO strings (`2026-06-04T12:00:00Z` / `...01Z`)
- `operator_approval_ref` ← `pilot_id` from config, fallback `mock-operator-approval`

No datetime parsing or validation.

---

## Scope Echo Strategy

Config lacks explicit `approved_scope` / `attempted_scope` fields (R1.2 model):

| Field | Mapping |
|-------|---------|
| `approved_scope` | `allowed_paths` list → tuple |
| `attempted_scope` | `attempted_scope` config key if present; else `allowed_paths`; if empty → empty tuple + **SAFE UNKNOWN** warning |

Warnings emitted on package when mapping is implicit.

---

## Evidence Status Strategy

| Field | Source |
|-------|--------|
| `connector_status` | Mock connector metadata `connector_status`; default `success` |

Allowed: `success`, `partial`, `failed`. No `package_quality_level`. Package-level `warnings` / `errors` when applicable (`errors` non-empty when `failed`).

---

## Validation Scope

`validate_contract_evidence_package()` implements R2 structural checks only (R2.4 R2-V-* subset):

- Identity non-empty (R2-V-01)
- Provenance non-empty; `completed_at` when terminal (R2-V-03, R2-V-04)
- `artifact_count == len(artifacts)` (R2-V-09)
- Per-entry non-empty type/ref/status (R2-V-10)
- `artifact_ref` uniqueness (R2-V-11)
- ≥1 manifest-class entry (R2-V-12)
- Canonical `artifact_type` / artifact `status` enums (R2-V-13, R2-V-17, R2-V-18)
- `connector_status` enum (R2-V-16)
- No OpenCart section prefixes in refs (R2-V-14)
- Forbidden serialized keys scan (R2-V-02, R2-V-21)
- Credential heuristic on serialized strings (R2-V-24)
- `errors` required when `connector_status == failed` (R2-V-19)

**Not validated:** R5 quality, publish, OpenCart sections, filesystem existence, quarantine layout.

## CLI Flow

```text
--config PATH
    ↓
load_config
    ↓
mock listing → manifest
    ↓
build_contract_evidence_package(manifest, config, connector_metadata)
    ↓
validate_contract_evidence_package(package)
    ↓
summary (identity, artifact_count, connector_status, validation PASS/FAIL)
```

No writes. No persistence. No network.
