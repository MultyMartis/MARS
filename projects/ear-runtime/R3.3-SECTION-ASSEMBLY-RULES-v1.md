## Purpose

Define the **authoritative mapping contract** that specifies how a contract-shaped **Evidence Package** (R2) may populate **Snapshot Package** OpenCart sections (R3) — without implementing assembly.

This document establishes:

```text
Evidence (H-IN-01 … H-IN-10)
        ↓
Snapshot Section (metadata/, file-manifest/, …)
```

**Authority for downstream:**

| Milestone | Depends on R3.3 for |
|-----------|---------------------|
| **R3.4** Safe Unknown Propagation | Per-section gap triggers; fallback matrix |
| **R3.5** HandoffContract + Candidate Snapshot Generator | Section builder contracts; input/output mapping |

**Explicit exclusions:** generator, assembly execution, persistence, Store changes, Validate, Publish, OCPilot, SITE-001, network.

## HO-ALLOW / HO-FORBID review (Task 1)

### What R3 may transform

| Rule | R3 may | Evidence source | Snapshot target |
|------|--------|-----------------|-----------------|
| **HO-ALLOW-01** | Copy/transform provenance fields | `EvidenceProvenance` | `acquisition-log/` |
| **HO-ALLOW-02** | Echo identity + platform claims | `site_ref`, session context, config echo | `metadata/` |
| **HO-ALLOW-03** | Map scope delta to scope + gaps | `EvidenceScopeEcho` | `acquisition-log/` scope; `safe-unknown/` |
| **HO-ALLOW-04** | Surface connector outcome honestly | `EvidenceStatus`, `errors`, `warnings` | `safe-unknown/` |
| **HO-ALLOW-05** | Expand manifest ref into manifest section | `artifact_index` manifest entry + H-IN-08 bulk read | `file-manifest/` |
| **HO-ALLOW-06** | Expand listing/metadata refs into inventories | `artifact_index` metadata/log entries + bulk read | `extension-inventory/`, `database-metadata/`, `theme-info/`, `seo-structure/`, `ocmod-inventory/` |
| **HO-ALLOW-07** | Map config echo to environment | Scope + operator context | `environment/` |
| **HO-ALLOW-08** | Placeholder gaps in safe-unknown | Any assembly-detected gap | `safe-unknown/` |
| **HO-ALLOW-09** | Per-artifact missing/unknown → topics | `artifacts[].status` | `safe-unknown/` |
| **HO-ALLOW-10** | Read quarantine bulk **read-only** | H-IN-08 + `artifact_ref` | Section content population |

**Boundary:** Allowed transformations produce **candidate** sections only. R5 certifies possession and quality; R3 does not.

### What R3 may not transform

| Rule | R3 must not | Applies to |
|------|-------------|------------|
| **HO-FORBID-01** | Mutate frozen `EvidencePackage` after handoff | R3 consumers |
| **HO-FORBID-02** | Delete evidence as assembly condition | R3 consumers |
| **HO-FORBID-03** | Copy/move quarantine bulk into `snapshots/` as evidence-shaped tree | R3 assembly + Store |
| **HO-FORBID-04** | Rename Evidence Package as Snapshot Package | R3 output naming |
| **HO-FORBID-05** | Change `acquisition_id`, `site_ref`, `connector_class` | R3 transforms |
| **HO-FORBID-06** | Set `package_quality_level` ≥ 1 from evidence alone | R3 metadata |
| **HO-FORBID-07** | Expose quarantine to consumer paths | R3 `bulk_root`, refs |
| **HO-FORBID-08** | *(R2 only)* Write OpenCart sections during R2 | N/A at R3 |
| **HO-FORBID-09** | *(R2 only)* Write under `snapshots/` during R2 | N/A at R3 |
| **HO-FORBID-10** | Omit `safe-unknown` when sections empty due to partial/failed evidence | R3 assembly |
| **HO-FORBID-11** | Treat R2 pass as R5 Validate pass | R3 eligibility checks |
| **HO-FORBID-12** | Treat evidence pass as Publish approval | R3 output |
| **HO-FORBID-13** | Put snapshot section paths in evidence index | R3 must not write back to evidence |
| **HO-FORBID-14** | Alias evidence quarantine path as snapshot `bulk_root` | R3 metadata |
| **HO-FORBID-15** | Introduce `evidence_id` as correlation key | R3 identity/refs |

### Ambiguities documented

| ID | Topic | Ambiguity | R3.3 resolution |
|----|-------|-----------|-----------------|
| **AMB-R3.3-01** | HO-ALLOW-02 platform claims | Evidence may carry only operator declaration — corroboration deferred | Platform/version fields are **claims** on `metadata/`; `detected_version` only when manifest expansion provides version proof files (HO-ALLOW-05) |
| **AMB-R3.3-02** | HO-ALLOW-06 "etc." | Single metadata artifact may feed multiple sections | Per-section mapping matrix below assigns primary artifact types; one ref may expand to multiple sections **only** via distinct parsed content — not duplicate verbatim refs |
| **AMB-R3.3-03** | HO-ALLOW-07 environment | No dedicated `environment` block on `EvidencePackage` | `environment_class` from config echo (`ear_mode`, scope) + operator assertion; fallback `UNKNOWN` |
| **AMB-R3.3-04** | HO-ALLOW-10 vs HO-FORBID-03 | Both involve quarantine bulk | **Read + transform** into section-shaped content is allowed; **copy evidence tree shape** into `snapshots/` is forbidden |
| **AMB-R3.3-05** | `connector_class` vs `channel` | R3.2 defers merge rule | `acquisition_log.connector_class` = evidence value; `acquisition_log.channel` = `provenance.channel`; if equal, both populated; if channel empty, use `connector_class` as channel echo only when provenance lacks channel — **SAFE UNKNOWN** at R3.5 |
| **AMB-R3.3-06** | `approved_at` | No direct evidence field | Derive from `provenance.started_at` or leave empty with safe-unknown topic `acquisition-log` — **SAFE UNKNOWN**; R3.5 picks one policy |
| **AMB-R3.3-07** | Artifact type → section routing | R2.3 taxonomy is class-level only | Section mapping uses `artifact_type` + expansion parser — channel-specific filenames map at R2.7/R3.5, not in R3.3 |
| **AMB-R3.3-08** | Candidate vs certified quality | HO-FORBID-06 vs L1 section population | R3 **populates** L1-target sections where evidence permits; `package_quality_level` stays **0** until R5 certifies possession |

## Section mapping matrix (Task 3)

Normative mapping: Evidence handoff inputs → Snapshot section population.

**Handoff input key:** H-IN-01 = contract-shaped `EvidencePackage`; H-IN-08 = quarantine path binding.

### `metadata/`

| Field | Allowed evidence inputs | Forbidden inputs | Expected assembly result | Fallback behavior |
|-------|------------------------|------------------|--------------------------|-------------------|
| Identity echoes | H-IN-02 `site_ref` → `site_id`; H-IN-02 `acquisition_id`; R3-created `snapshot_id`, contracts | `site_ref` field name; evidence quarantine path as `bulk_root`; `package_quality_level` from evidence | Min L0 identity set + optional platform/version claims | Missing platform → empty claim + `safe-unknown` topic `metadata.platform` if L1 version proof required |
| Provenance echoes | H-IN-03 `operator_approval_ref`, timestamps, config `ear_mode` | `published_by`, `published_at` | `operator_approval`, `created_at`, `ear_mode`, `acquisition_date` | Missing `ear_mode` → safe-unknown `metadata.ear_mode` |
| Scope echo | H-IN-04 approved/attempted scope summary | Raw connector credentials | `acquisition_scope` string or tuple summary | Partial scope → scope string + HO-ALLOW-03 gaps |
| Manifest-derived | HO-ALLOW-05 version proof file parse | Fabricated version strings | `detected_version` when proof files present | No proof → `detected_version` empty + safe-unknown `live_version_proof` |
| Operator/config echo | R1.2 config platform claim, baseline refs | Secrets, API keys | `platform`, `version`, `baseline_candidate` as **claims** | Claims without corroboration remain claims; R5 validates |

## Assembly rules (Task 5)

Formal rules governing section assembly. Extends HO-ALLOW/HO-FORBID and R3.2 ID-R3-* for section scope.

| ID | Rule | Authority |
|----|------|-----------|
| **AR-R3-01** | **Identity continuity mandatory** — `acquisition_id` survives; `site_ref` → `site_id`; `snapshot_id` created at Store boundary only | R3.2 ID-CONT-01–02; HO-INV-04 |
| **AR-R3-02** | **No fabricated content** — assembly must not invent section payloads to avoid safe-unknown | HO-FORBID-10; SU-FORBID-02 |
| **AR-R3-03** | **Missing evidence → safe-unknown** — empty L1-target section without entry is a contract violation | HO-ALLOW-08; HO-FORBID-10 |
| **AR-R3-04** | **Evidence refs may expand into sections** — logical `artifact_ref` resolves via H-IN-08 read-only bulk; refs are not copied verbatim as section paths | HO-ALLOW-05/06/10; HO-INV-11 |
| **AR-R3-05** | **R3 may not assign certified quality** — `package_quality_level` default `0` at assembly; ≥1 only after R5 possession certification | HO-FORBID-06; HO-INV-08 |
| **AR-R3-06** | **Handoff inputs only** — assembly consumes H-IN-01–H-IN-10; no R5 reports, no publish metadata, no live credentials | R2.6 § Handoff inputs |
| **AR-R3-07** | **Invalid evidence blocks assembly** — R2 structural fail closed → no section population | HO-INV-13 |
| **AR-R3-08** | **Evidence remains read-only** — no mutation, deletion, or merge of evidence tree into snapshot Store | HO-FORBID-01/02/03; HO-INV-12 |
| **AR-R3-09** | **Quarantine read ≠ snapshot bulk_root** — H-IN-08 used for expansion only; snapshot `bulk_root` points to `snapshots/{snapshot_id}/` | HO-FORBID-14; ID-R3-02 |
| **AR-R3-10** | **Connector success ≠ section completeness** — `connector_status: success` does not suppress safe-unknown for missing L1 sections | HO-INV-09; SU-FORBID-03 |
| **AR-R3-11** | **Partial/failed runs surface honestly** — `connector_status: partial\|failed` yields safe-unknown topics; `acquisition_log.partial_run` set | HO-INV-10; HO-ALLOW-04 |
| **AR-R3-12** | **Scope delta explicit** — attempted ≠ approved scope produces acquisition-log scope tuples **and** safe-unknown entries | HO-ALLOW-03 |
| **AR-R3-13** | **Per-artifact status honored** — `artifacts[].status` of `unknown` or `missing` yields per-topic safe-unknown; not quality inflation | HO-ALLOW-09; ART-ST-05 |
| **AR-R3-14** | **Manifest ref ≠ file-manifest section** — index entry must be expanded; unexpanded ref is not a compliant section | HO-INV-11 |
| **AR-R3-15** | **Platform claims are claims** — metadata platform/version fields require corroboration for consumer trust; R3 records what evidence provides | EAR-OPENCART-SNAPSHOT-SPEC § metadata |
| **AR-R3-16** | **No secrets in sections** — credentials, API keys, connection strings forbidden in assembled sections | EAR-OPENCART-SNAPSHOT-SPEC; SU-FORBID-05 |
| **AR-R3-17** | **L2 sections not fabricated at L1** — `extension-inventory/` and `ocmod-inventory/` receive safe-unknown topics at R3 L1 scope, not fake extension rows | R3 Charter L1 target |
| **AR-R3-18** | **Assembly independent of Validate** — R3 produces candidate package; R5 Validate is separate read of evidence + candidate | HO-INV-05/06; VAL-INV-01 |
| **AR-R3-19** | **Assembly independent of Publish** — no publish approval fields; consumer paths forbidden pre-R4 | HO-FORBID-12; HO-FORBID-07 |
| **AR-R3-20** | **One assembly contract** — this document is normative for R3.5 HandoffContract section builders | R2.6 R-R2.6-06 |
| **AR-R3-21** | **metadata echoes snapshot_id** — OpenCart spec requires `snapshot_id` in metadata section serialization; value must match `SnapshotIdentity` | R3.2 FC-R3.2-05; EAR-OPENCART-SNAPSHOT-SPEC |
| **AR-R3-22** | **Environment fallback** — when environment not declared in evidence/config echo, `environment_class` = `UNKNOWN` | HO-ALLOW-07 |
| **AR-R3-23** | **No evidence_id correlation** — assembly must not introduce `evidence_id` keys | HO-FORBID-15; ID-R3-12 |
| **AR-R3-24** | **DB section schema-only** — `database-metadata/` must not contain row data or PII | EAR-OPENCART-SNAPSHOT-SPEC § database-metadata |
| **AR-R3-25** | **Quality level possession deferred** — populating L1 sections does not imply L1 quality claim; R5 maps possession per EAR-OPENCART-QUALITY-MAPPING | AMB-R3.3-08 |
