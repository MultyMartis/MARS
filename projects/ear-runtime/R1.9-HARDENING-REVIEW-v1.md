### What happens if…

#### Snapshot already exists

| Layer | Behavior |
|-------|----------|
| `snapshot_store` L47–50 | `PersistenceError` if `snapshot_dir.exists()` |
| `snapshot_store` L52 | `mkdir(..., exist_ok=False)` — second guard |
| `snapshot_store` L62–63 | Per-file `exists()` before each write |
| Connector | Catches `PersistenceError` → `validation.valid: false` |
| **Outcome** | **FAIL CLOSED** — no overwrite |

#### Acquisition missing

| Interpretation | Behavior |
|----------------|----------|
| Empty / invalid `acquisition_id` in layout | Validator error — persist blocked |
| No pre-existing `acquisition_id` directory required | Layout creates `{output_root}/{acquisition_id}/snapshots/...` on first persist — **not an error** |
| **Outcome** | **FAIL CLOSED** for invalid id; **N/A** for “folder must pre-exist” |

#### `output_root` invalid

| Condition | Gate | Outcome |
|-----------|------|---------|
| Missing at config load | `config_loader` required fields | `ConfigValidationError` |
| Empty string | `config_loader` + validator | Fail before store |
| Outside `ear\` | `output_root_under_ear_bulk` | Validation error |
| Contains `..` | `config_loader._reject_path_traversal` | `ConfigValidationError` |
| Missing key after load (hypothetical) | `build_persistence_layout` | `KeyError` — **not** `PersistenceError` |

#### Path traversal attempted

| Vector | Mitigation | Residual |
|--------|------------|----------|
| `..` in config `output_root` | Config loader reject | — |
| Resolved path outside `ear\` | Validator `relative_to(ear_root)` | Junction/symlink **SAFE UNKNOWN** |
| `snapshot_dir` outside `output_root` | Store `relative_to(output_root)` | — |
| `snapshot_id` / `acquisition_id` with `\` or `..` | **None** | Path shape drift under `output_root` (NT-11) |
| Tampered `paths` without store call | Validator checks non-empty strings only | Store boundary still required for write |

#### `store_state` invalid

| Layer | Behavior |
|-------|----------|
| `find_store_state_violation` | Rejects values outside `ALLOWED_STORE_STATES` |
| Mock layout | Always sets `STORE_STATE_UNPUBLISHED` |
| **Outcome** | **FAIL CLOSED** for invalid layout state |
