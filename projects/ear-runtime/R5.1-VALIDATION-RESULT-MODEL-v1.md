## Purpose

Define the canonical **ValidationResult** contract — the sole authoritative output of **R5 EAR Validate** — as frozen dataclass models in `runtime/shared/validation_result_models.py`.

Model layer only: no Validate Engine, no R5-V-* rules, no quality formulas, no Publish execution, no Store markers, no JSON Schema files.

**Critical disambiguation (mandatory):**

| Stage | Artefact | R5 PASS equivalent? |
|-------|----------|---------------------|
| **R2 structural validation** | `{valid, errors}` / future `EvidenceValidationResult` | **No** — R2 PASS ≠ R5 PASS (VAL-INV-01) |
| **R3 assembly eligibility** | `{valid, errors}` from `validate_candidate_snapshot_package()` | **No** — R3 PASS ≠ R5 PASS (VB-R3-01) |
| **R5 EAR Validate** | `ValidationResult` | **Yes** — authoritative R5 certification outcome |
| **R4 Publish** | Published snapshot reference | **No** — R5 PASS ≠ Publish approval (VAL-INV-02; VB-R3-02) |

## Model hierarchy

```text
ValidationResult
├── result_id
├── summary                    → ValidationSummary
│   ├── status                 → ValidationStatus
│   ├── finding_count
│   ├── blocker_count
│   ├── warning_count
│   └── certified_quality_level   (R5-owned field; no L0–L3 logic here)
├── findings[]                 → ValidationFinding
│   ├── finding_id
│   ├── category               → ValidationCategoryRef
│   ├── severity               → ValidationSeverity
│   ├── title
│   ├── description
│   └── recommendation         (operator guidance text — not Publish action)
├── audit                      → ValidationAudit (optional at model construction)
│   ├── validator_version
│   ├── validated_at
│   ├── validated_snapshot_id
│   ├── operator_ref
│   └── contract_ref
└── recommendation             → ValidationRecommendation (optional; advisory only)
```

All types are **frozen** `@dataclass` instances. Immutable collections use `tuple`; `to_dict()` emits JSON-safe lists.

## Status semantics (`ValidationStatus`)

Canonical R5 statuses only:

| Constant | Value | Meaning |
|----------|-------|---------|
| `VALIDATION_STATUS_PASS` | `PASS` | Mandatory category checks satisfied for certified level; no blockers |
| `VALIDATION_STATUS_PASS_WITH_NOTES` | `PASS_WITH_NOTES` | Certified level achievable; non-blocking warnings or downgrade notes |
| `VALIDATION_STATUS_FAIL` | `FAIL` | Mandatory blocker, contract breach, redaction failure, or precondition not met |

**Invariants:**

- R2 structural pass does **not** imply `PASS`.
- R3 assembly eligibility pass does **not** imply `PASS`.
- `PASS` or `PASS_WITH_NOTES` does **not** imply Publish approval — operator HITL mandatory (ST-R5-04).
- `FAIL` maps to `NOT_ELIGIBLE` recommendation by default (fail closed).

## Severity semantics (`ValidationSeverity`)

| Constant | Value | Use |
|----------|-------|-----|
| `VALIDATION_SEVERITY_INFO` | `INFO` | Informational note |
| `VALIDATION_SEVERITY_WARNING` | `WARNING` | Non-blocking concern |
| `VALIDATION_SEVERITY_ERROR` | `ERROR` | Significant defect — may contribute to FAIL |
| `VALIDATION_SEVERITY_BLOCKER` | `BLOCKER` | Mandatory blocker — typically forces FAIL |

No scoring. No weighting. No percentages.

## Recommendation semantics (`ValidationRecommendation`)

Publish Eligibility Recommendation — **advisory only**:

| Constant | Value | Typical `ValidationStatus` mapping |
|----------|-------|----------------------------------|
| `VALIDATION_RECOMMENDATION_ELIGIBLE` | `ELIGIBLE` | `PASS` |
| `VALIDATION_RECOMMENDATION_ELIGIBLE_WITH_NOTES` | `ELIGIBLE_WITH_NOTES` | `PASS_WITH_NOTES` |
| `VALIDATION_RECOMMENDATION_NOT_ELIGIBLE` | `NOT_ELIGIBLE` | `FAIL` |

**Recommendation ≠ Publish.** R5 emits recommendation; R4 executes Publish; operator HITL required on all paths before R4 acts (pilot).

## Finding contract (`ValidationFinding`)

| Field | Type | Notes |
|-------|------|-------|
| `finding_id` | `str` | Stable finding identifier within result |
| `category` | `ValidationCategoryRef` | One of seven R5 categories |
| `severity` | `ValidationSeverity` | INFO / WARNING / ERROR / BLOCKER |
| `title` | `str` | Short operator-facing title |
| `description` | `str` | Finding detail — no filesystem paths |
| `recommendation` | `str` | Operator guidance text — not a Publish action |

**Explicit exclusions from findings:** filesystem paths, credentials, raw secrets, publish actions.

---

## Summary contract (`ValidationSummary`)

| Field | Type | Notes |
|-------|------|-------|
| `status` | `ValidationStatus` | Aggregate R5 outcome |
| `finding_count` | `int` | Total findings |
| `blocker_count` | `int` | Findings at BLOCKER severity |
| `warning_count` | `int` | Findings at WARNING severity |
| `certified_quality_level` | `int \| None` | R5-certified L0–L3 — field only; **no certification logic** |

**Note:** R3 candidate `package_quality_level: 0` and R5 certified `0` share a numeric value but **different semantic stage** (VB-R3-06). R5 alone may assign certified level on Validate pass.

---

## Audit contract (`ValidationAudit`)

| Field | Type | Notes |
|-------|------|-------|
| `validator_version` | `str` | Validate tooling version label |
| `validated_at` | `str` | ISO 8601 timestamp (conventional) |
| `validated_snapshot_id` | `str` | Target candidate snapshot |
| `operator_ref` | `str` | Operator identity reference — not credential |
| `contract_ref` | `str` | Snapshot contract identifier (e.g. `ear-opencart-snapshot-v1`) |

No implementation logic. No Store writes.

## Ownership analysis

| Concern | Owner | R5.1 model role |
|---------|-------|-----------------|
| Evidence structural gate | **R2** | **Not represented** — precondition only at Validate entry (future R5.7) |
| Handoff / assembly eligibility | **R3** | **Not represented** — distinct `{valid, errors}` artefact |
| EAR Validate certification | **R5** | **`ValidationResult`** — authoritative |
| Certified `package_quality_level` | **R5** | Field on `ValidationSummary` — logic deferred R5.3+ |
| Publish Eligibility Recommendation | **R5** advises; **R4** decides | `ValidationRecommendation` — advisory |
| Publish execution | **R4** | **Forbidden** in model |
| Consumer readiness | **R5** + **R4** | **Not represented** as pass/fail in this artefact |
| Validate report (operator sections) | **R5** | **Separate artefact** — R5.5; not duplicated here |

## Serialization

Every model exposes `to_dict()` returning plain `dict` with stable snake_case keys. Nested models recurse via child `to_dict()`. Tuples serialize as lists. `None` allowed on optional fields.
