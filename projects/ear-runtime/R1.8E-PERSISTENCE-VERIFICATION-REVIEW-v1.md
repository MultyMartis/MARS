## Recommendations

1. **R1.9 (Dry-run local test):** Add automated check: second persist same `snapshot_id` → validation error; assert three files unchanged.
2. **Future section encoding:** When moving beyond R1.8 minimal, align on-disk layout with R1.8C section folders or document ZIP alternative (OQ-10).
3. **Honesty pass:** Add `environment` to `safe-unknown` entries if `environment/` folder not written, or populate `environment/` slice.
4. **Field normalization:** Map `operator_approval_ref` → `operator_approval` and `ear_mode` config → numeric contract values at a chartered boundary (not required for R1.8E pass).
5. **Evidence persist:** Charter `evidence/` under `{acquisition_id}` remains **deferred** — track under R2/R3, not R1.8E.
