## Purpose

Define the **authoritative handoff boundary** between:

- **R2 Evidence Package** — acquisition-internal, pre-contract artefact produced at Acquire, and  
- **R3 Snapshot Assembly** — OpenCart section population and candidate Snapshot Package creation at Validate/Store.

This document exists **before** any generator, snapshot builder, or handoff code is written. It specifies handoff inputs, outputs, ownership transfer, identity continuity, allowed and forbidden transformations, and invariants — using architecture evidence only.

**Explicit exclusions:** generator (R2.7), validator implementation, persistence, snapshot builder (R3), OpenCart section writers, SITE-001, SFTP, acquisition, network.

## Handoff purpose

### Why Evidence Package is not Snapshot

| Dimension | Evidence Package (R2) | Snapshot Package (R3+) | Authority |
|-----------|----------------------|------------------------|-----------|
| **Audience** | EAR Validation + operator inspection | Consumers (OCPilot, etc.) | EAR-EVIDENCE-PACKAGE-v1 § vs Snapshot Package |
| **Lifecycle stage** | Acquire → Validate input | Store → Publish → Consume → Archive | EAR-SNAPSHOT-LIFECYCLE-v1 |
| **Contract stage** | Pre-contract — may be partial | Post-Validate governed package | EAR-EVIDENCE-PACKAGE-v1 § Definition |
| **Shape** | Connector-oriented blobs + logical index | OpenCart section tree per spec | EAR-OPENCART-SNAPSHOT-SPEC-v1 |
| **Completeness** | Honest `connector_status`; partial allowed | Gaps declared in `safe-unknown` at publish | EAR-EVIDENCE-PACKAGE-v1 |
| **Quality** | **Not certified** — no `package_quality_level` | Quality level assigned at Validate/Publish | R2-CHARTER forbidden rules |
| **Secrets** | May exist pre-redaction in external quarantine | Must not contain secrets at publish | EAR-EVIDENCE-PACKAGE-v1 |
| **Storage** | `{acquisition_id}/evidence/` quarantine | `{acquisition_id}/snapshots/{snapshot_id}/` Store | R1.8C; R2.5 |
| **Immutability** | Working acquisition artefact | Published snapshot = point-in-time evidence | EAR-EVIDENCE-PACKAGE-v1 |

Validation **transforms** evidence into snapshot sections; it does **not** rename Evidence Package as Snapshot Package ([EAR-EVIDENCE-PACKAGE-v1.md](../../shared/external-access-runtime/EAR-EVIDENCE-PACKAGE-v1.md)).

### Why Snapshot cannot exist without handoff

| Reason | Detail |
|--------|--------|
| **Transformation boundary** | Snapshot sections are **derived** from validated evidence inputs — not from raw connector output alone |
| **Ownership separation** | Evidence quarantine and snapshot Store are **sibling trees** — no direct rename or merge |
| **Identity separation** | `snapshot_id` is created at R3 Store boundary — not present on evidence |
| **Quality gate** | Snapshot `package_quality_level` requires section possession — evidence carries connector outcome only |
| **Honesty preservation** | Partial/failed acquisition must flow into `safe-unknown` — handoff makes gaps explicit |
| **Consumer protection** | Consumers receive snapshot only — handoff forbids publishing evidence bulk |

Without a defined handoff, R3 would lack authoritative inputs, risk evidence/snapshot conflation (R1 mock pipeline gap), and could inflate quality or completeness claims.

### Why R3 depends on R2 output

| Dependency | R2 provides | R3 requires |
|------------|-------------|-------------|
| **Contract shape** | `EvidencePackage` aligned to EAR-EVIDENCE-PACKAGE-v1 | Stable logical inputs for section assembly |
| **Identity binding** | `acquisition_id`, `site_ref`, `connector_class` | Correlation to Store layout and `acquisition-log` |
| **Artifact index** | Logical refs to manifest, exports, bulk | Section expansion source pointers |
| **Scope echo** | Approved vs attempted scope | Honest `safe-unknown` and acquisition-log scope |
| **Connector status** | `success` / `partial` / `failed` + errors/warnings | Partial-run handling in snapshot |
| **Quarantine refs** | Paths under `{acquisition_id}/evidence/` | Bulk reads for manifest expansion — not consumer paths |
| **Validation eligibility** | R2 structural pass (when implemented) | Necessary precondition — **not sufficient** for snapshot quality |

Per backlog: **R1 → R2 → R3** — R3 Snapshot Builder is **blocked** on stable R2 evidence shape ([R2-CHARTER-v1.md](R2-CHARTER-v1.md) § R2 Boundaries).

### Authoritative input set (what R3 is allowed to receive)

R3 Snapshot Builder may consume **only** the following from the R2 handoff boundary:

| # | Handoff input | Source block / artefact | R3 use |
|---|---------------|-------------------------|--------|
| H-IN-01 | **Contract-shaped `EvidencePackage`** (logical) | R2.1 aggregate | Primary transformation source |
| H-IN-02 | **`EvidenceIdentity`** | `identity` — `acquisition_id`, `site_ref`, `connector_class` | Folder correlation; `acquisition-log`; metadata `site_id` mapping |
| H-IN-03 | **`EvidenceProvenance`** | `provenance` — `channel`, `started_at`, `completed_at`, `operator_approval_ref` | `acquisition-log` timestamps, channel, approval trace |
| H-IN-04 | **`EvidenceScopeEcho`** | `scope_echo` — approved vs attempted scope | `acquisition-log` scope; `safe-unknown` for scope gaps |
| H-IN-05 | **`EvidenceArtifactIndex`** | `artifact_index` + `artifacts[]` | Locate manifest, exports, listing summary, bulk refs |
| H-IN-06 | **`EvidenceStatus`** | `status.connector_status` | Partial-run handling; no silent completeness |
| H-IN-07 | **Errors and warnings** | `errors`, `warnings` tuples | `safe-unknown` topics; operator review |
| H-IN-08 | **Quarantine path binding** | Derived: `{output_root}/{acquisition_id}/evidence/` | External bulk reads for section expansion — **not** consumer paths |
| H-IN-09 | **R2 validation eligibility flag** | `EvidenceValidationResult` when R2.4 code exists | Gate: invalid evidence **must not** proceed to assembly — distinct from R5 pass |
| H-IN-10 | **This HandoffContract document** | R2.6 deliverable | Field-level mapping rules and prohibitions |

| Derived input | Derivation | Notes |
|---------------|------------|-------|
| Quarantine root path | `output_root` (R1.2 config) + `identity.acquisition_id` | R2.5 — no `quarantine_root` on model |

| Manifest logical ref | `artifact_index` entry with `artifact_type == manifest` | R2.3 ART-INV-05 |

### Explicit non-inputs (R3 must not treat as handoff)

| Artefact | Reason | Owner |
|----------|--------|-------|

| `snapshot_id`, `snapshot_version`, `snapshot_contract` | Created at R3 Store boundary | R3 |

| Consumer `project-sites\` paths | Publish handoff only | R4 |
| Live connector credentials | External secrets | Operator |
| R5 Validate report / Publish gate output | Post-assembly | R5 |

## Handoff outputs

### What R3 receives at the boundary

The handoff **does not transfer ownership of evidence**. R2/quarantine **retains** the Evidence Package and quarantine tree. R3 receives **authorized consumption rights** over a defined input bundle:

| # | Handoff output | Exact language | Meaning |
|---|----------------|----------------|---------|
| H-OUT-01 | **Snapshot Assembly Inputs** | Authorized input bundle for R3 Snapshot Builder | Logical `EvidencePackage` blocks H-IN-01–H-IN-08 plus eligibility flag H-IN-09 |
| H-OUT-02 | **Candidate Snapshot Assembly Mandate** | R3 may **read** evidence and quarantine bulk to **populate** OpenCart sections | Transformation authorization — not evidence ownership |
| H-OUT-03 | **Transformation Contract** | Field-level mapping rules (§ Allowed Transformations) | How evidence blocks become snapshot section inputs |
| H-OUT-04 | **Identity Continuity Record** | Correlation map: `acquisition_id` → future `snapshot_id` | Same session folder; new snapshot identity at Store |
| H-OUT-05 | **Honesty Carriers** | Partial status, scope delta, artifact statuses, warnings/errors | Must surface in `safe-unknown` / `acquisition-log` — not suppressed |

### What R3 creates (not handed off — R3 ownership)

| Output | Created by | Boundary |
|--------|------------|----------|
| **`snapshot_id`** | R3 at Store boundary | **New** identifier — ≠ `acquisition_id` |
| **Candidate Snapshot Package** | R3 Snapshot Builder | OpenCart sections per spec |
| **`package_quality_level`** (candidate) | R3 assembly + R5 certification | Starts Level 0 honest until R5 validates possession |
| **Snapshot `bulk_root`** | R3 Store persist | Points to `snapshots/{snapshot_id}/` — ≠ evidence quarantine |
| **OpenCart section trees** | R3 | Under `snapshots/{snapshot_id}/` only |

### Ownership transfer summary

| Asset | Before handoff (R2) | After handoff (R3+) |
|-------|---------------------|---------------------|
| Evidence Package logical record | R2 generator / quarantine index | **Retained** by R2 — R3/R5 **read-only** |
| Quarantine bulk under `evidence/` | Operator + EAR | **Retained** — PC-08 minimum |
| Snapshot sections under `snapshots/` | **Not created** | **R3 owns** write access |
| Consumer visibility | **None** | **R4 only** after Publish |

## Identity continuity

### Traceability chain

```text
R1.2 Config
│  site_id ──────────────────────────────┐
│  connector ────────────────────────────┤
│  output_root, scope, ear_mode          │
└────────────────────────────────────────┘
                    │
                    ▼  Runtime session start
            acquisition_id  ← NEW at session; binds folder
                    │
                    ▼  R2 Evidence Package
        EvidenceIdentity { acquisition_id, site_ref, connector_class }
        + provenance, scope_echo, artifact_index, status
                    │
                    ▼  R2.6 HANDOFF (read-only consumption)
                    │
                    ▼  R3 Snapshot Assembly
        snapshot_id  ← NEW at Store boundary
        site_id (from site_ref), snapshot_contract, package_quality_level
                    │
                    ▼  R1.8 Store
        {output_root}/{acquisition_id}/snapshots/{snapshot_id}/
```

### What survives (carried forward)

| Evidence field / concept | Snapshot destination | Rule |
|--------------------------|---------------------|------|
| `acquisition_id` | Folder correlation; optional `acquisition-log` reference | **Same value** — binds `{acquisition_id}/` tree |
| `site_ref` | Snapshot `site_id` / metadata Site ID | **Semantic carry** — rename at OpenCart contract boundary |
| `connector_class` | `acquisition-log` channel provenance | **Same value** — may combine with `channel` |
| `channel` | `acquisition-log` / metadata acquisition channel | **Same value** |
| `started_at`, `completed_at` | `acquisition-log` timestamps; metadata acquisition date | **Same values** — claim semantics apply at snapshot |
| `operator_approval_ref` | Snapshot `operator_approval`; `acquisition-log` approved_by | **Semantic carry** — distinct field names per contract |
| Approved / attempted scope | `acquisition-log` scope; metadata acquisition scope | **Transformed** — may become `safe-unknown` entries |
| `connector_status` | Informs `safe-unknown` — not copied as enum to snapshot root | **Honesty carrier** |
| Artifact index refs | Section expansion inputs (`file-manifest/`, etc.) | **Read and transform** — refs not copied verbatim as section paths |

### What changes (transformation — not identity mutation)

| Evidence | Snapshot | Transformation type |
|----------|----------|---------------------|
| `site_ref` | `site_id` | Field rename per OpenCart spec |
| `operator_approval_ref` | `operator_approval` | Field rename per snapshot contract |
| Logical `artifact_ref` | Section file paths / inventories | Expansion — ref → content |
| Connector-oriented index | OpenCart section tree | Structural transformation |
| Pre-redaction bulk | Redacted snapshot content | R5 Validate enforces redaction |

### What new identifiers appear

| Identifier | Appears at | Must not appear on |
|------------|------------|-------------------|
| **`snapshot_id`** | R3 Store boundary | Evidence identity block |
| **`snapshot_contract`** / `snapshot_version` | R3 candidate package | Evidence Package |
| **`package_quality_level`** | R3 assembly (candidate) + R5 certification | Evidence Package |
| **`bulk_root`** (snapshot) | Snapshot metadata | Evidence quarantine path — must not alias |

### Identity drift prevention rules

| ID | Rule | Authority |
|----|------|-----------|
| ID-DRIFT-01 | Do **not** store `snapshot_id` in evidence identity block | R2.2 INV-03; R2.5 Reference Semantics |
| ID-DRIFT-02 | Do **not** store `evidence_id` as package root — **SAFE UNKNOWN** | R2.2 INV-02 |
| ID-DRIFT-03 | `acquisition_id` **immutable** after `EvidencePackage` construction | R2.2 INV-06 |
| ID-DRIFT-04 | Evidence quarantine path **≠** snapshot `bulk_root` without explicit R3 mapping | R2.5 Reference Semantics |
| ID-DRIFT-05 | One primary evidence package per connector run unless hybrid (**Future** R2.8) | R2.2 INV-04 |
| ID-DRIFT-06 | 1:N `acquisition_id` → `snapshot_id` policy | **SAFE UNKNOWN** — each cycle gets new `snapshot_id` per lifecycle |

## Allowed transformations

Authoritative transformations R3 may perform **from** handoff inputs **to** snapshot sections. R2 **must not** perform these — R3 ownership only.

| ID | Transformation | Evidence source | Snapshot target | Notes |
|----|----------------|-----------------|-----------------|-------|
| HO-ALLOW-01 | Provenance → acquisition log | `EvidenceProvenance` | `acquisition-log/` section | Timestamps, channel, approval |
| HO-ALLOW-02 | Identity echo → metadata | `site_ref`, session context | `metadata/` site id, platform claims | Claims require corroboration |
| HO-ALLOW-03 | Scope echo → scope + safe-unknown | `EvidenceScopeEcho` | `acquisition-log` scope; `safe-unknown/` | Partial scope → explicit gaps |
| HO-ALLOW-04 | Connector status → safe-unknown | `EvidenceStatus`, `errors`, `warnings` | `safe-unknown/` entries | Failed/partial → honesty topics |
| HO-ALLOW-05 | Manifest ref → file-manifest expansion | `artifact_index` manifest entry | `file-manifest/` section | Reads quarantine bulk via H-IN-08 |
| HO-ALLOW-06 | Listing/metadata refs → inventories | `artifact_index` metadata/log entries | `extension-inventory/`, `database-metadata/`, etc. | Level-dependent — R5 validates possession |
| HO-ALLOW-07 | Config echo → environment | Scope + operator context | `environment/` section | Operator-recorded class |
| HO-ALLOW-08 | Missing data → safe-unknown placeholder | Any gap detected at assembly | `safe-unknown/` object list | Required per EAR-SNAPSHOT-CONTRACT-v1 |
| HO-ALLOW-09 | Artifact status `unknown`/`missing` → safe-unknown | Per-artifact `status` | `safe-unknown/` per topic | ART-ST-05 — not quality inflation |
| HO-ALLOW-10 | Quarantine bulk read | H-IN-08 path + `artifact_ref` | Section content population | **Read-only** from evidence tree |

**Boundary note:** Allowed transformations produce **candidate** snapshot sections. R5 Validate certifies contract, quality, and publish readiness — R3 assembly alone does not.

## Handoff invariants

Authoritative rules — derived from architecture + R2.1–R2.5; **not** new policy.

| ID | Invariant | Authority |
|----|-----------|-----------|
| **HO-INV-01** | **Evidence remains evidence** — handoff does not reclassify artefact type | EAR-EVIDENCE-PACKAGE-v1; VAL-INV-09 |
| **HO-INV-02** | **Snapshot remains derived artefact** — created by transformation, not rename | EAR-EVIDENCE-PACKAGE-v1 § vs Snapshot |
| **HO-INV-03** | **Evidence survives handoff** — quarantine retained through Validate and Store (PC-08) | Q-INV-03; Q-INV-08 |
| **HO-INV-04** | **Snapshot identity ≠ Evidence identity** — `snapshot_id` created at R3 Store; ≠ `acquisition_id` as package id | INV-03; INV-07 |
| **HO-INV-05** | **R2 pass ≠ R3 pass** — assembly may fail independently of evidence shape | VAL-INV-01 |
| **HO-INV-06** | **R2 pass ≠ R5 Validate pass** — evidence structural pass does not certify snapshot contract | VAL-INV-01; R-R2.4-08 |
| **HO-INV-07** | **R2 pass ≠ Publish approval** | VAL-INV-02 |
| **HO-INV-08** | **R2 pass ≠ quality level** — no `package_quality_level` from evidence | VAL-INV-03 |
| **HO-INV-09** | **`connector_status: success` ≠ snapshot completeness** | VAL-INV-05; ART-ST-03 |
| **HO-INV-10** | **`connector_status: partial\|failed` ≠ silent omission** — must surface in snapshot honesty | VAL-INV-06, VAL-INV-07 |
| **HO-INV-11** | **Manifest ref in index ≠ `file-manifest/` section** | VAL-INV-12; ART-ST-05 |
| **HO-INV-12** | **Handoff is read-only on evidence** — R3 reads; does not own quarantine | R2.5 Ownership matrix |
| **HO-INV-13** | **Invalid evidence blocks assembly** — R2 fail closed → no R3 handoff consume | VAL-INV-13 |
| **HO-INV-14** | **Mock Store Level 0 honest** until R3+R5 certify possession | HO-INV-08; R2-CHARTER SC-05 |
| **HO-INV-15** | **Consumer never receives quarantine refs** from handoff | Q-INV-05; HO-FORBID-07 |
