# Mobile-first indexing

Mobile-first indexing — подход Google Search, при котором для индексации и ранжирования Google преимущественно использует мобильную версию содержания сайта. Поэтому мобильный вариант должен содержать важную информацию и быть доступным для обхода.

<p>Если мобильная версия скрывает основной текст, ссылки, метаданные или структурированные данные, Google может не увидеть их так же, как на десктопе. На адаптивном сайте это обычно проще контролировать, поскольку URL и HTML общие.</p><h2>Что проверяют</h2><p>Проверяют доступность ресурсов, совпадение основного контента, корректное отображение на небольших экранах и отсутствие блокировки для Googlebot. Мобильная пригодность полезна прежде всего для реальных посетителей.</p><p>Mobile-first indexing не означает, что Google ранжирует только по «мобильной красоте»: оценка поиска учитывает множество сигналов и контекст запроса.</p><p>Для проверки удобно сравнить то, что получает мобильный пользователь и робот: основной текст, изображения с описаниями, ссылки, метаинформацию и структурированные данные. Отдельный мобильный URL требует особенно внимательной синхронизации вариантов. Адаптивная вёрстка уменьшает число расхождений, но не исключает их: важные блоки могут скрываться стилями или загружаться только после нестабильного скрипта.</p><p>Связанные понятия: Индексация; Техническая оптимизация; Core Web Vitals.</p>
