# UX и UI

UX и UI — связанные, но разные области проектирования цифрового продукта: UX описывает пользовательский опыт и логику пути, UI — визуальный интерфейс и элементы взаимодействия. Удобный интерфейс поддерживает сценарий пользователя, а не только выглядит аккуратно.

<p>UX включает понимание задач аудитории, структуру информации, навигацию, тексты, формы и последовательность действий. UI охватывает типографику, цвета, кнопки, состояния элементов и визуальную иерархию.</p><h2>Связь с сайтом и SEO</h2><p>Поисковая оптимизация не сводится к дизайну, но понятная структура и удобство на мобильных устройствах помогают посетителю работать со страницей. Полезно проверять реальные сценарии: поиск услуги, сравнение условий, отправку заявки.</p><p>Оценивать UX и UI стоит через наблюдения, доступность, аналитику и обратную связь, а не по одной метрике времени на сайте.</p><p>При проектировании интерфейса учитывают доступность: контраст текста, понятные подписи полей, управление с клавиатуры и сообщения об ошибках. Эстетичный UI не компенсирует запутанный путь, а хорошо продуманный UX нуждается в ясной визуальной подаче. Изменения разумно проверять на пользователях или сценарных тестах до того, как делать широкие выводы по агрегированной статистике.</p><p>Связанные понятия: Посадочная страница; Конверсия; Поведенческие факторы.</p>
