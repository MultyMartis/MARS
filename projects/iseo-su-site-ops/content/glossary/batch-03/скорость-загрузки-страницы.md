# Скорость загрузки страницы

Скорость загрузки страницы — насколько быстро пользователь получает полезное содержимое и может начать взаимодействие. В практике измеряют лабораторные и полевые метрики, а не одну субъективную оценку.

<p>На скорость влияют хостинг, размер ресурсов, скрипты, изображения, кеширование и сторонние виджеты. Для SEO и UX особенно важны показатели вроде LCP и задержек взаимодействия, описанные в экосистеме Core Web Vitals.</p><h2>Как подходить к улучшениям</h2><p>Сначала находят узкие места: тяжёлые медиа, блокирующий JS/CSS, медленный ответ сервера. Затем проверяют эффект на реальных устройствах и каналах, а не только в идеальном тесте.</p><p>Быстрая страница не заменяет релевантный контент, но снижает отказы и улучшает восприятие сервиса.</p><p>Связанные понятия: Core Web Vitals; UX и UI; CDN; Кеширование.</p>
