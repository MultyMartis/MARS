# Disavow

Disavow — инструмент Google Search Console, которым владелец сайта может пометить токсичные входящие ссылки как нежелательные для учёта. Это крайняя мера, а не ежедневная рутина.

<p>Сначала пытаются удалить вредные ссылки у вебмастеров-доноров. Disavow применяют при явной ссылочной атаке или наследстве спама, понимая риск ошибки в списке.</p><p>У Яндекса нет идентичного публичного «disavow» с тем же интерфейсом; переносить процесс один в один нельзя.</p><p>Связанные понятия: Ссылочный спам; Google Search Console; Google Penguin; Обратная ссылка.</p>
