# Донор ссылки

Донор ссылки — сайт или страница, с которых ведёт ссылка на ваш ресурс. Качество донора оценивают по тематике, аудитории и рискам спама — не только по красивой метрике.

<p>Слабый донор: автоматически сгенерированные сетки, нерелевантные каталоги, страницы без посетителей. Сильный — материал, который реально читают в вашей теме.</p><p>Связанные понятия: Акцептор ссылки; Обратная ссылка; Линкбилдинг.</p>
