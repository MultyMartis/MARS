# Пагинация

Пагинация — разбиение длинного списка на страницы: каталог, блог, результаты фильтра. Для SEO важно, чтобы робот понимал связь страниц и не индексировал бесконечные дубли параметров.

<p>Неудачная пагинация создаёт множество похожих URL с тонким контентом. Это усложняет обход и размывает сигналы между страницами.</p><p>На практике проверяют: доступность страниц для робота, логику каноникалов, работу фильтров и сортировок, наличие полезного контента на первой странице категории. Бесконечная прокрутка без серверных URL может ухудшать обнаружение контента.</p><p>Решение зависит от CMS и типа листинга; универсальной «одной кнопки» нет.</p><p>Связанные понятия: Индексация; Канонический URL; Краулинговый бюджет; Структура сайта.</p>
