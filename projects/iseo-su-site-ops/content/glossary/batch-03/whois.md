# WHOIS

WHOIS — система и протокол для запроса сведений о домене: регистратор, даты, статус, иногда контакты. Часть полей сегодня скрыта политиками приватности.

<p>В расследованиях WHOIS помогает оценить возраст домена и смену регистратора. Это не рейтинг «траста» сам по себе.</p><p>Связанные понятия: Домен; Хостинг; Wayback Machine.</p>
