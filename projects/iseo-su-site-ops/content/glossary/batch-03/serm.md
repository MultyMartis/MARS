# SERM

SERM — управление репутацией бренда в поисковой выдаче: работа с отзывами, информационными поводами и страницами, которые формируют впечатление о компании по запросам имени.

<p>В выдаче по бренду могут быть сайт, карты, отзывы, новости и сторонние мнения. SERM сочетает контент, работу с площадками отзывов и юридические/сервисные процессы, а не только «продвижение позитива ссылками».</p><p>Цель — честная и управляемая картина для пользователя, а не скрытие реальных проблем сервиса.</p><p>Связанные понятия: Сниппет; Органическая выдача; Бренд.</p>
