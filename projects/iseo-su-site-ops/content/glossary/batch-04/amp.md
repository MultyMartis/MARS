# AMP

AMP (Accelerated Mobile Pages) — технология и формат облегчённых мобильных страниц, которые Google продвигал для быстрой загрузки контента на смартфонах. Она ограничивает часть HTML и JavaScript и использует собственную инфраструктуру кеширования.

<p>AMP решала практическую проблему медленного мобильного веба: страница строилась по более строгим правилам и могла открываться быстрее. В издательских проектах такие версии нередко существовали параллельно с обычными URL.</p><h2>Почему AMP больше не обязательный ориентир</h2><p>Стратегическая роль AMP снизилась: для ряда специальных блоков Google перестал требовать этот формат. Современная мобильная страница может быть быстрой и без AMP — за счёт оптимизации изображений, кода, сервера и пользовательских сценариев.</p><p>Сам по себе AMP не даёт гарантированного преимущества в ранжировании. Поисковая система оценивает страницу комплексно, а точные веса сигналов не раскрывает. Поэтому выбор формата стоит делать по стоимости поддержки, скорости и качеству опыта, а не ради ожидания «автоматического топа».</p><p>Если AMP уже внедрён, перед отключением проверяют каноникализацию, мобильные URL, аналитику и редиректы. Решение зависит от архитектуры сайта: универсального требования сохранить или удалить AMP нет.</p><p>Связанные понятия: Мобильная версия сайта; Mobile-first indexing; Скорость загрузки страницы; Core Web Vitals.</p>
