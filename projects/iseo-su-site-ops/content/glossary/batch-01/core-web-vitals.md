# Core Web Vitals

Core Web Vitals — набор пользовательских метрик Google: LCP, CLS и INP. Они оценивают загрузку основного контента, визуальную стабильность и отзывчивость интерфейса; историческая FID заменена INP.

<p>Core Web Vitals объединяют три метрики опыта страницы: LCP отражает скорость появления основного контента, CLS — отсутствие неожиданных сдвигов макета, INP — отзывчивость на действия пользователя. FID — историческая метрика, которую заменили INP.</p><p>Показатели помогают находить проблемы интерфейса: тяжёлые изображения, нестабильные блоки или медленные обработчики. Их улучшение полезно для удобства посетителей.</p><p>Однако Core Web Vitals — лишь часть множества сигналов и не являются единственным условием ранжирования.</p><p>Связанные понятия: Техническая оптимизация; HTTPS; SEO.</p>
