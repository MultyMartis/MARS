# Канонический URL

Канонический URL — предпочтительный адрес среди страниц с одинаковым или близким содержанием. Его обычно указывают через link rel="canonical", чтобы подсказать поисковой системе, какую версию учитывать основной.

<p>Подсказку обычно передают тегом <code>link rel="canonical"</code> в коде страницы. Например, товар может открываться с параметрами сортировки и без них — каноникал помогает обозначить базовый адрес.</p><p>Поисковая система оценивает эту рекомендацию вместе с другими сигналами и может выбрать иной вариант. Canonical не равен 301-редиректу: редирект переносит пользователя и робота на другой URL, а каноникал не меняет маршрут перехода.</p><p>Связанные понятия: Дубли страниц; Редирект; Индексация.</p>
