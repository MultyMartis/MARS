# robots.txt

robots.txt — текстовый файл в корне сайта с правилами обхода URL для поисковых роботов. Он задаёт рекомендации по краулингу, но не скрывает данные и сам по себе не гарантирует удаление страницы из индекса.

<p>robots.txt размещают по адресу вида <code>https://site.ru/robots.txt</code>. В нём указывают, какие разделы или параметры URL нежелательно обходить конкретным роботам.</p><h2>Важное ограничение</h2><p>Файл управляет подсказками для краулинга, а не конфиденциальностью. Закрытый URL может быть известен по внешней ссылке, а правила файла доступны всем посетителям. Для запрета индексации применяют подходящие директивы noindex или ограничение доступа.</p><p>Карту сайта часто указывают в robots.txt отдельной строкой Sitemap.</p><p>Связанные понятия: Краулинг; Noindex; Карта сайта; Индексация.</p>
