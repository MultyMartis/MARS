# Анкорный текст

Анкорный текст — видимая кликабельная часть ссылки. Он подсказывает пользователю, куда ведёт переход, а поисковой системе может дать контекст целевой страницы, если текст естественен и соответствует ссылке.

<p>Анкорный текст — слова, на которые нажимает пользователь при переходе по ссылке. В HTML он находится внутри тега <code>a</code>.</p><h2>Каким бывает анкор</h2><ul><li>тематическим: «ремонт офисной мебели»;</li><li>брендовым: название компании;</li><li>безанкорным: URL, «здесь», «подробнее».</li></ul><p>Анкор должен честно описывать ожидаемую страницу. Массовое повторение одинаковых коммерческих фраз выглядит неестественно и ухудшает опыт читателя.</p><p>Связанные понятия: Обратная ссылка; Nofollow; Ссылочный профиль.</p>
