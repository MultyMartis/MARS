# HTTPS

HTTPS — защищённая версия HTTP, использующая TLS-шифрование для передачи данных между браузером и сервером. Термин SSL часто используют по привычке, хотя современные защищённые соединения обычно основаны на TLS.

<p>HTTPS защищает данные при передаче между браузером и сервером: снижает риск их перехвата или подмены в пути. Для работы нужен корректно настроенный TLS-сертификат и серверная конфигурация.</p><p>Название SSL часто сохраняется в интерфейсах и разговорной речи, однако актуальные защищённые соединения обычно используют TLS. HTTPS не делает сайт автоматически безопасным во всех отношениях: необходимо также защищать аккаунты, сервер и приложение.</p><p>При миграции с HTTP важно настроить единый вариант URL и перенаправления на HTTPS.</p><p>Связанные понятия: Техническая оптимизация; Редирект; Core Web Vitals.</p>
