# Дополнение sitemap i-seo.su

## Что было обнаружено

После предыдущего исправления sitemap технически работал корректно, но список статических страниц оказался неполным.

SEO-команда передала список из 54 отсутствующих URL (кейсы, AI optimization, SEO-посадки). Все 54 адреса были проверены на продакшене и подтверждены как публичные индексируемые страницы.

## Почему так произошло

Генератор `sitemap-static.xml` работал по **кураторскому allowlist** — это безопасная модель (не выгружает в индекс служебные файлы). Но сам allowlist был собран неполно: в него не попали часть кейсов, весь блок AI optimization и ряд SEO-посадок. Проверка после предыдущего фикса подтверждала только валидность XML и HTTP-статусы уже включённых URL, но **не полноту** покрытия публичных статических страниц.

Это не ошибка SEO-команды: список отсутствующих URL помог быстро локализовать пробел.

## Что исправили

- проверили все предоставленные URL на продакшене;
- исправили источник формирования sitemap (allowlist + инвентарь публичных статических маршрутов);
- добавили все 54 подтверждённые индексируемые страницы;
- дополнительно сверили остальные публичные статические страницы и добавили 2 юридических URL (`cookie-files-policy`, `user-agreement`), которых не было в списке из 54;
- пересобрали `sitemap-static.xml` (было 71 → стало 127);
- опубликовали файл и проверили все URL после публикации;
- добавили обязательную проверку полноты: публичные канонические статические маршруты минус URL в static sitemap = 0.

## Результат

- было URL в static sitemap: **71**
- добавлено: **56** (54 от SEO + 2 юридических)
- стало: **127**
- 404 среди URL sitemap: **0**
- 5xx среди URL sitemap: **0**
- пропущенных подтверждённых публичных статических страниц: **0**
- пересечение static sitemap с WordPress sitemap: **0**

Корневой `/sitemap.xml` без изменений по архитектуре: по-прежнему указывает на `sitemap-static.xml` и `wp-sitemap.xml`.

## Что просим проверить SEO-команду

Просим выборочно проверить в Search Console / глазами:

- кейсы (в т.ч. новые и SMM-кейсы);
- раздел AI optimization;
- SEO landing pages (`prodvizhenie-…`);
- общий состав `https://i-seo.su/sitemap-static.xml`.

Если есть страницы, которые SEO хочет убрать или добавить по семантическим причинам — верните список в MARS / Site Ops: правим allowlist и пересобираем sitemap штатной процедурой.
