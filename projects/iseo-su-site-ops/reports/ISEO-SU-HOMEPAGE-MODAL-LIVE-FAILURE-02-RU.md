# ISEO-SU — сбой модалки аудита на homepage (LIVE FAILURE 02)

**Дата:** 2026-09-09  
**Сайт:** https://i-seo.su/

## Что сломалось

Модалка **«Получить бесплатный аудит вашего сайта»** после отправки показывала ошибку «Не удалось отправить заявку…», если поле «Адрес сайта» было пустым (consent включён). Success-state не появлялся.

Предыдущий PASS по homepage/modal относился к другой форме (`#callback__FORM`) и **не покрывал** эту модалку. Синтетический/direct POST как финальное доказательство недостаточен — подтверждено живым браузером.

## Контракт

- Форма: `#audit__FORM`
- Кнопка: `#audit__FORM_send`
- Обработчик: `audit__FORM.php`
- JS: `js/common.js`

## Причина

Сервер требовал «осмысленный» `af_site` даже при пустом значении. В HTML поле необязательное. Ответ `false` → общая ошибка в UI.

Телефон в стиле оператора (`+7 (111) 111-11-11`) при заполненном сайте принимался — валидация телефона не была корнем проблемы.

## Исправление

1. В `audit__FORM.php` сайт опционален: отклоняется только непустой, но «неосмысленный» сайт.
2. В `common.js` для кнопки аудита добавлены `preventDefault` / `return false` (как у page/callback).

## Проверка после фикса (браузер)

- Пустой сайт → успех UI, без перезагрузки, без общей ошибки  
- Заполненный сайт → успех  
- Главная форма, вебинар, restaurant / city / niche — smoke OK  
- Consent без галочки — заявка не уходит  
- `test_mode` в конце: **OFF**, письмо тестов на `im.work@mail.ru`  
- HMAC / honeypot / min-fill / rate / duplicate / consent — активны  
- Дизайн / SEO / меню / sitemap не менялись
