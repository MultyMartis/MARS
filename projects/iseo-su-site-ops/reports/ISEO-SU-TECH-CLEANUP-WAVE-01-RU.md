# ТЕХНИЧЕСКАЯ ЧИСТКА I-SEO.SU — WAVE 01

**Дата:** 24.08.2026  
**Сайт:** https://i-seo.su/  
**Задача:** техническая чистка без изменения SEO-семантики (canonical / title / meta / H1 / alt / OG)

## 1. Что перепроверили по sitemap

После закрытия неполноты static sitemap (127 URL) заново сравнили:

- текущие indexable страницы с обхода production;
- актуальный union sitemap: `sitemap-static.xml` + `wp-sitemap.xml` и дочерние.

Исходная цифра аудита **197** больше не используется как текущая истина.

## 2. Что оказалось после пересчёта

| Показатель | Значение |
|---|---:|
| Было в аудите | 197 |
| Сырой остаток «indexable вне sitemap» | 161 |
| Реально недостающие канонические публичные URL | **0** |

Остаток 161 — не «дыры sitemap», а ожидаемые поверхности:

- query-варианты блога (`?tags=`, `?sort=`) — 149;
- Report Hub / tool — 8;
- legacy/неканонические варианты (`home.html`, `blog.html`, archive glossary) — 4.

Static marketing completeness по-прежнему закрыта; архитектура dual-sitemap не менялась.

## 3. Что было не так с внутренними ссылками

В аудите: **129** внутренних целей, которые отвечают редиректом.

Главный паттерн — «лишний» trailing slash:

- `/blog/` → `/blog`
- `/glossary/` → `/glossary`
- `/blog/?…` → `/blog?…`

Отдельно на `/offers` блок архивов по месяцам вёл на URL вида `/blog/2026/06`, которые сейчас 301 на главную.

## 4. Как исправили ссылки

Исправили **источники ссылок** (не правила редиректов):

- шаблоны темы WordPress (меню, фильтры блога, теги);
- статические `blog.html` / `blog-article.html`;
- для виджета архивов — безопасная подмена цели на `/blog` (без изменения redirect-конфига).

После проверки по страницам sitemap/seed: **0** оставшихся проблемных href выбранного класса.

## 5. Какие изображения были слишком тяжёлыми

Подтверждены два файла выборки аудита:

1. `/img/cases/seo_ai_cases/makita_01.png` — ≈2,76 МБ  
2. `/img/cases/seo_ai_cases/maltipoo_01.png` — ≈2,73 МБ  

Используются на кейс-страницах Makita / Maltipoo.

## 6. Как оптимизировали изображения

Сжали PNG без смены размеров и без смены имени файла (разметка не менялась):

| Файл | Было | Стало | Экономия |
|---|---:|---:|---:|
| makita_01.png | 2 760 350 | 333 369 | ≈88% |
| maltipoo_01.png | 2 726 005 | 312 435 | ≈89% |

Визуальная проверка скриншотов: без заметной деградации читаемости. Оба файла теперь ниже порога 1,5 МБ.

## 7. Что проверили после исправлений

- ключевые маршруты (`/`, услуги, кейсы, блог, offers, calculator, glossary, sitemap);
- отсутствие PHP fatal;
- отсутствие новых битых внутренних ссылок в smoke-наборе;
- формы / Метрика / глоссарий / SEO-метаданные / архитектура sitemap — без изменений.

## 8. Что осталось на согласование SEO

Без изменений статуса (нужно SEO-решение, не tech-autofix):

- CANON-MISSING, CANON-MISMATCH  
- SM-NONINDEX  
- TITLE-DUP, TITLE-LONG  
- META-MISSING, META-DUP  
- ORPHAN-CRAWLER  
- IMG-ALT, OG-MISSING  
- H1-MISSING — по-прежнему кандидат на ожидаемое поведение tool/hub поверхностей

- два тяжёлых изображения оптимизированы.

Семантические SEO-находки оставлены на отдельное согласование.
