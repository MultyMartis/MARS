# Term 1 — SEO

| Field | Value |
|-------|-------|
| Canonical title | SEO |
| Source workbook title | SEO |
| Status | KEEP |
| Category | SEO fundamentals |
| Synonyms | поисковая оптимизация; продвижение сайта (as glossary merge aliases) |
| Expert verification | NO |
| Priority / difficulty | HIGH / SIMPLE |

**Short definition**  
SEO (Search Engine Optimization) — комплекс работ по улучшению видимости сайта в органической выдаче поисковых систем за счёт качества страниц, технической доступности и соответствия запросам пользователей.

**Full definition**

SEO (Search Engine Optimization, поисковая оптимизация) — практики и процессы, которые помогают сайту лучше находиться и оцениваться поисковыми системами в **органической** (неоплаченной) выдаче.

В практическом смысле SEO объединяет несколько направлений: понимание спроса и интента, структуру и содержание страниц, техническую доступность для обхода и индексирования, внутреннюю перелинковку, а также работу с внешними сигналами (ссылки и упоминания) в рамках правил поисковых систем. SEO не равно контекстной рекламе: реклама покупает показы, SEO работает с органическими результатами.

**Зачем это важно.** Для бизнеса SEO — канал привлечения пользователей, которые уже ищут товар, услугу или ответ. Устойчивый результат зависит от полезности сайта, а не от разовых «секретных» приёмов.

**Как используется.** Обычно начинают с аудита и семантики, затем устраняют технические ограничения, усиливают важные страницы и измеряют видимость, трафик и конверсии.

**Пример.** Интернет-магазин улучшает карточки товаров, скорость мобильных страниц и структуру категорий — чтобы запросы вроде «купить …» находили релевантные страницы, а не дубли и ошибки.

**Related terms:** Органический трафик; Поисковая выдача; Семантическое ядро; Техническая оптимизация; PPC  

**Distinction:** SEO ≠ PPC. SEO работает с органикой; PPC — с оплачиваемыми кликами.

**SEO title:** SEO — что такое поисковая оптимизация | i-seo.su  
**Meta description:** SEO — это работа над видимостью сайта в органической выдаче. Простое определение, зачем нужно бизнесу и чем отличается от рекламы.

# Term 2 — Анкорный текст

| Field | Value |
|-------|-------|
| Canonical title | Анкорный текст |
| Source workbook title | Анкор (анкорный текст) |
| Status | RENAME |
| Category | link building |
| Synonyms | анкор; текст ссылки; anchor text |
| Expert verification | NO |
| Priority / difficulty | HIGH / SIMPLE |

**Short definition**  
Анкорный текст — видимый текст гиперссылки, по которому пользователь переходит на другую страницу; для поисковых систем это один из сигналов о теме целевого URL.

**Full definition**

Анкорный текст (анкор) — кликабельная текстовая часть ссылки. Он помогает человеку понять, куда ведёт переход, и даёт поисковой системе контекст о содержании целевой страницы.

Анкоры бывают брендовыми, URL-подобными (безанкорными), составными и с вхождением ключевой фразы. Для ссылочного профиля важны естественность и разнообразие: избыток одинаковых «точных» коммерческих анкоров выглядит неестественно и исторически связывался с рисками ссылочного спама.

**Зачем это важно.** Владельцу сайта полезно контролировать, как сайт ссылается сам на себя и какие анкоры приходят извне: это влияет и на удобство, и на оценку ссылочного профиля.

**Пример.** Вместо массовых ссылок с текстом «купить окна недорого» безопаснее и понятнее сочетание бренда, URL и описательных формулировок («обзор монтажа окон»).

**Related terms:** Обратная ссылка; Безанкорная ссылка; Внутренняя перелинковка; Ссылочный профиль; Nofollow  

**Distinction:** Анкор — текст ссылки; акцептор — страница, которая ссылку принимает.

**SEO title:** Анкорный текст — что это в SEO | i-seo.su  
**Meta description:** Анкорный текст — это текст гиперссылки. Зачем он нужен, какие бывают анкоры и почему важно разнообразие ссылочного профиля.

# Term 3 — robots.txt

| Field | Value |
|-------|-------|
| Canonical title | robots.txt |
| Source workbook title | Файл robots.txt |
| Status | RENAME |
| Category | technical SEO |
| Synonyms | файл robots.txt; robots |
| Expert verification | NO |
| Priority / difficulty | HIGH / MODERATE |

**Short definition**  
robots.txt — текстовый файл в корне сайта, который подсказывает поисковым роботам, какие разделы можно обходить, а какие лучше не запрашивать.

**Full definition**

robots.txt — общепринятый механизм управления обходом (crawl) сайта. Файл размещается по адресу вида `https://example.com/robots.txt` и содержит директивы для роботов (например, `User-agent`, `Disallow`, `Allow`, указание на карту сайта).

Важно понимать границы: robots.txt **не является надёжным способом скрыть конфиденциальные данные** и не заменяет авторизацию. Также запрет обхода не всегда равен «удалить из индекса»: для управления индексированием чаще используют другие средства (например, noindex), а robots.txt влияет прежде всего на crawl.

**Зачем это важно.** Ошибки в robots.txt могут закрыть от робота нужные разделы или, наоборот, открыть служебные. Для бизнеса это риск потери видимости или лишней нагрузки на сервер.

**Пример.** Закрыть от обхода служебные параметры фильтров или тестовый поддомен — нормальная практика; закрыть всю папку `/blog/`, если блог должен быть в поиске, — ошибка.

**Related terms:** Индексация; Краулинг; Noindex; Карта сайта; Поисковый робот  

**Distinction:** robots.txt управляет обходом; noindex — скорее сигнал об индексировании. Это разные задачи.

**SEO title:** robots.txt — что это и как влияет на SEO | i-seo.su  
**Meta description:** robots.txt подсказывает роботам, что можно обходить на сайте. Чем он отличается от noindex и какие ошибки опасны для видимости.  
**Editorial notes:** Rely on robots exclusion standard / Search Central explanations; avoid inventing Yandex-only quirks without docs.

# Term 4 — CTR

| Field | Value |
|-------|-------|
| Canonical title | CTR |
| Source workbook title | CTR (кликабельность) |
| Status | RENAME |
| Category | analytics and metrics |
| Synonyms | кликабельность; click-through rate |
| Expert verification | NO |
| Priority / difficulty | HIGH / SIMPLE |

**Short definition**  
CTR (click-through rate, кликабельность) — доля кликов от числа показов: CTR = клики ÷ показы. Показывает, насколько привлекателен результат или объявление.

**Full definition**

CTR — относительная метрика эффективности показа. В поиске её считают для сниппета в выдаче; в рекламе — для объявлений и мест размещения. Формула одна: клики делят на показы и обычно выражают в процентах.

Высокий CTR сам по себе не доказывает качество сайта и не является «гарантией позиций». Он показывает реакцию аудитории на заголовок, описание, быстрые ссылки и соответствие ожиданиям запроса. Низкий CTR при высоких показах часто сигнал слабого сниппета или неверного интента.

**Зачем это важно.** Бизнесу CTR помогает сравнивать формулировки title/description, объявлений и посадочных сценариев без путаницы с абсолютным числом кликов.

**Пример.** Два объявления получили по 1 000 показов: первое — 50 кликов (CTR 5%), второе — 20 (CTR 2%). При прочих равных первое привлекательнее в выдаче/рекламе.

**Related terms:** Сниппет; Поисковая выдача; CPC; Конверсия; Поисковый интент  

**Distinction:** CTR ≠ конверсия. CTR — про клик по показу; конверсия — про целевое действие после входа.

**SEO title:** CTR — что такое кликабельность | i-seo.su  
**Meta description:** CTR (кликабельность) — доля кликов от показов. Как считается, где применяется в SEO и рекламе и чем отличается от конверсии.  
**Editorial notes:** Do not claim CTR is a direct ranking factor.

# Term 5 — Семантическое ядро

| Field | Value |
|-------|-------|
| Canonical title | Семантическое ядро |
| Source workbook title | Семантическое ядро |
| Status | KEEP |
| Category | content and semantics |
| Synonyms | семантика сайта; ядро запросов |
| Expert verification | NO |
| Priority / difficulty | HIGH / MODERATE |

**Short definition**  
Семантическое ядро — структурированный набор поисковых запросов и тем, по которым сайт планирует быть полезным и видимым; основа для структуры разделов и контента.

**Full definition**

Семантическое ядро — рабочий список запросов, сгруппированных по смыслу и интенту, с привязкой к страницам сайта. Его собирают из спроса аудитории, текущей видимости, конкурентного окружения и бизнес-приоритетов.

Ядро — не «список ключей для вставки в текст». Это карта спроса: какие страницы нужны, какие запросы информационные, какие коммерческие, где риск каннибализации. На его основе проектируют категории, фильтры, статьи и посадочные.

**Зачем это важно.** Без ядра сайт растёт хаотично: появляются пересекающиеся страницы, пустые разделы и контент «ни о чём». Для бизнеса семантика связывает маркетинг и структуру сайта.

**Пример.** Для клиники ядро может включать кластеры «симптомы», «методы лечения», «цены», «врачи» — с разными типами страниц под каждый интент.

**Related terms:** Частотность запроса; Поисковый интент; Кластеризация запросов; Каннибализация запросов; LSI  

**Distinction:** Семантическое ядро ≠ LSI. LSI — связанные формулировки/термины; ядро — управляемый набор целевых запросов сайта.

**SEO title:** Семантическое ядро — что это в SEO | i-seo.su  
**Meta description:** Семантическое ядро — структурированный набор запросов для сайта. Зачем нужно, как связано с интентом и чем отличается от LSI.  
**Editorial notes:** Avoid presenting Wordstat alone as complete methodology.

# Term 6 — PPC

| Field | Value |
|-------|-------|
| Canonical title | PPC |
| Source workbook title | Pay-per-Click (PPC) |
| Status | RENAME |
| Category | contextual advertising |
| Synonyms | pay-per-click; оплата за клик; контекстная реклама (частично) |
| Expert verification | NO |
| Priority / difficulty | HIGH / SIMPLE |

**Short definition**  
PPC (pay-per-click) — модель онлайн-рекламы, при которой рекламодатель платит за клик по объявлению, а не за простой показ.

**Full definition**

PPC — принцип оплаты в цифровой рекламе: стоимость списывается, когда пользователь кликает по объявлению. Классические площадки — Google Ads и Яндекс Директ, но модель встречается и в других системах.

PPC часто пересекается с контекстной рекламой в поиске и сетях, но термин точнее описывает **модель оплаты**, а не весь маркетинг. Рядом считают CPC (цена клика), CTR, конверсии и ДРР/ROMI.

**Зачем это важно.** Для бизнеса PPC даёт быстрый тестовый трафик и управляемый спрос, но требует контроля ставок, качества объявлений и посадочных — иначе бюджет «сгорает» в кликах без заявок.

**Пример.** Объявление по запросу «ремонт котлов» ведёт на посадочную с формой заявки; оплата идёт за клики, эффективность смотрят по заявкам и стоимости лида (CPL).

**Related terms:** CPC; CTR; Контекстная реклама; SEO; Google Ads; Яндекс Директ  

**Distinction:** PPC ≠ SEO. PPC покупает клики; SEO развивает органическую видимость.

**SEO title:** PPC — что такое оплата за клик | i-seo.su  
**Meta description:** PPC (pay-per-click) — реклама с оплатой за клик. Чем отличается от SEO, какие метрики смотреть и как связана с CPC и CTR.  
**Editorial notes:** «Поисковая контекстная реклама» may stay separate; do not merge blindly.

# Term 7 — GEO

| Field | Value |
|-------|-------|
| Canonical title | GEO |
| Source workbook title | GEO |
| Status | KEEP |
| Category | AI search and GEO |
| Synonyms | Generative Engine Optimization; оптимизация для генеративных ответов |
| Expert verification | YES |
| Priority / difficulty | HIGH / EXPERT |

**Short definition**  
GEO (Generative Engine Optimization) — практики повышения вероятности, что бренд, факты и страницы сайта будут корректно использованы в ответах генеративных и AI-поисковых систем.

**Full definition**

GEO — формирующееся направление рядом с классическим SEO. Речь о видимости и представленности в сценариях, где пользователь получает ответ от генеративной системы (AI-обзоры, чат-поиск, ассистенты), а не только кликает по синей ссылке в выдаче.

Практический смысл пока осторожный: полезны ясная структура фактов, авторитетные источники, доступность контента для обхода, прозрачные атрибуты бренда и отсутствие манипулятивных «AI-спам» страниц. Отрасль ещё не имеет единого официального стандарта от всех поисковиков, поэтому GEO нельзя описывать как гарантированную «кнопку попадания в AI-ответ».

**Зачем это важно.** Бизнесу полезно готовить контент так, чтобы его было легко правильно процитировать: иначе в AI-ответах могут закрепляться чужие или неточные формулировки.

**Пример.** Компания публикует точные, датированные материалы с понятными определениями услуг и источниками — повышая шанс корректного упоминания, без обещаний «гарантированного цитирования».

**Related terms:** SEO; E-E-A-T; Human-First Content; Индексация; Сниппет  

**Distinction:** GEO ≠ геозависимость запроса и ≠ локальное SEO. Здесь «GEO» — про generative engines, не про географию.

**SEO title:** GEO — что такое Generative Engine Optimization | i-seo.su  
**Meta description:** GEO — оптимизация присутствия бренда в генеративных и AI-ответах. Чем отличается от SEO и геозависимости запросов.  
**Editorial notes:** PROVISIONAL. Expert/Nikita must approve wording before any WP upload. Avoid hype.

# Term 8 — Обратная ссылка

| Field | Value |
|-------|-------|
| Canonical title | Обратная ссылка |
| Source workbook title | Обратная ссылка (backlink) |
| Status | RENAME |
| Category | link building |
| Synonyms | backlink; входящая ссылка; внешняя ссылка (как merge alias) |
| Expert verification | NO |
| Priority / difficulty | HIGH / SIMPLE |

**Short definition**  
Обратная ссылка (backlink) — ссылка с другого сайта на вашу страницу; один из сигналов, которые поисковые системы могут учитывать при оценке документа и сайта.

**Full definition**

Обратная ссылка — входящая гиперссылка с внешнего донора на ваш URL (акцептор). Совокупность таких ссылок образует ссылочный профиль. Качество важнее количества: тематическая близость, естественность анкора, контекст размещения и отсутствие признаков покупного спама.

Ссылки бывают dofollow/nofollow (и с другими `rel`), редакционными и размещёнными в служебных блоках. Покупка ссылок и частные сети (PBN) несут риск фильтров и ручных мер — это нужно объяснять нейтрально, без инструкций по обходу правил.

**Зачем это важно.** Для бизнеса ссылки — и канал трафика, и фактор доверия к ресурсу. Плохой профиль может навредить сильнее, чем помочь.

**Пример.** Упоминание компании в отраслевом обзоре со ссылкой на исследование — естественный backlink; массовая покупка одинаковых анкоров на бирже — риск.

**Related terms:** Донор ссылки; Акцептор ссылки; Анкорный текст; Ссылочный профиль; Disavow; Nofollow  

**Distinction:** Обратная (входящая) ссылка ≠ исходящая. Исходящие ведут с вашего сайта наружу.

**SEO title:** Обратная ссылка (backlink) — что это | i-seo.su  
**Meta description:** Обратная ссылка — это входящий backlink с другого сайта. Зачем нужен ссылочный профиль и чем опасен ссылочный спам.  
**Editorial notes:** MERGE «Внешняя ссылка (backlink)» сюда.

# Term 9 — Показатель отказов

| Field | Value |
|-------|-------|
| Canonical title | Показатель отказов |
| Source workbook title | Отказы (показатель отказов) |
| Status | RENAME |
| Category | analytics and metrics |
| Synonyms | отказ; bounce rate (частично — см. distinction) |
| Expert verification | YES |
| Priority / difficulty | HIGH / MODERATE |

**Short definition**  
Показатель отказов — метрика аналитики о «неуспешных» или слишком коротких визитах; точная формула зависит от системы учёта (например, Яндекс.Метрика и классический bounce rate считаются по-разному).

**Full definition**

В разговорном SEO «отказы» часто смешивают с англоязычным bounce rate. На практике определения различаются:

- в классической модели bounce — сессия с просмотром одной страницы без дальнейших действий;
- в Яндекс.Метрике «отказ» исторически связан с коротким визитом и глубиной (уточнять по актуальной справке Метрики).

Поэтому нельзя переносить пороги и «нормы» между системами один в один. Также опасно считать отказы прямым «фактором ранжирования» Google/Yandex в упрощённом виде: метрика прежде всего диагностическая для UX и соответствия интенту.

**Зачем это важно.** Высокий отказ на посадочной часто означает обманчивый сниппет, медленную загрузку или нерелевантный оффер — это повод улучшить страницу, а не «накрутить поведение».

**Пример.** Реклама обещает «цены от 1 000 ₽», а на сайте — только дорогие пакеты: пользователь уходит сразу, отказы растут.

**Related terms:** Сессия; Конверсия; CTR; Поведенческие факторы; Яндекс.Метрика; Google Analytics  

**Distinction:** «Отказ» Метрики ≠ всегда bounce rate GA. Сверяйте определение в интерфейсе конкретной системы.

**SEO title:** Показатель отказов — что это и как читать | i-seo.su  
**Meta description:** Показатель отказов — метрика коротких или одностраничных визитов. Почему её нельзя путать между Метрикой и bounce rate и как использовать.

# Term 10 — Core Web Vitals

| Field | Value |
|-------|-------|
| Canonical title | Core Web Vitals |
| Source workbook title | Core Web Vitals |
| Status | KEEP |
| Category | technical SEO |
| Synonyms | CWV; основные интернет-показатели (разг.) |
| Expert verification | NO |
| Priority / difficulty | HIGH / MODERATE |

**Short definition**  
Core Web Vitals — набор метрик Google о реальном пользовательском опыте загрузки и стабильности страницы; важные ориентиры технического качества сайта.

**Full definition**

Core Web Vitals (CWV) — ключевые пользовательские метрики качества страницы в экосистеме Google. Актуальный набор следует сверять с Search Central: в фокусе скорость отрисовки основного контента (LCP), стабильность визуала (CLS) и отзывчивость на ввод (INP; FID — устаревшая метрика).

CWV помогают находить проблемы медленных изображений, сдвигов вёрстки и «зависшего» интерфейса. Они важны для UX и могут учитываться среди сигналов ранжирования страниц, но **не заменяют** релевантность контента и не гарантируют топ.

**Зачем это важно.** Медленный или «прыгающий» сайт теряет заявки ещё до чтения оффера. Для бизнеса CWV — практичный чеклист скорости и стабильности.

**Пример.** Крупный баннер без размеров сдвигает кнопку «Оставить заявку» — растёт CLS, пользователи промахиваются по клику.

**Related terms:** LCP; CLS; FID (historical); Мобильная версия сайта; HTTPS; Техническая оптимизация  

**Distinction:** Улучшение CWV ≠ автоматический рост позиций. Это качество опыта, а не единственный фактор.

**SEO title:** Core Web Vitals — что это простыми словами | i-seo.su  
**Meta description:** Core Web Vitals — метрики реального опыта загрузки страницы (LCP, CLS, INP). Зачем нужны бизнесу и чем не стоит их переоценивать.

# Term 11 — E-E-A-T

| Field | Value |
|-------|-------|
| Canonical title | E-E-A-T |
| Source workbook title | E-E-A-T |
| Status | KEEP |
| Category | SEO fundamentals |
| Synonyms | Experience, Expertise, Authoritativeness, Trustworthiness; опыт, экспертность, авторитетность, надёжность |
| Expert verification | YES |
| Priority / difficulty | HIGH / EXPERT |

**Short definition**  
E-E-A-T — концепция оценки качества контента в руководстве для асессоров Google: опыт, экспертность, авторитетность и достоверность. Это не отдельный «балл» в Search Console.

**Full definition**

E-E-A-T описывает, насколько страница и её авторы выглядят заслуживающими доверия для людей, особенно в темах с высоким риском (здоровье, финансы, безопасность). Google использует эти понятия в **документах для асессоров качества**, чтобы оценивать выдачу; это не означает наличие публичного числового «E-E-A-T score».

На практике E-E-A-T проявляется через прозрачность авторства, подтверждаемые факты, репутацию организации, качество источников и отсутствие вводящих в заблуждение обещаний. «Добавить блок E-E-A-T» ради галочки без реальной экспертизы — пустая имитация.

**Зачем это важно.** Для бизнеса доверие напрямую связано с конверсией и репутацией. В чувствительных нишах слабая доказательная база вредна и пользователям, и видимости.

**Пример.** Медицинская статья с именем врача, датой обновления и ссылками на клинические источники выглядит убедительнее анонимного текста с гарантиями «100% излечения».

**Related terms:** Асессор; Экспертность контента; Human-First Content; SEO; YMYL (if later added)  

**Distinction:** E-E-A-T ≠ прямой ranking factor-кнопка. Это рамка качества; алгоритмы учитывают множество сигналов, но отдельного публичного счётчика нет.

**SEO title:** E-E-A-T — что значит для сайта | i-seo.su  
**Meta description:** E-E-A-T — опыт, экспертность, авторитетность и доверие. Почему это не «балл SEO» и как проявляется в качественном контенте.  
**Editorial notes:** Expert review required; cite rater-guidelines framing carefully without overclaim.

# Term 12 — Канонический URL

| Field | Value |
|-------|-------|
| Canonical title | Канонический URL |
| Source workbook title | Канонический URL (canonical) |
| Status | RENAME |
| Category | technical SEO |
| Synonyms | canonical; rel=canonical; каноникал |
| Expert verification | NO |
| Priority / difficulty | HIGH / MODERATE |

**Short definition**  
Канонический URL — предпочтительный адрес страницы среди её дублей; через него сайту и поисковым системам сообщают, какую версию считать основной.

**Full definition**

Канонический URL задаёт предпочтительную версию документа, когда один и тот же или почти одинаковый контент доступен по нескольким адресам (параметры UTM/сортировки, HTTP/HTTPS, www/non-www, печать и т.п.). На практике чаще используют элемент `rel="canonical"` в HTML (и иногда HTTP-заголовок).

Canonical — сигнал предпочтения, а не «магическое удаление» всех дублей. Его комбинируют с корректными редиректами, единым главным зеркалом и аккуратной внутренней перелинковкой. Ошибки (каноникал на нерелевантную страницу, цепочки, каноникал на 404) вредят индексированию.

**Зачем это важно.** Дубли размывают сигналы и мешают понять, какую страницу показывать в поиске. Для бизнеса это потеря видимости важных URL.

**Пример.** Карточки товара с `?color=` и `?sort=` указывают canonical на чистый URL без параметров — чтобы в индексе укреплялась одна версия.

**Related terms:** Дубли страниц; Главное зеркало сайта; Редирект; Индексация; Параметр GET  

**Distinction:** Canonical ≠ 301 redirect. Redirect принудительно переводит пользователя и робота; canonical — предпочтение при сосуществовании URL.

**SEO title:** Канонический URL — что такое canonical | i-seo.su  
**Meta description:** Канонический URL указывает основную версию страницы среди дублей. Чем отличается от редиректа и зачем нужен бизнесу.  
**Editorial notes:** Strong pilot for misconception/distinction requirement.
