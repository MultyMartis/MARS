## Central workspace feeling

`main_area` answers: **«Над чем работаю сейчас?»**

| Target | Description |
|--------|-------------|
| **Calm-control** | Activity localized; chrome quiet |
| **Spatial breathing room** | Negative space is feature — not empty failure |
| **Architectural calmness** | Instruments on glass — not equal widget wall |
| **Focus ownership** | Foveal attention natural here |
| **Asymmetry** | Blocks vary S/M/L — not rigid grid vanity |

---

## Focus-state atmosphere

| State | Atmosphere shift |
|-------|------------------|
| Default work | Standard glass instruments; environment P3 |
| Selected block | Slight raise + focus light |
| Focus mode (C) | Center clearer; periphery reduced contrast — not invisible |
| Overlay-open | Center dimmed under panel; silhouette preserved |

Aligns with [operational-focus-state-model-v0.1.md](operational-focus-state-model-v0.1.md).

## Large-screen behavior (2K philosophy)

| Principle | Probe framing |
|-----------|---------------|
| Wide center canvas | Generous horizontal breath |
| Not mobile-blown cards | Fewer, larger instruments |
| Density readable | S/M/L blocks — not 20 micro-widgets |
| Viewport-fixed | No «long scrolling poster» composition |

---

## Explore: asymmetry and calm

| Allowed | Forbidden |
|---------|-----------|
| 1–3 dominant instruments + secondary | 12 equal KPI cards |
| Offset block placement feel | Perfect symmetric marketing grid |
| Quiet gaps between blocks | Sterile void with no depth |
| Raised active block | Everything raised |
