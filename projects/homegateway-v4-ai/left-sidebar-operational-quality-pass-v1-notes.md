# Left Sidebar Operational Quality Pass v1 Notes

## Почему сайдбару понадобился ребаланс

Левая колонка после предыдущих проходов уже стала читабельнее, но оставалась слишком плотной для роли основного оперативного навигатора. Основная проблема была не в структуре, а в слишком узком рабочем поле, сырой telemetry-линии и одинаковом визуальном весе блоков `Projects`, `Tools` и `Quick Access`.

## Финальное решение по ширине

- Базовая сетка принята как `400px / 1fr / 440px`.
- Левый сайдбар получил дополнительное пространство для заголовка и второго telemetry-ряда.
- Центральная область не была дополнительно ужата, потому что компенсация сделана за счет небольшого уменьшения правой колонки.

## Решение по иерархии строк

- Сохранена двухстрочная структура строки.
- Верхний ряд оставлен для semantic icon + entity title.
- Нижний ряд закреплен за telemetry-группой.
- Для `Projects` увеличен вес и высота строк, для `Tools` сохранена та же структура, но с более спокойной плотностью.

## Решение по telemetry micro-modules

- Telemetry переведена из ощущения случайной линии в компактные micro-modules с радиусом `4px`.
- Числа выровнены через tabular-nums и `3ch`, чтобы 1/2/3-значные значения не ломали ритм.
- Completed-состояние сделано тише, чем warning/problem, без тяжелых плашек и без glow.

## Решение по cyan dot

- Бессмысленный правый cyan dot удален.
- В текущей разметке у него не было документированной semantic-модели, поэтому сохранение такого элемента усиливало шум, а не навигацию.

## Решение по semantic zoning

- `Projects` оставлен главным operational-блоком через более сильный surface и более уверенную row-иерархию.
- `Tools` оставлен рядом, но сделан спокойнее по surface и плотности.
- `Quick Access` зафиксирован как utility-layer с самым низким визуальным приоритетом, без редизайна общей архитектуры панели.

## Ограничения, которые сохранены

- Не менялись centered shell logic, `1920px` wrapper и desktop shell rule `900–1080px`.
- Не тронуты `#main_area`, topbar architecture, favorites structure, monitor card structure и status module structure.
- Сохранены `Exo 2`, отсутствие `letter-spacing`, отсутствие `text-transform`, закон `4px` radius и палитра без новых accent colors.
