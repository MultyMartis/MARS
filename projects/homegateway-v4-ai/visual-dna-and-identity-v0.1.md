**Статус:** **DRAFT** · **PLANNING** · Lane B  
**Назначение:** формализация **визуальной ДНК** HG — эмоциональная личность, operator-centric identity, целевые и запрещённые состояния.

**Не является:** brand guidelines PDF, logo spec, marketing site identity.

## DNA in one sentence

**HG is a premium operational cockpit for a solo human operator — calm, spatial, intelligent, restrained.**

---

## How HG should FEEL (emotionally)

| Feeling | Description |
|---------|-------------|
| **Grounded** | Nothing floats without purpose; anchors (`top_bar`, zones) stable |
| **Capable** | System depth visible; not empty minimalism |
| **Quietly alert** | Risks peripheral; center remains workspace |
| **Professional** | Aerospace / mission-control dignity, not startup hype |
| **Human-scaled** | One operator station, not enterprise team theater |

The operator should sense: *«I am at my station, and the environment supports my judgment.»*

---

## Visual personality

| Trait | Expression |
|-------|------------|
| **Operator-centric** | Layout serves task + peripheral awareness, not admin KPI theater |
| **Spatial** | Tri-focus memory; zones have roles |
| **Layered** | Depth planes readable at glance |
| **Technological** | Exo 2, clean geometry — without costume fonts |
| **Restrained** | Color and motion are instruments, not decoration |
| **Premium** | Material quality on glass and borders — not flat bootstrap |

**Personality is NOT:** playful, cute, aggressive, cyberpunk, corporate-gray, gamer-RGB.

---

## Target emotional states (create)

| State | Visual mechanisms |
|-------|-------------------|
| **Confidence** | Consistent shell; predictable signal ladder |
| **Calmness** | Low-motion chrome; muted P3 ambient |
| **Control** | Clear selected states; focus in center |
| **Focus** | Dimming under overlay; reduced peripheral contrast in Focus mode |
| **Awareness** | `info_area` always present (or compact chip); level semantics |
| **Intelligence** | Subtle environmental depth; no fake «AI brain» graphics |
| **Spatial orientation** | Persistent left nav / center work / right tactical |

---

## Forbidden emotional states (must not create)

| State | Typical cause | Mitigation |
|-------|---------------|------------|
| **Anxiety** | Blinking alerts, red floods, modal spam | Calm-control; sticky not screaming |
| **Overload** | 20 equal widgets, rainbow borders | Tri-focus; P-tier caps |
| **Adrenaline** | Fast motion, pulse loops, gamer FX | Motion atmosphere; no infinite pulse |
| **Gamer hype** | RGB accents, neon frames | Accent philosophy; anti-patterns |
| **Neon chaos** | Glow on everything | One glow focal per region |
| **Sterile emptiness** | White SaaS void | Atmospheric depth without noise |
| **Fantasy immersion** | Starscape, hologram UI | Environment philosophy boundaries |

---

## Premium operational identity

| Principle | Visual implication |
|-----------|-------------------|
| **Instruments, not cards** | Block-screens read as panels on glass |
| **Mission posture** | Modes change density, not identity |
| **Long-session quality** | Contrast, type size, motion restraint |
| **Signal honesty** | CRITICAL means today/tomorrow — not decoration |

Premium ≠ luxury marketing aesthetic. Premium = **precision under load**.

---

## Operator-centric identity

| Operator reality | HG visual response |
|------------------|-------------------|
| Solo operator, many domains | Multi-view shell; one viewport |
| Deadlines and recurring work | Tactical rail; not calendar widget cosplay |
| Display-only integrations (v0.1) | Status blocks calm; no fake live graphs |
| Admin later | Admin is **layer**, not visual takeover of cockpit |

HG never implies **team collaboration** tropes (avatars wall, activity feed social UI).

---

## Intelligent environment feeling

**Ambient intelligence** means:

- Environment has **depth and light logic** suggesting a living system.
- Signals appear **where expected** (right rail, top chip).
- No mascot, no chat bubble character, no «AI sparkle» iconography.

**Not:** literal brain networks, matrix rain, particle brains, holographic assistants.

---

## Identity vs product positioning

| Positioning claim | Visual must support |
|-------------------|---------------------|
| Cockpit for MARS/web ecosystem | Operational density without NOC chaos |
| Anti-SaaS | Spatial hierarchy over card grid |
| Anti-CRM | No pipeline columns as hero UI |
| Static-first honest | No fake real-time animation theater |
