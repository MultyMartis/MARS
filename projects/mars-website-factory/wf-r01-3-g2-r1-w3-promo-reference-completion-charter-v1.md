### Purpose

Universal T1+ reference for service/service-direction presentation on PROMO/CORPORATE surfaces.

### Root semantics

- Semantic `<section>` with accessible heading
- Service **collection** (list or grid of items)
- Repeated internal service items

### Required content (minimum)

| Element | Required |
|---------|----------|
| Section heading | **Yes** |
| ≥2 service items | **Yes** (reference minimum) |
| Item title | **Yes** |
| Short description | **Yes** |
| Optional neutral icon/media | Optional |
| Optional detail link | Optional |

### Allowed variations (pick one canonical minimum in implementation)

- cards
- compact list
- compact directions row

**Rule:** One canonical partial — **not** separate partials per variation.

### Excluded content

`PROCESS`, `PRICING`, `FAQ`, primary `LEAD_FORM`, primary `CTA`, `CASE_STUDIES` block, catalog grids.

### Accessibility minimum

Semantic section; heading association; list/grid semantics; accessible link names; decorative icon policy (`aria-hidden` when decorative); keyboard focus on links; long description readability.

### Responsive minimum

Desktop / tablet / mobile layouts; long titles/descriptions wrap; many items stack; single-item edge case; **no persistent horizontal overflow**.
