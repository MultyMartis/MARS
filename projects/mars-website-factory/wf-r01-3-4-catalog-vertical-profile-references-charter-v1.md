## 4. Problem Statement

Program design assigned **Wave W4–W5** catalog corridor work to WF-R01.3.4. WF-R01.3.3 **completed** global shell policy, BREADCRUMBS/PAGINATION T1+ references, shell matrix, and scaffold contract — but **excluded** FILTERS, SEARCH, catalog grids, and CATEGORY/PRODUCT scaffolds. Without a dedicated WF-R01.3.4 charter, operators risk:

1. **Re-implementing shell work** — duplicating HEADER_NAV, BREADCRUMBS, PAGINATION, or global shell policy.
2. **Conflating control surfaces** — merging FILTERS, SEARCH, sorting, pagination, and grid markup into monolithic blocks.
3. **Inventing Registry vocabulary** — creating `CATALOG_GRID`, `LISTING_CARD`, or new PDP zone `block_id` rows.
4. **Premature G2 claims** — treating charter ACCEPTED or partial catalog work as G2 CLOSED.
5. **Vertical profile drift** — treating MANUFACTURER/AUTO as new `site_type_code` or block families.

WF-R01.3.4 closes the **catalog reference gap**: FILTERS/SEARCH policy, grid/card boundaries, PLP/PDP scaffold contracts, catalog composition path, vertical profile binding — **without** repeating WF-R01.3.3 shell waves.

## 13. Vertical Profile Policy

### Definition

```text
Vertical Profile = binding layer that adapts canonical catalog/page references
to a business vertical without creating a new universal vocabulary family.
```

### Allowed adaptations (documentation + composition binding)

| Adaptation | Example |
|------------|---------|
| Required attributes | Manufacturer SKU, dealer stock flags |
| Dominant card fields | Spec summary vs price vs RFQ CTA |
| Comparison needs | Feature matrix emphasis |
| Filter facets | Industry-specific facet groups inside `FILTERS` |
| Commercial fields | RFQ vs price-on-request |
| Trust signals | Certificates, warranty badges |
| Media requirements | Gallery depth, datasheet links |
| Category hierarchy | Deep vs shallow taxonomy notes |
| PDP emphasis | Spec table vs gallery-first |

### Forbidden reinterpretations

```text
Vertical Profile ≠ new site_type_code
Vertical Profile ≠ new page_type family
Vertical Profile ≠ new block family (F1–F6)
Vertical Profile ≠ client-specific production theme

```
