# MARS Website Factory - Section Language Governance

**Status:** **documented** - Website Factory section language governance and human-supervised visual/compositional continuity methodology only.  
**Not:** design system generator, style linter, automatic section composer, or universal visual language law.

**Core principle:** sections need a shared language of density, spacing, hierarchy, CTA behavior, and composition so a page feels intentionally built.

**Related layers:** [vertical-rhythm-governance.md](vertical-rhythm-governance.md), [typography-rhythm-governance.md](typography-rhythm-governance.md), [content-density-governance.md](content-density-governance.md), [commercial-density-governance.md](commercial-density-governance.md), [design-system-intent-governance.md](design-system-intent-governance.md), [atmosphere-continuity-governance.md](atmosphere-continuity-governance.md).  
**Forge findings category:** `SECTION LANGUAGE FINDINGS`.

---

## 1. Purpose

Section Language Governance names the recurring visual and compositional language that lets independent sections cohere without becoming identical.

It covers:

- section language;
- density language;
- spacing language;
- hierarchy language;
- CTA language;
- compositional language;
- visual-language continuity;
- section rhythm survivability.

---

## 2. Language Dimensions

| Dimension | Meaning |
|-----------|---------|
| **Density language** | How information weight changes across sections without random overload or emptiness. |
| **Spacing language** | How padding, gaps, and transitions express narrative rhythm. |
| **Hierarchy language** | How headings, proof, media, and CTAs signal priority consistently. |
| **CTA language** | How action surfaces repeat, escalate, or recede across the page. |
| **Compositional language** | How cards, bands, grids, foreground/background, and visual clusters are reused or varied. |
| **Visual-language continuity** | How sections feel related without flattening into sameness. |

---

## 3. Canonical Rules

- Keep section-level variation tied to page rhythm and business intent.
- Do not let each section import a different design language by convenience.
- Do not use identical spacing or density everywhere when the narrative requires pressure changes.
- Preserve CTA language across hero, mid-page, sticky, and final conversion moments.
- Check section language after reconstruction: source fidelity can pass locally while page language fragments globally.
- Record section language findings when density, spacing, hierarchy, CTA, or composition language breaks continuity.

---

## 4. Anti-Patterns

| Anti-pattern | Why it is drift |
|--------------|-----------------|
| **Section dialect drift** | Each section looks like a different template. |
| **Random density language** | Dense and light sections alternate without narrative reason. |
| **Spacing accent mismatch** | Section spacing breaks established rhythm or emotional pressure. |
| **CTA language split** | CTA forms, weight, tone, or rhythm diverge without strategy. |
| **Compositional language break** | Cards, bands, overlays, and grids change logic section by section. |
| **Visual-language flattening** | All sections become uniform and lose purposeful emphasis. |

---

## 5. Drift Patterns

- **Visual-language continuity drift** - sections no longer read as one page system.
- **Section rhythm survivability drift** - rhythm collapses after responsive or scoped implementation changes.
- **Hierarchy language drift** - section priorities use conflicting visual grammar.
- **CTA language drift** - conversion language becomes inconsistent or diluted.

---

## 6. Triumph V3 Lesson

Triumph V3 showed that first-screen fixes alone cannot protect the page if downstream section language, CTA rhythm, density language, and atmospheric rhythm fragment.

The governance lesson is continuity of section language. It is not a requirement to make every section visually identical.

---

## 7. SAFE UNKNOWN

Record **SAFE UNKNOWN** when:

| Situation | Why it is unknown |
|-----------|-------------------|
| Only one section source is available | Cannot judge page-wide section language. |
| CTA hierarchy is unresolved | Cannot evaluate CTA language continuity. |
| Density intent is undocumented | Cannot separate healthy pressure from overload. |
| Responsive behavior is missing | Cannot prove section rhythm survives mobile collapse. |
| Existing sections use conflicting languages | Requires source, strategy, or HITL authority. |

**Action:** report local confidence separately from page-language confidence.
