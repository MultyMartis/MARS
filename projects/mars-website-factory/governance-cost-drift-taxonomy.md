# Governance Cost Drift Taxonomy - Website Factory

**Status:** documented taxonomy for human-supervised Website Factory governance economics review.  
**Not:** automated detector, runtime cost monitor, financial audit system, universal economics law, or exhaustive proof of governance efficiency.

**Parent layer:** [governance-economics.md](governance-economics.md).  
**Cost model:** [operational-cost-awareness-model.md](operational-cost-awareness-model.md).

---

## 1. Purpose

This taxonomy names drift patterns where governance remains extensive, thorough-looking, or survivability-focused while becoming economically unhealthy.

It exists because Website Factory governance can fail not only through weak process, but also through expensive low-value process.

---

## 2. Drift Patterns

| Drift pattern | Definition | Typical symptom |
|---------------|------------|-----------------|
| **Governance cost blindness** | Governance is added or invoked without acknowledging time, attention, review load, validation effort, or handoff cost. | "Run everything" becomes default even when the scope is low-risk. |
| **Process cost inflation** | Process steps accumulate until the cost of operating governance grows faster than the value produced. | Reports expand while decision clarity does not improve. |
| **QA resource drain** | QA consumes disproportionate effort on low-risk, duplicated, or low-evidence-value checks. | Review time is spent proving minor reversible issues while critical risks wait. |
| **Operational overhead accumulation** | Rules, checklists, report blocks, and cross-links add background burden that slows routine operation. | Operators spend more time navigating governance than resolving the task. |
| **Diminishing governance returns** | Each additional governance step adds less value than its cost. | More validation produces no new decision, evidence, or confidence boundary. |
| **Review-cost imbalance** | Reviewer attention is allocated away from the highest-value risks. | Cosmetic or informational findings receive the same review weight as freeze or source authority risks. |
| **Validation-cost explosion** | Validation depth expands across many layers without proportional evidence value. | PASS requires a growing chain of checks even when only a targeted risk is in scope. |
| **Governance inefficiency** | Governance uses more effort than necessary to create the same evidence, clarity, or survivability. | Duplicate checks, repeated findings, and long explanations replace concise evidence. |
| **Survivability-to-cost mismatch** | Continuity, recovery, or handoff protection is either too costly for the risk or too light for the consequence. | Every small task gets archive-level continuity, or critical freeze work gets weak handoff evidence. |
| **Governance resource waste** | Time, attention, report space, or review capacity is spent on controls that do not materially improve outcomes. | Operators can name the process performed but not the value it created. |
| **Expensive low-value governance** | A high-cost governance path is applied to a low-value concern. | Full-depth review is used for a reversible, local, well-sourced change. |
| **Process-weight escalation** | Governance weight increases because more process feels safer, not because risk justifies it. | The method keeps adding subsections to avoid the discomfort of a scoped decision. |
| **Unsustainable governance complexity** | Governance becomes too costly to operate repeatedly across sessions, projects, or handoffs. | Future operators inherit a method that is technically complete but too heavy to use. |

---

## 3. Severity Heuristics

| Severity | Use when |
|----------|----------|
| **Informational** | Cost concern is visible but does not affect current decision, freeze, or handoff. |
| **Operational** | Cost overhead slows execution, lowers report readability, or consumes reviewer attention. |
| **Continuity** | Cost imbalance threatens handoff, compression, checkpoint readability, recovery, or future operation. |
| **High-criticality** | Cost drift hides critical risk, blocks safe freeze, distorts QA confidence, or prevents timely escalation. |
| **Meta-governance** | Economics controls themselves create layer duplication, cross-link sprawl, or governance architecture confusion. |

Severity should remain proportional. Not every expensive-looking step is drift; high cost can be justified by high consequence, strong uncertainty, or continuity need.

---

## 4. Drift Diagnostics

Ask:

- What did this governance cost buy?
- Did the cost produce new evidence or only repeat an existing finding?
- Was the cost justified by current risk, or by generic process habit?
- Did this validation improve confidence enough to justify its depth?
- Did review attention move toward or away from critical-path risk?
- Did survivability improve enough to justify added continuity overhead?
- Is report value density increasing or decreasing?
- Are we adding process because a named threshold was crossed, or because "more governance feels safer"?
- Would lightweight, targeted, optional-depth, escalation-only, or deferred handling preserve enough value?

---

## 5. Drift Responses

| Drift | Preferred response |
|-------|--------------------|
| Governance cost blindness | Name the cost driver and classify the cost layer. |
| Process cost inflation | Consolidate duplicate checks and scale depth to active risk. |
| QA resource drain | Reallocate QA to evidence gaps and critical-path risks. |
| Operational overhead accumulation | Keep only cross-links and report blocks that improve navigation or decisions. |
| Diminishing governance returns | Stop adding depth unless it changes confidence, escalation, freeze, or handoff. |
| Review-cost imbalance | Use risk weighting to protect reviewer attention. |
| Validation-cost explosion | Use adaptive governance to target validation depth. |
| Governance inefficiency | Replace ritual checks with concise evidence or explicit deferral. |
| Survivability-to-cost mismatch | Rebalance continuity detail against handoff need and risk consequence. |
| Governance resource waste | Remove from current scope, defer, or record as informational. |
| Expensive low-value governance | Scale down to lightweight, targeted, optional-depth, or no action. |
| Process-weight escalation | Require a named risk threshold before adding more process. |
| Unsustainable governance complexity | Use governance minimalism and meta-governance to preserve readability. |

---

## 6. Anti-Patterns

Forbidden drift language and behavior:

- "More governance always safer."
- "Full QA by default" when scope is low-risk and well-sourced.
- "Add another checklist" without naming new evidence value.
- "All layers must report" when many layers are not active in the current risk profile.
- "Survivability at any cost."
- "Longer report equals stronger governance."
- "More findings equals safer review."
- "Escalate everything uncertain" regardless of consequence.
- "Cost is not a governance concern."
- "Governance economics means weakening governance."

Governance economics does not argue for weak controls. It argues for controls whose cost is justified by value, risk, evidence, and survivability.

## 7. REPORT Vocabulary

Use these labels in **GOVERNANCE ECONOMICS FINDINGS** when material:

- cost layer;
- cost driver;
- value produced;
- efficiency concern;
- review-allocation concern;
- validation-cost concern;
- survivability-to-cost concern;
- diminishing-returns concern;
- scaled-down / scaled-up / unchanged / deferred decision;
- SAFE UNKNOWN.

---

## 8. SAFE UNKNOWN

Record **SAFE UNKNOWN** when:

- a cost drift pattern is suspected but cannot be proven;
- cost is visible but value cannot be measured from available evidence;
- scaling down might hide a critical risk;
- scaling up might create expensive low-value governance;
- review allocation cannot be evaluated;
- validation-cost explosion may exist but evidence boundaries are unclear;
- survivability-to-cost balance cannot be established.

**Action:** name the suspected drift, state the missing evidence, classify provisional severity, and decide whether to keep depth, target depth, scale down, defer, or escalate.
