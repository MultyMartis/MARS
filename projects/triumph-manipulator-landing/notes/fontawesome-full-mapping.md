# Recommended global icon strategy

1. **Основной вес (primary):** `fal` (Font Awesome 5 Pro Light) для маркетинговых иконок среднего и крупного размера: hero features, trust-benefits, hero trust, equipment spec icons, крупные декоративные акценты. Даёт «воздух» и премиальный вид на тёмных подложках при достаточном размере и контрасте `currentColor`.

2. **Вторичный вес:** `far` для сбалансированного UI: стрелки в кнопках (`arrow-right`), элементы, где light может теряться на градиенте или мелком размере без доработки токенов.

3. **Solid (`fas`):** узкий слой — FAQ `plus`/`minus`, inline-пули (`check`), телефон в CTA, **вся полоса stats** (`trust-stats`), мелкие примечания со `stopwatch`. Цель: читаемость и силуэт на тёмном фоне без утолщения всей страницы.

4. **Brands (`fab`):** только WhatsApp и Telegram; MAX — исключение, отдельный SVG.

5. **Отступы и ритм:** выравнивание по сетке компонента: иконка + `gap` не меньше 0.5–0.75em от текста в списках; в карточках — фиксированная ширина колонки иконки (как сейчас у `price-card__spec-icon`), чтобы не «плясала» типографика при смене начертания FA.

6. **Размеры (ориентиры поверх текущих `icon--*`):**  
   - Hero features / trust benefits (крупно): эквивалент ~24–32px по ключевому глифу.  
   - Equipment specs (`icon--md`): ~20–24px.  
   - Кнопки и FAQ (`icon--sm`): ~14–18px, с обязательным `fas` или проверкой контраста для `far`.  
   - Stats (`icon--2xl`): визуальный вес ближе к 28–36px; держать единый вес `fas` в полосе.

7. **Штрих / визуальный ритм:** после перехода на FA не копировать прежний stroke SVG; задать единые `font-size`, `line-height: 1`, опционально лёгкую оптическую компенсацию (`transform: translateY(1px)`) по итогам браузерной проверки. Для light на тёмном — не опускаться ниже читаемого размера без увеличения веса до `far`/`fas`.

# Potential problem icons

| Тема | Файл / контекст | Почему сложно | Практика |
|------|-----------------|---------------|----------|
| Манипулятор как тип техники | `manipulator-arm.svg` | Нет отдельного «knuckle boom» в FA 5.15.4 | Оставить `truck-loading` или рассмотреть `dolly-flatbed` / `industry` как альтернативы с A/B в макете. |
| Вылет стрелы | `boom-diagonal.svg` | Нет крановой стрелы | `expand-arrows-alt` — абстракция «вылет», не буквальная стрела. |
| Один SVG — два смысла | `document-verify.svg` в hero (НДС) и trust (без скрытых доплат) | Одна иконка не покрывает оба смысла с одинаковой силой | На этапе внедрения: **два ассета** — например hero → `file-invoice-dollar`, trust → `file-contract` или `handshake` (все три имени есть в `all.css`). |
| MAX | `max.svg` | Нет глифа в FA | Кастомный SVG. |
| Яндекс / Авито | `yandex_logo.svg`, `avito_logo.svg` | Товарные знаки | Только брендовые ассеты, не FA. |
| Дублирование метафоры | `weight-hanging` в hero и в equipment | Одинаковый глиф для «тоннаж» и «грузоподъёмность в карточке» | Допустимо для системности; если нужно различие — заменить одну из позиций на `weight` (тоже в `all.css`). |
