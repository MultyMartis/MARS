# Duplicate Layer Detection v1

## Status

Manual duplicate-detection guide. Not automated governance or repository analysis.

## Purpose

Find ORCA layers that repeat the same operational purpose with different names.

## Duplicate Signals

- duplicated methodology;
- repeated abstractions;
- same checklist under different labels;
- same boundary language without new use;
- multiple layers solving the same operator question;
- repeated PPC review loops;
- no distinct commercial decision value.

## Review Questions

- Does this layer change operator action?
- Does it reduce review time?
- Does it add evidence quality?
- Is it only a renamed abstraction?
- Can it be merged into an existing layer?

## Required Compression Discipline

Smaller can be better. Documentation has maintenance cost. Operator attention is limited. Low-value layers should be removed.

## Boundary

This guide rejects abstraction inflation, giant governance layering, fake sophistication, and documentation for its own sake.
