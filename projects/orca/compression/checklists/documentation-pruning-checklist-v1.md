# Documentation Pruning Checklist v1

## Status

Manual checklist. Not automated pruning or governance enforcement.

## Checklist

- document improves operator speed;
- document supports practical PPC action;
- document is not duplicated elsewhere;
- abstraction is necessary;
- maintenance cost is justified;
- stale content is removed or marked;
- low-value review loops are removed;
- operator fatigue is reduced.

## Prune When

- the document repeats existing guidance;
- it is theoretical-only;
- it creates non-operational complexity;
- it exists for fake sophistication;
- it does not improve commercial realism.

## Required Compression Discipline

Smaller can be better. Documentation has maintenance cost. Operator attention is limited. Low-value layers should be removed.

## Boundary

This checklist rejects documentation for its own sake, abstraction inflation, and giant governance layering.
