# Complexity Review Checklist v1

## Status

Manual complexity checklist. Not telemetry, dashboards, automation, or governance scoring.

## Complexity Checks

- duplicated methodology present;
- repeated abstractions present;
- low-signal documentation present;
- theoretical-only layers present;
- non-operational complexity present;
- excessive review loops present;
- operator fatigue amplified;
- stale docs create confusion.

## Action

- keep only practical PPC value;
- merge duplicates;
- compress templates;
- remove low-value layers;
- stop adding theory to solve theory.

## Required Compression Discipline

Smaller can be better. Operator attention is limited. Practical usability matters. Fake sophistication is dangerous.

## Boundary

This checklist rejects giant governance layering, abstraction inflation, methodology addiction, and pseudo-intelligence narratives.
