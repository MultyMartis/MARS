# ORCA Documentation Compression Layer v1

## Purpose

This layer protects ORCA from documentation bloat, duplicate methodology, and operator overload.

It supports pruning, duplicate detection, stale-document review, and operational usefulness checks.

## What This Layer Is

- Operational cleanup discipline.
- Anti-bloat methodology.
- Documentation maintenance aid.
- Operator usability protection.
- Practical survivability discipline.

## What This Layer Is Not

- Not governance expansion.
- Not AI architecture.
- Not automation, orchestration, dashboards, telemetry, or runtime systems.
- Not intelligence mythology.
- Not documentation for its own sake.

## Required Compression Discipline

- Smaller can be better.
- Practical usability matters.
- Documentation has maintenance cost.
- Operator attention is limited.
- Fake sophistication is dangerous.
- Low-value layers should be removed.
- Stale docs create operational confusion.
