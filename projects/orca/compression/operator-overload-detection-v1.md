# Operator Overload Detection v1

## Status

Manual overload guide. Not productivity telemetry, monitoring, dashboards, or automation.

## Purpose

Detect when ORCA documentation makes practical PPC review harder instead of easier.

## Overload Signals

- operator cannot find the right entrypoint quickly;
- too many layers answer the same question;
- review requires excessive switching;
- checklists repeat without priority;
- documentation volume delays action;
- operator fatigue increases;
- commercial decision quality does not improve.

## Compression Response

- merge duplicate guidance;
- remove low-value layers;
- shorten templates;
- keep only high-use PPC decisions;
- add stop rules where reviews expand.

## Required Compression Discipline

Operator attention is limited. Smaller can be better. Practical usability matters. Documentation has maintenance cost.

## Boundary

This guide rejects giant governance layering, methodology addiction, abstraction inflation, and documentation for its own sake.
