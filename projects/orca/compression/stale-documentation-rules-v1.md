# Stale Documentation Rules v1

## Status

Manual stale-document review. Not automated freshness monitoring, telemetry, or governance enforcement.

## Stale Documentation Signals

- guidance conflicts with current ORCA practice;
- documents describe unused review loops;
- terminology no longer matches operator usage;
- examples no longer support practical PPC decisions;
- boundaries are missing or misleading;
- stale docs create operational confusion.

## Review Response

- mark SAFE UNKNOWN when current use is unclear;
- update only if the document still has operator value;
- compress if the core value is small;
- remove or archive if low-value and confusing;
- avoid adding another layer to explain the stale layer.

## Required Compression Discipline

Documentation has maintenance cost. Stale docs create operational confusion. Operator attention is limited. Smaller can be better.

## Boundary

These rules reject documentation for its own sake, fake sophistication, giant governance layering, and abstraction inflation.
