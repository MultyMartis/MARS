# Low-Value Documentation Rules v1

## Status

Manual low-value documentation filter. Not automated classification or governance enforcement.

## Low-Value Documentation

- low-signal documentation;
- theoretical-only layers;
- repeated abstractions;
- non-operational complexity;
- excessive review loops;
- documents that amplify operator fatigue;
- stale docs that confuse review;
- pseudo-intelligence language with no PPC action.

## Remove Or Compress When

- no practical operator action is supported;
- the content repeats another layer;
- maintenance cost exceeds usefulness;
- the document increases review time;
- the layer exists to appear sophisticated.

## Keep Only If

- it protects PPC decision quality;
- it improves speed;
- it simplifies review;
- it preserves commercial realism.

## Required Compression Discipline

Practical usability matters. Documentation has maintenance cost. Fake sophistication is dangerous. Low-value layers should be removed.

## Boundary

These rules reject documentation for its own sake, abstraction inflation, and pseudo-intelligence narratives.
