# Mobile-First SERP Logic v1

## Purpose

Documents heuristics for PPC strategy when mobile SERP behavior is commercially dominant. Mobile-first logic requires device-specific evidence.

## Heuristic

When mobile SERPs compress attention around ads, local pack, calls, messenger CTAs, and fast-response claims, campaign and landing strategy may need mobile-first review before desktop assumptions are reused.

## Evidence Basis

Use only when observations show:

- mobile-heavy local pack visibility;
- tap-to-call prominence;
- WhatsApp or messenger visibility;
- strong above-the-fold compression;
- fast-response CTAs;
- reduced form tolerance signals.

## Operational Guidance

- Review mobile SERP separately from desktop.
- Prioritize first-screen CTA clarity where evidence supports it.
- Keep trust proof compressed and visible.
- Avoid long form-first paths for urgent mobile intent unless validated.
- Treat desktop findings as separate evidence.

## Contradiction Sensitivity

Reduce confidence when:

- desktop and mobile SERPs differ sharply;
- mobile evidence is single-snapshot only;
- local pack behavior is unstable;
- region or personalization risk is high.

## SAFE UNKNOWN

- actual mobile conversion rate;
- user scroll depth;
- personalization effect;
- stability across devices;
- call quality.

## Boundary

This heuristic guides human mobile PPC review. It is not mobile automation, telemetry, browser automation, or autonomous optimization.
