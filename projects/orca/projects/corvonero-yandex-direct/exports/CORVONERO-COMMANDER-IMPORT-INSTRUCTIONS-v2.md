# Инструкция импорта — Direct Commander — Корво Неро v2

**Файл импорта:** `exports/CORVONERO-YANDEX-DIRECT-COMMANDER-v2.xlsx`  
**Файл проверки (не для импорта):** `exports/CORVONERO-CAMPAIGN-REVIEW-v2.xlsx`  
**Статус v1:** SUPERSEDED — `CORVONERO-YANDEX-DIRECT-COMMANDER-v1.xlsx` не использовать  
**Статус v2:** структурно проверен в ORCA; **финальный import check — оператором в Директ Коммандере**  
**Запуск рекламы не авторизован** — посадочные URL ещё не опубликованы.

---

## 1. Модель выгрузки v2

| Параметр | Значение |
|----------|----------|
| Кампаний в XLSX | **1** (единая перфоманс-кампания) |
| Групп в XLSX | **48** (все активные) |
| Маркеры направлений | `[C01]` … `[C08]` в **начале названия каждой группы** |
| UTM campaign | `corvonero_1c_search_nsk` (единый) |
| UTM content | `<group_id>` (например `CORV-G01-01`) |
| UTM term | `{keyword}` |
| Разделение на 8 кампаний | **отложено** — выполняется после операторской проверки |

Пример названия группы: `[C02] Доработка конфигурации 1С`

---

## 2. Резервная копия

1. Откройте Яндекс Директ Коммандер.
2. **Файл → Экспорт → Экспортировать в Excel** — сохраните backup с датой.
3. Для dry-run используйте тестовый аккаунт, если доступен.

---

## 3. Импорт XLSX v2

1. **Файл → Импорт → Импортировать из Excel**.
2. Выберите `CORVONERO-YANDEX-DIRECT-COMMANDER-v2.xlsx`.
3. Лист **«Тексты»** — источник данных.
4. **Не отправляйте на модерацию** до проверки и публикации посадочных страниц.

---

## 5. Что не импортируется из XLSX

- Название кампании (только metadata-блок)
- Дневной/недельный бюджет
- Стратегия автоматических ставок (ручные ставки)
- Расписание показов
- Корректировки по устройствам
- Метрика и цели
- Визитка / телефон / организация Яндекс Бизнеса
- Изображения объявлений

## 7. Будущее разделение кампаний

После операторской проверки единого файла:

1. Создать 8 кампаний по маркерам `[C01]`–`[C08]`.
2. Перенести группы по префиксу в названии.
3. Применить direction-level UTM (`corv_general_1c`, `corv_modifications`, …) — см. `production/direct-commander-production-dataset-v2.json` → `logical_directions`.
4. Сгенерировать отдельные XLSX (финальный этап — не в scope v2).
