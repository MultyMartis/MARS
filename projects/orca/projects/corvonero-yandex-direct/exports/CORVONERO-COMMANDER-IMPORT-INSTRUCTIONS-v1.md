# Инструкция импорта — Direct Commander — Корво Неро v1

**Файл:** `exports/CORVONERO-YANDEX-DIRECT-COMMANDER-v1.xlsx`  
**Статус:** **SUPERSEDED** — заменён v2 (`CORVONERO-YANDEX-DIRECT-COMMANDER-v2.xlsx`)  
**Не использовать для импорта.** См. `CORVONERO-COMMANDER-IMPORT-INSTRUCTIONS-v2.md`.  
**Запуск рекламы не авторизован** — посадочные URL ещё не опубликованы.

---

## 1. Резервная копия текущих данных Коммандера

1. Откройте Яндекс Директ Коммандер.
2. Выберите аккаунт Корво Неро (или тестовый аккаунт для dry-run).
3. **Файл → Экспорт → Экспортировать в Excel** — сохраните текущий XLSX с датой в имени, например `corvonero-commander-backup-2026-06-22.xlsx`.
4. При наличии черновиков кампаний — экспортируйте их отдельно или зафиксируйте скриншот структуры.

---

## 2. Импорт XLSX

1. **Файл → Импорт → Импортировать из Excel**.
2. Выберите `CORVONERO-YANDEX-DIRECT-COMMANDER-v1.xlsx`.
3. Подтвердите лист **«Тексты»** как источник данных.
4. **Не отправляйте на модерацию** до проверки и публикации посадочных страниц.

---

## 3. Тип кампании

В metadata-блоке файла указано:

- **Тип кампании:** «Единая перфоманс-кампания»
- **Места показа:** search (только поиск)
- **Объект продвижения:** `https://lk.corvonero.ru/`

При импорте подтвердите:

- тип кампании соответствует возможностям аккаунта (ЕПК или текстово-графическая — сверить со «Словарь значений полей»);
- **только поиск**, без РСЯ и рекомендаций.

**Важно:** XLSX содержит **48 групп** всех 8 кампаний ORCA в одном transport-файле (ограничение шаблона — один metadata-блок). После импорта **распределите группы по 8 кампаниям** по префиксу в названии группы (`CORV-C01 — …` … `CORV-C08 — …`) или создайте 8 кампаний и перенесите группы вручную.

## 5. Поля, которые могут не импортироваться из XLSX

- Название кампании (не в data table — только metadata)
- Дневной/недельный бюджет
- Стратегия автоматических ставок (используются **ручные** ставки)
- Расписание показов
- Корректировки по устройствам
- Привязка Метрики и целей
- Визитка / телефон / организация Яндекс Бизнеса
- Изображения объявлений (колонки очищены — search-only export)

## 7. Не отправлять на модерацию до публикации URL

Все 31 посадочная страница в статусе **PLANNED — PAGE NOT YET PUBLISHED**.  
Импорт и проверка структуры допустимы; **запуск показов** — только после:

1. Публикации URL из `production/url-landing-map-v1.md`
2. Проверки форм и контактов на каждой странице
3. Явной авторизации запуска оператором

---

## 8. Проверка ставок

- Колонка «Ставка» — phrase-level bids (T1: 450–550 ₽ … T4: 180–250 ₽)
- Убедитесь, что нет нулевых ставок
- Внутри группы — spread 10–90 ₽ (не flat)

---

## 9. Проверка минус-фраз

- **Глобальные:** metadata block «Минус-фразы на кампанию»
- **Групповые:** колонка «Минус-фразы на группу» на первой ad-строке группы
- **Фразовые:** inline в «Фраза (с минус-словами)» для head-групп (G01-01, G06-03, G07-01)

---

## 10. Пробный импорт без запуска

1. Используйте **тестовый** или пустой сегмент аккаунта, либо импортируйте в черновик.
2. Проверьте количество сущностей и отсутствие ошибок валидации Коммандера.
3. **Не включайте** кампании и **не отправляйте** объявления на модерацию.
4. Зафиксируйте observations в операторском логе (Stage 2D manual check).
