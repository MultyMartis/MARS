# Evidence Quality Checklist v1

- [ ] Source is traceable.
- [ ] Timestamp is present.
- [ ] Region is present.
- [ ] Niche is present.
- [ ] Device or channel context is present.
- [ ] Visible fact is separated from interpretation.
- [ ] Screenshot or manual review reference exists when needed.
- [ ] Contradictions are linked.
- [ ] Freshness is reviewed.
- [ ] Confidence does not exceed evidence strength.
