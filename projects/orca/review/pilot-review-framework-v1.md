# Pilot Review Framework v1

## Purpose

Defines how ORCA pilot cases are reviewed for evidence quality, commercial usefulness, methodology fit, contradictions, and reusable insight.

A pilot case is a bounded learning artifact. It is not proof of universal market behavior.

## Review Areas

- pilot objective clarity;
- evidence traceability;
- local-service and PPC realism;
- methodology fit;
- QA findings;
- contradiction review;
- confidence review;
- heuristic candidates;
- stale pattern risk;
- regional and niche transfer limits.

## Pilot Usefulness Questions

- Did the pilot produce evidence-backed findings?
- Are observations separated from recommendations?
- Are contradictions visible?
- Are confidence limits clear?
- Are reusable heuristics bounded?
- Is the output useful for a real human operator?
- Are commercial unknowns preserved?

## Failure Signals

- pilot summary overstates evidence;
- local context is missing;
- findings are too abstract to guide PPC review;
- contradictions are smoothed away;
- a single case is treated as a broad rule;
- strategic recommendations ignore commercial reality;
- evidence cannot be traced.

## Boundary

This framework supports human pilot review. It is not autonomous pilot scoring, automatic optimization, runtime orchestration, or market intelligence automation.
