# Methodology Review Framework v1

## Purpose

Defines how ORCA methodologies are reviewed for usefulness, evidence realism, commercial practicality, and operational survivability.

Methodology review protects ORCA from process bloat and theoretical elegance that does not help real PPC work.

## Review Questions

- Does the methodology help a human reviewer make a clearer decision?
- Does it separate observation from interpretation?
- Does it require traceable evidence?
- Does it preserve contradictions?
- Does it expose region, niche, device, and season limits?
- Does it reduce ambiguity or add unnecessary ceremony?
- Does it remain practical for repeated use?

## Stress Tests

Apply these stress tests:

- weak evidence test - does the method prevent overclaiming?
- contradiction test - does it keep conflicts visible?
- stale evidence test - does it degrade reliability when evidence ages?
- local-service test - does it remain useful in real local PPC conditions?
- reviewer load test - can a human use it without review fatigue?
- transfer test - does it prevent unsupported region or niche transfer?

## Failure Signals

- too many fields without decision value;
- abstract categories that do not change review outcomes;
- confidence language unsupported by evidence;
- hidden assumptions about automation;
- duplicate workflow with another ORCA layer;
- unclear reviewer responsibility;
- missing SAFE UNKNOWN handling.

## Boundary

This framework supports human methodology review. It is not automatic methodology optimization, self-improvement, runtime governance, or autonomous review.
