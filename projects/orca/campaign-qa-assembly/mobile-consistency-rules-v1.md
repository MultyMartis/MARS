# Mobile Consistency Rules v1

## Purpose

Review whether mobile search behavior is supported by ad, extension, and landing choices.

## Checks

- mobile ad is readable;
- extension set is not cluttered;
- primary CTA is visible;
- phone path works;
- WhatsApp path is clear if used;
- landing first screen confirms service;
- trust appears early enough;
- form friction is acceptable.

## Risk Signals

- mobile clutter;
- hidden CTA;
- slow contact access;
- trust proof buried;
- urgent mobile traffic sent to generic page;
- desktop assumptions applied to mobile behavior.

## Boundary

ORCA does not optimize mobile delivery or measure mobile conversion. Human review is mandatory.
