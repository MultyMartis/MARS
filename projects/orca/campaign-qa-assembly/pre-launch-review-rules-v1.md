# Pre-Launch Review Rules v1

## Purpose

Support a practical human review before any campaign is prepared for launch.

## Required Checks

- campaign naming;
- geo consistency;
- semantic cleanliness;
- keyword-to-ad alignment;
- ad-to-landing alignment;
- CTA consistency;
- trust support;
- mobile usability;
- negative keywords;
- extension relevance;
- unsupported claims.

## Review Rule

Pre-launch review should find blockers, not create giant theory.

If a check does not affect PPC relevance, trust, CTA, geo, mobile behavior, or operational risk, keep it short.

## Boundary

ORCA does not approve launch. Human review and platform-specific checks are mandatory.
