# ORCA Campaign QA Assembly Layer

## Purpose

This layer supports lightweight, human-reviewed campaign QA before any manual platform preparation.

It helps operators review semantic consistency, landing alignment, CTA consistency, geo consistency, mobile consistency, fragmentation, and final campaign risks.

## What This Layer Is

- PPC campaign review discipline.
- Pre-launch review support.
- Final assembly QA preparation.
- Manual risk review.

## What This Layer Is Not

- Not autonomous launch approval.
- Not autonomous campaign QA.
- Not Direct API integration.
- Not campaign optimization.
- Not telemetry or runtime orchestration.

## Required Discipline

- ORCA does not launch campaigns.
- Human review is mandatory.
- Operational simplicity matters.
- Semantic cleanliness matters.
- Fragmentation risks exist.
- Contextual review matters.
- Evidence quality matters.
