# Mobile Review Checklist v1

## Status

Manual mobile QA checklist. Not mobile optimization automation.

## Checklist

- ad is readable on mobile;
- extensions are not cluttered;
- service is clear quickly on landing;
- primary CTA is visible;
- click-to-call path is clear;
- WhatsApp path is clear if used;
- form friction is acceptable;
- trust appears early enough;
- urgent intent has fast contact path;
- pricing or estimate logic is understandable;
- SAFE_UNKNOWN recorded.

## Boundary

ORCA does not measure mobile performance or optimize campaigns autonomously.
