# Tasks

## Eyebrow

Что выполняем по контейнерным заявкам

## H2

Контейнерные задачи, с которыми работаем

## Allowed tasks

- Перевозка контейнеров по Краснодару и краю
- Доставка контейнера на строительный объект
- Перевозка складского контейнера
- Погрузка и разгрузка контейнера стрелой
- Перемещение контейнера по территории объекта
- Доставка контейнера на участок, базу или склад

## Note label

Важно перед подачей

## Note text

Для точного расчета заранее уточняем тип контейнера, вес, размеры, адрес подачи, подъезд и точку разгрузки.

## Denied title

Что не выполняем

## Denied list

- Контейнеры вне параметров машины
- Перевозка при неизвестном весе без уточнения
- Негабаритные задачи без предварительного согласования
- Опасные грузы
- Эвакуация автомобилей
