# Essential Signals Model v1

## Status

Manual prioritization model. Not automated scoring, telemetry, AI optimization, or runtime intelligence.

## Purpose

Help an operator separate decision-useful PPC evidence from low-value observation volume.

## Essential Signal Definition

An essential signal is visible evidence that is:

- commercially relevant;
- strong enough to affect PPC action;
- tied to SERP, trust, semantic, landing, offer, urgency, local, aggregator, CTA, or mobile behavior;
- clearer than ordinary noise;
- safe to describe without unsupported certainty.

## Priority Order

1. Clear PPC risk.
2. Dominant commercial pattern.
3. Strong evidence with obvious operator action.
4. Medium evidence that should be verified.
5. SAFE UNKNOWN.

## Compression Discipline

- Signal quality matters more than volume.
- Weak signals should not dominate review time.
- Noise creates false complexity.
- Observation inflation makes reviews harder to use.

## Boundary

This model rejects fake sophistication, abstraction overload, unsupported signal importance, and pseudo-intelligence narratives.
