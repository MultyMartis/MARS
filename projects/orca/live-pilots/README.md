# ORCA Live Pilots

## Purpose

This folder contains small, human-run ORCA pilot packages for real SERP review.

Each pilot package should help an operator prepare, observe, and record evidence from a live search session without turning the work into automation, scraping, telemetry, dashboards, or a large methodology layer.

## Operating Rules

- Run manually.
- Use real SERP observation.
- Save or reference screenshots where useful.
- Keep notes short and evidence-linked.
- Separate observed facts from interpretation.
- Preserve uncertainty.
- Stop if the process becomes too heavy to repeat.

## Current Pilot Packages

- `manipulator-krasnodar-live-v1/` - first live human-reviewed SERP pilot package for manipulator services in Krasnodar.

## Boundary

Live pilots are operator execution packages. They are not runtime systems, browser agents, autonomous PPC intelligence, monitoring, or proof of market-wide truth.
