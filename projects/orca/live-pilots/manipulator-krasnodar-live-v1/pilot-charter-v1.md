# Pilot Charter v1

## Pilot Identity

- pilot name: Manipulator Krasnodar Live SERP Review v1
- niche: manipulator truck / crane-manipulator rental and related local transport services
- region: Krasnodar
- session type: live human-reviewed SERP observation
- primary use: practical PPC research preparation

## Goal

Understand the visible search environment for manipulator services in Krasnodar well enough to support early PPC decisions about query risk, competitor positioning, trust signals, CTA patterns, and landing expectations.

This pilot should produce small, evidence-aware observations. It should not produce final campaign truth.

## Operator Scope

The operator may:

- manually search selected queries;
- capture SERP screenshots;
- open visible competitor pages;
- record obvious ads, local pack, aggregator, CTA, pricing, and trust patterns;
- write conservative PPC implications.

The operator should not:

- scrape SERPs;
- automate browser behavior;
- infer conversion performance;
- claim market-wide certainty;
- create new methodology layers;
- expand beyond the pilot query set unless clearly needed.

## Review Constraints

- Use one focused review session where possible.
- Prefer 5-10 queries.
- Review mobile and desktop separately.
- Open only a small number of visible competitors.
- Keep notes short.
- Mark contradictions instead of resolving them by guesswork.

## Device Scope

- mobile SERP: required if available;
- desktop SERP: required if available;
- local pack: review where present;
- maps or business profile behavior: note only if visible during normal manual review.

## Operational Limits

- No automation.
- No scraping.
- No browser agents.
- No telemetry.
- No dashboards.
- No PPC platform changes.
- No claim that findings are stable beyond the session.

## Evidence Limitations

SERP results may be affected by location, personalization, time of day, device, language, search engine behavior, ad auction volatility, and competitor budget changes.

All findings from this pilot are bounded by the observed screenshots, timestamps, queries, device contexts, and operator notes.
