# Manipulator Krasnodar Live Pilot v1

## Purpose

Prepare one lightweight, human-reviewed ORCA pilot session for live SERP analysis in the manipulator services niche in Krasnodar.

The package is designed for one focused operator session using manual search, screenshots, short notes, and conservative PPC observations.

## Suggested Use

1. Read `pilot-charter-v1.md`.
2. Run the queries from `query-list-v1.md` manually.
3. Capture mobile and desktop SERP screenshots where practical.
4. Fill only the notes that are useful for the session.
5. Record uncertainty in `safe-unknown-review-v1.md`.
6. Finish with `operational-review-v1.md`.

## Files

- `pilot-charter-v1.md` - scope, limits, and evidence boundaries.
- `query-list-v1.md` - small query set for live review.
- `mobile-review-notes-v1.md` - mobile SERP notes.
- `desktop-review-notes-v1.md` - desktop SERP notes.
- `local-pack-review-notes-v1.md` - local pack notes.
- `competitor-review-notes-v1.md` - visible competitor landing notes.
- `semantic-risk-notes-v1.md` - query and intent risk notes.
- `trust-pattern-notes-v1.md` - trust, CTA, and proof observations.
- `strategic-observations-v1.md` - bounded PPC observations.
- `confidence-review-v1.md` - certainty limits.
- `safe-unknown-review-v1.md` - missing and unstable evidence.
- `operational-review-v1.md` - usefulness and friction review.

## Boundary

This is a practical live review package. It does not create automation, scraping, browser agents, runtime orchestration, telemetry, dashboards, or autonomous PPC intelligence.
