# Query List v1

## Use

Run these queries manually. Record the search engine, device, timestamp, approximate location context, and screenshot reference where available.

Do not expand the list during the first pass unless a query clearly fails to show the market.

## Core Commercial Queries

- `манипулятор краснодар`
- `заказать манипулятор краснодар`
- `аренда манипулятора краснодар`

## Urgent-Intent Queries

- `манипулятор срочно краснодар`
- `вызвать манипулятор краснодар`

## Geo-Modified Queries

- `манипулятор краснодар недорого`
- `манипулятор краснодар прикубанский`

## Equipment / Service Ambiguity Queries

- `кран манипулятор краснодар`
- `манипулятор 5 тонн краснодар`

## Aggregator-Sensitive Query

- `услуги манипулятора краснодар`

## Notes

- Watch for whether results mix rental, cargo delivery, crane work, towing, construction material delivery, and private owner offers.
- If one query is clearly too broad, mark it as semantic risk instead of replacing the whole list.
