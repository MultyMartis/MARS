# PPC Failure Patterns Model v1

## Status

Manual review model. Not autonomous diagnosis, automation, optimization, telemetry, or root-cause proof.

## Purpose

Help an operator recognize recurring PPC failure patterns and decide what deserves human review.

## Common Failure Pattern Families

- broad semantic pollution;
- low-commercial-intent contamination;
- wrong-service traffic;
- weak CTA alignment;
- trust collapse;
- fake urgency;
- pricing mismatch;
- geo mismatch;
- mobile friction;
- excessive fragmentation;
- operator overload;
- weak landing clarity.

## Evidence Standard

A failure pattern should be treated as a candidate, not a conclusion. Stronger evidence may include repeated search-term mismatch, visible landing friction, consistent trust gaps, or clear contradiction between query, ad, and landing page.

## Required Reality Discipline

- PPC failure is contextual.
- Evidence quality matters.
- Human review is mandatory.
- Failures can have multiple causes.
- Weak evidence can mislead.
- Fake certainty is dangerous.
- Operational simplicity matters.

## Boundary

This model rejects autonomous diagnosis, fake root-cause certainty, unsupported attribution claims, and fake optimization certainty.
