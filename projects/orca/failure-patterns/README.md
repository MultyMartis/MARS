# ORCA PPC Failure Patterns Layer v1

## Purpose

This layer helps a human PPC operator notice common failure patterns without pretending to diagnose root causes automatically.

It supports practical review of semantic pollution, landing mismatch, trust collapse, fake urgency, mobile friction, operator overload, and low-quality lead risk.

## What This Layer Is

- PPC failure-pattern awareness.
- Commercial realism review support.
- Evidence-aware operator discipline.
- Human-supervised failure detection aid.
- Lightweight review structure.

## What This Layer Is Not

- Not autonomous diagnosis.
- Not an AI reasoning engine.
- Not automation, orchestration, telemetry, dashboards, or runtime systems.
- Not fake optimization certainty.
- Not proof of root cause.

## Required Reality Discipline

- PPC failure is contextual.
- Evidence quality matters.
- Human review is mandatory.
- Failures can have multiple causes.
- Weak evidence can mislead.
- Fake certainty is dangerous.
- Operational simplicity matters.
