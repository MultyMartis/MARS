# Operational Minimalism Rules v1

## Status

Manual minimalism rules. Not automation, orchestration, governance expansion, or intelligence architecture.

## Purpose

Keep PPC review useful by reducing scope to the smallest set of high-impact signals.

## Minimalism Rules

- review only strong semantic risks;
- review only strong landing mismatch;
- review only strong trust failures;
- review only major mobile friction;
- review only major CTA failures;
- review only strong aggregator pressure;
- review only high commercial-impact signals.

## Deprioritize

- cosmetic observations;
- weak unsupported patterns;
- endless nuance;
- speculative abstraction;
- low-impact differences.

## Required Minimalism Discipline

Not everything deserves analysis. Speed matters. Practical action matters. Operator energy matters. Diminishing returns exist. High-impact signals matter most. Theory expansion reduces usefulness.

## Boundary

These rules reject giant audits, fake completeness, endless observation loops, abstraction addiction, and methodology obsession.
