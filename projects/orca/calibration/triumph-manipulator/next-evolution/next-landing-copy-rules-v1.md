# Next Landing Copy Rules v1

Derived from Triumph calibration loop v1 — apply to **new** packs and handoffs.

## Global locks (all 12 PPC routes)

1. **One machine** — fixed specs unless route is explicitly another capability (6×6, etc.)
2. **No fleet language** in hero or specs
3. **No fake hero price**
4. **Price honesty** — «по задаче», factors not fabricated tariff
5. **Geo** — Краснодар + край unless intercity route
6. **Anti-evacuation** — qualification or denied block required
7. **Reviews** — Яндекс + Авито only; no invented quotes
8. **Messenger order** — MAX → Telegram → WhatsApp
9. **Robots** — `noindex,nofollow` until operator opens indexing
10. **CTA labels** — declare primary string; Factory may not synonym-swap without override

## Hero copy rules

| Rule | Detail |
|------|--------|
| H1 | Must list primary ad verb + geo OR document multi-ad strategy |
| Lead | One capability anchor (тоннаж) even on master hot |
| Specs | Exactly five bullets when machine is 5 т class |
| Trust hero | Pick `social` \| `ops` \| `hybrid` in pack — no silent swap |
| Qualification | One sentence if anti-evacuation in doctrine |

## CTA copy rules

## Drift tolerance

| Change | Allowed without override? |
|--------|---------------------------|
| `&nbsp;` typography | yes |

| H1 intent verb change | **no** |
