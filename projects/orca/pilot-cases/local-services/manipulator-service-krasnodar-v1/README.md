# ORCA Pilot Case: Manipulator Service Krasnodar v1

## Purpose

This package is a fictionalized operational simulation for a local manipulator / cargo transportation service in Krasnodar. It tests ORCA research workflow, evidence discipline, semantic QA, landing analysis, and contradiction handling.

It is demonstration-only. It is not live market evidence, production intelligence, campaign automation, scraping output, browser-agent output, telemetry, or automatic campaign management.

## Case Identity

- `case_id`: `orca-local-manipulator-krasnodar-v1`
- `niche`: manipulator truck service / cargo transportation with crane
- `region`: Krasnodar, Russia
- `search_engine_context`: simulated local commercial SERP
- `device_context`: mobile-heavy, mixed desktop uncertainty
- `status`: draft pilot simulation
- `validation`: not externally validated

## Boundary

All observations are hypothetical, region-bound, time-bound, and require human review before reuse. Regional variation, SERP volatility, personalization, seasonality, and incomplete evidence may change the interpretation.
