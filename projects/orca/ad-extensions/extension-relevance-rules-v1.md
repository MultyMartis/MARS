# Extension Relevance Rules v1

## Purpose

Check whether extensions reinforce the ad, query, landing, and service context.

## Relevance Areas

- local relevance;
- service relevance;
- CTA relevance;
- trust reinforcement;
- mobile readability;
- landing support;
- commercial intent support.

## Good Relevance

An extension is useful when it helps the user understand the service, trust the provider, or contact the business faster.

## Weak Relevance

An extension is weak when it:

- repeats the headline;
- points to a generic page;
- adds unsupported claims;
- distracts from the CTA;
- does not match the query intent;
- creates mobile clutter.

## Boundary

ORCA does not decide final extension use autonomously. Human review is mandatory.
