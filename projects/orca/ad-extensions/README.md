# ORCA Ad Extensions Layer

## Purpose

This layer supports lightweight, human-reviewed preparation of PPC ad extensions for local-service search campaigns.

It covers sitelinks, callouts, structured snippets, contact-oriented extensions, WhatsApp-oriented messaging, mobile-first extension logic, and relevance review.

## What This Layer Is

- Extension preparation guidance.
- Local-service PPC assembly support.
- Manual relevance review.
- Mobile and fast-contact review support.

## What This Layer Is Not

- Not autonomous extension generation.
- Not Direct API integration.
- Not upload tooling.
- Not campaign launch or optimization.

## Required Discipline

- Extensions remain contextual.
- Human review is mandatory.
- Extension overload risks exist.
- Misleading claims are forbidden.
- Mobile behavior matters.
- Operational clarity matters.
- Fake trust claims are forbidden.
