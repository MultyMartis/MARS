# Mobile Extension Rules v1

## Purpose

Keep extension choices readable and useful on mobile search results.

## Mobile Priorities

- quick scanning;
- short wording;
- clear contact path;
- service relevance;
- local relevance;
- trust reinforcement;
- reduced clutter.

## Mobile Review Questions

- Does the extension help a user act faster?
- Is the wording too long?
- Does it duplicate the ad?
- Is the CTA clear?
- Does it support phone or WhatsApp behavior?
- Is trust visible without overload?

## Risks

- extension overload;
- weak readability;
- competing CTAs;
- generic trust phrases;
- clutter hiding the main action.

## Boundary

ORCA does not optimize mobile delivery or device settings. Human review is mandatory.
