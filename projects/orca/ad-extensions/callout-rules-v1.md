# Callout Rules v1

## Purpose

Guide short callout messages that reinforce service, trust, and response clarity.

## Good Callouts

- clear service benefit;
- real local availability;
- verified response detail;
- supported trust proof;
- simple estimate logic;
- operationally true contact path.

## Avoid

- fake guarantees;
- fake urgency;
- vague superiority claims;
- unsupported "best" language;
- misleading cheapness;
- duplicate phrases already in headline.

## Review Questions

- Is the claim true?
- Is it useful for this intent?
- Is it readable quickly?
- Does landing evidence support it?
- Does it create clutter?

## Boundary

Callouts remain contextual drafts. ORCA does not upload or optimize them autonomously.
