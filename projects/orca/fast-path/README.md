# ORCA Fast Path

## Purpose

Fast Path is the ultra-thin ORCA decision mode.

Use it when the operator needs one useful PPC decision fast and must avoid document gravity.

## Default Path

1. Open `../OPERATIONAL-INDEX.md`.
2. Open one primary review only.
3. Add one support signal only if the decision is blocked.
4. Write top 3 findings.
5. Make the next PPC decision or mark SAFE UNKNOWN.
6. Stop.

## Hard Limits

- One PPC object.
- One primary review.
- One support signal.
- Three findings.
- One decision.
- No methodology browsing.
- No governance reading during session.
- No "just one more review."

## Goal

Make one good PPC decision fast.

Do not produce a large analysis.
