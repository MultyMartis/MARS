# One Primary Review Rule v1

## Rule

One session gets one primary review.

Opening a second primary review means the session has split into a new task.

## Primary Review Choices

- SERP pressure: `../fast-review/mobile-serp-review-v1.md`
- Landing mismatch: `../fast-review/landing-mismatch-review-v1.md`
- CTA clarity: `../fast-review/cta-pattern-review-v1.md`
- Mobile friction: `../fast-review/mobile-friction-review-v1.md`
- Semantic waste: `../essential-signals/semantic-contamination-v1.md`

## Support Signal Limit

One support signal is allowed only when it unblocks the decision.

Examples:

- SERP pressure plus aggregator pressure.
- Landing mismatch plus CTA pattern.
- Mobile friction plus trust pattern.

## Stop If

- the support signal confirms what the primary review already showed;
- the operator wants a third document;
- the next issue is a different PPC object;
- the remaining uncertainty needs live evidence.

## Reason

Document gravity is the main overload risk. The system must protect operator attention before it protects completeness.
