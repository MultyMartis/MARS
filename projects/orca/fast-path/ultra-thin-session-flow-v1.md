# Ultra-Thin Session Flow v1

## Use When

Use when time is limited and the operator needs the next PPC decision, not a full review.

## Flow

1. Name the PPC object.
2. Pick the obvious primary lens:
   - query / SERP: `../fast-review/mobile-serp-review-v1.md`;
   - query / landing mismatch: `../fast-review/landing-mismatch-review-v1.md`;
   - search-term waste: `../essential-signals/semantic-contamination-v1.md`;
   - mobile page blocker: `../fast-review/mobile-friction-review-v1.md`.
3. Open no other review unless the decision is blocked.
4. Capture top 3 findings.
5. Decide: keep, change, split, add negative candidate, fix landing, hold / SAFE UNKNOWN.
6. Stop.

## Time Box

Target: 10 minutes.

Hard stop: 20 minutes.

## Forbidden During Session

- browsing ORCA folders;
- opening governance;
- comparing similar reviews;
- filling every report section;
- researching methodology.

## Output

- PPC object:
- Primary lens:
- Top 3 findings:
- Decision:
- SAFE UNKNOWN:
