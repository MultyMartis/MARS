# Decision Path Rules v1

## Decision First

Every step must support one of these human PPC decisions:

- keep current direction;
- change ad promise;
- change or check landing page;
- split query/ad group;
- add negative keyword candidate;
- narrow traffic;
- hold / SAFE UNKNOWN.

## Reject

- observations with no action impact;
- weak signals promoted to findings;
- full audit behavior;
- large reports;
- document comparison;
- speculative performance claims.

## Finding Test

A finding counts only if it has:

- visible or stated evidence;
- PPC implication;
- next human action or SAFE UNKNOWN.

## Maximum Output

Three findings.

One decision.

One stop reason.
