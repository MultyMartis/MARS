# Stop Analysis Enforcement v1

## Rule

If the next note will not change the next PPC decision, stop now.

## STOP NOW Cues

- You already have three findings.
- You already have one decision.
- The next document is being opened "just in case."
- The next question needs live SERP, landing, or platform evidence.
- You are reading ORCA instead of reviewing PPC evidence.
- You are trying to make the note look complete.
- You are adding a second support signal.
- You are about to open governance during the session.

## Allowed Continuation

Continue only when the current decision is blocked and one support signal can unblock it.

## Not Allowed Continuation

- More confidence without new evidence.
- More categories.
- More labels.
- More proof inventory.
- More report fields.

## Exit Line

Write one line:

`STOP: next action is clear enough / SAFE UNKNOWN blocks unsupported certainty.`
