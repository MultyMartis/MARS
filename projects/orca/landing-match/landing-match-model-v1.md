# Landing Match Model v1

## Purpose

Define a simple PPC-focused model for reviewing whether traffic intent matches the landing page.

This is manual review guidance, not a CRO platform, analytics system, or website optimizer.

## Practical Review Areas

- query intent alignment;
- service relevance;
- geo relevance;
- CTA relevance;
- trust relevance;
- pricing relevance;
- urgency relevance;
- mobile usability;
- conversion friction.

## Basic Review Question

If a user clicks this ad after this query, does the landing page quickly confirm:

- this is the service they searched for;
- this business serves the location;
- the next action is clear;
- the trust signals are believable;
- pricing or estimate logic is understandable;
- urgent expectations are handled honestly.

## Review Output

Use simple statuses:

- aligned;
- partially aligned;
- mismatched;
- blocked;
- SAFE_UNKNOWN.

## Operator Rule

Fix obvious PPC mismatch before discussing advanced UX.

Service clarity, CTA access, local relevance, and trust support matter more than decorative page critique.

## Boundary

ORCA does not autonomously optimize websites or claim conversion certainty. Human review is mandatory.
