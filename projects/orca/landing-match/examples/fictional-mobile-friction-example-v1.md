# Fictional Mobile Friction Example v1

## Status

Fictional demonstration only. Non-production. Non-validated.

This is not heatmap analysis, behavioral tracking, or a conversion claim.

## Scenario

- niche: fictional emergency repair service;
- region: fictional city;
- device: mobile;
- review purpose: show obvious mobile PPC friction.

## Observed Friction

- service name appears after a long hero block;
- phone button is below the first screen;
- WhatsApp is visible but not explained;
- reviews are buried below several sections;
- form asks for too many fields before contact.

## PPC Risk

- urgent users may not find the call path quickly;
- trust proof is compressed too low;
- CTA overload may slow action;
- ad urgency may not match page experience.

## SAFE UNKNOWN

- actual mobile conversion rate;
- page speed;
- live response capacity;
- whether users prefer WhatsApp in this niche.

## Boundary

This example is demonstration only. ORCA does not measure behavior or optimize landing performance automatically.
