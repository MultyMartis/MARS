# ORCA Landing Match Layer

## Purpose

This layer supports lightweight, human-supervised review of whether PPC traffic intent matches the landing page experience.

It helps an operator check query intent, service clarity, geo relevance, CTA alignment, trust support, pricing clarity, mobile usability, and obvious conversion friction.

## What This Layer Is

- PPC landing-match discipline.
- Intent-to-landing review.
- CTA alignment review.
- Trust alignment review.
- Conversion-friction review.
- Manual landing evaluation support.

## What This Layer Is Not

- Not an autonomous CRO system.
- Not a UX audit platform.
- Not an AI website optimizer.
- Not runtime analytics.
- Not heatmap or behavioral tracking.
- Not automation infrastructure.

## Required Discipline

- Human review is mandatory.
- Observations remain revisable.
- Evidence quality matters.
- Landing effectiveness is contextual.
- Mobile behavior matters.
- Local-service behavior matters.
- Operational realism matters.
- Do not turn a landing review into giant UX theory.
