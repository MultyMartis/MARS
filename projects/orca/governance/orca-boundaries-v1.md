# ORCA Boundaries v1

## Allowed

- Human-supervised PPC review.
- SERP, mobile, CTA, landing, search-term, and semantic checks.
- Practical operator reports.
- Evidence-aware recommendations for human review.
- Lightweight documentation that improves live sessions.

## Not Allowed

- runtime claims;
- autonomous PPC optimization;
- bid or budget automation;
- campaign launch automation;
- scheduler, queue, daemon, or validator concepts;
- orchestration language unless describing what ORCA is not.

## Required Wording

ORCA is a PPC operational toolkit and live review framework.

It may assist a human operator. It does not execute advertising actions.

## Boundary Test

If a document sounds like software operating campaigns without a human, rewrite it or remove the claim.
