# ORCA Anti-Bloat Rules v1

## Keep Small

- One document must support one operator action.
- Prefer checklist over taxonomy.
- Prefer live evidence over theory.
- Prefer one clear decision over many observations.
- Remove repeated boundary prose when a link is enough.

## Avoid

- platform architecture;
- abstract intelligence layers;
- fake scoring systems;
- lifecycle engines;
- enterprise process language;
- exhaustive audits during live review.

## Add A Document Only If

- it reduces operator time;
- it prevents a recurring PPC mistake;
- it improves evidence quality;
- it clarifies a boundary that was drifting.

## Stop Rule

If a document cannot be used during or immediately after a live PPC session, it belongs outside the starter core.
