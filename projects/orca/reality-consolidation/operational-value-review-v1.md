# Operational Value Review v1

## Status

Manual operational value review. Not scoring automation, governance expansion, telemetry, or architecture.

## Classification Criteria

Layers are classified by:

- practical PPC usefulness;
- operator speed impact;
- evidence usefulness;
- real-world applicability;
- maintenance burden;
- complexity cost.

## HIGH VALUE

These layers are closest to practical PPC work and should remain lean.

- `workflows` — useful for operator navigation if kept short.
- `contracts` — useful for scope and boundary discipline.
- `research` — useful for SERP and market review input.
- `semantic` — core to intent cleanliness.
- `search-terms-review` — directly protects spend quality.
- `landing-match` — directly protects ad-to-page alignment.
- `offer-evaluation` — commercially realistic offer review.
- `ad-copy` — practical output layer for messaging.
- `ad-extensions` — practical output layer for extensions.
- `campaign-qa-assembly` — final applied QA spine.
- `qa` — quality discipline if not duplicated.
- `evidence` — reality discipline and anti-fake-certainty anchor.
- `fast-review` — speed and operator fatigue reduction.
- `minimalism` — anti-bloat operator discipline.
- `compression` — necessary maintenance layer if kept compact.

## MEDIUM VALUE

Useful, but overlap-heavy or likely to need compression.

- `direct-commander` — useful entrypoint, but should not become another method system.
- `operator-decisions` — useful for uncertainty and escalation, overlaps with evidence/confidence.
- `confidence` — useful, but overlaps with evidence and contradictions.
- `contradictions` — useful, but overlaps with confidence and operator decisions.
- `observations` — useful if connected to real review; overlaps with evidence and live observations.
- `review` — useful only if it routes to practical workflows.
- `essential-signals` — useful as compression aid, overlaps with fast-review/minimalism.
- `failure-patterns` — useful reference, but can become diagnosis mythology.
- `patterns` — useful if pilot-proven; otherwise abstract.

## LOW VALUE

Current value is weak unless compressed or tied to real operator use.

- `methodology` — high abstraction risk and high duplication risk.
- `intelligence` — naming and framing risk fake sophistication unless tightly constrained.
- `evolution` — weak immediate PPC operator value without repeated pilot evidence.
- broad duplicated templates across meta-review layers — maintenance cost may exceed use.

## EXPERIMENTAL

Potentially valuable, but value depends on actual human-run use.

- `pilot-cases` — useful for demonstrations if clearly fictional or manual.
- `live-observations` — high value if real observations are used; low value if stale.
- `live-pilots` — high value if pilots produce pruning decisions.
- `heuristics` — useful only if operators actually reuse them.
- `heuristic-mapping` — useful only if it reduces review effort.
- `agents` — useful only if agent roles map to real operator entrypoints.

## Main Value Finding

ORCA's highest value is not in more methodology. It is in a short path from research to semantic cleanliness, landing/offer alignment, ad construction, QA, and evidence-aware decision-making.

## Maintenance Burden Finding

The largest maintenance burden is duplicated boundary language and repeated review logic across evidence, confidence, contradictions, operator decisions, signals, failures, minimalism, and compression.

## Boundary

This review does not delete or demote files. It identifies operational value for later human cleanup.
