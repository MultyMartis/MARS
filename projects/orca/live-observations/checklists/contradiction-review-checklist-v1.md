# Contradiction Review Checklist v1

## Identify Conflict

- [ ] Conflicting observations linked.
- [ ] Conflict type recorded.
- [ ] Region differences checked.
- [ ] Device differences checked.
- [ ] Timestamp differences checked.
- [ ] Query differences checked.
- [ ] Landing versus SERP claim mismatch checked.
- [ ] Local pack variation checked.

## Explain Limits

- [ ] Possible explanation recorded.
- [ ] SERP volatility considered.
- [ ] Screenshot aging considered.
- [ ] Regional variation considered.
- [ ] Seasonal variation considered.
- [ ] Personalization risk considered.
- [ ] SAFE UNKNOWN used when cause is unclear.

## Preserve Evidence

- [ ] Older evidence kept.
- [ ] Newer evidence linked.
- [ ] Contradiction not hidden.
- [ ] Findings not averaged into a cleaner conclusion.
- [ ] Confidence impact recorded.

## Status

- [ ] Open.
- [ ] Bounded.
- [ ] Unstable.
- [ ] Superseded.
- [ ] Resolved by human review.
- [ ] SAFE UNKNOWN.
