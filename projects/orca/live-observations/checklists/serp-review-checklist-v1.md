# SERP Review Checklist v1

## Before Review

- [ ] Reviewer recorded.
- [ ] Timestamp and timezone recorded.
- [ ] Region recorded.
- [ ] Device recorded.
- [ ] Search engine recorded.
- [ ] Exact query recorded.
- [ ] Personalization and localization notes recorded.
- [ ] Screenshot reference prepared.

## SERP Evidence

- [ ] Top ad block observed.
- [ ] Bottom ad block observed when visible.
- [ ] Local pack presence recorded.
- [ ] Organic overlap recorded.
- [ ] Aggregator or directory presence recorded.
- [ ] CTA patterns recorded.
- [ ] Trust patterns recorded.
- [ ] Pricing visibility recorded.
- [ ] Urgency signals recorded.
- [ ] Mobile/desktop differences recorded when reviewed.

## Interpretation

- [ ] Visible evidence separated from inference.
- [ ] SERP volatility noted.
- [ ] Regional variation considered.
- [ ] Screenshot aging risk noted.
- [ ] SAFE UNKNOWN used where evidence is missing.
- [ ] No claim of autonomous observation, scraping, telemetry, or automatic analysis.

## Closeout

- [ ] Contradictions checked.
- [ ] Confidence impact reviewed.
- [ ] Next review trigger recorded.
