# Landing Review Checklist v1

## Before Review

- [ ] Reviewer recorded.
- [ ] Timestamp and timezone recorded.
- [ ] Source query recorded.
- [ ] Region and device recorded.
- [ ] Landing URL recorded.
- [ ] Access path from SERP recorded.
- [ ] Screenshot reference recorded.

## Landing Evidence

- [ ] Primary CTA reviewed.
- [ ] Phone visibility reviewed.
- [ ] WhatsApp or messenger visibility reviewed.
- [ ] Pricing visibility reviewed.
- [ ] Urgency handling reviewed.
- [ ] Trust architecture reviewed.
- [ ] Local trust signals reviewed.
- [ ] Response promises recorded.
- [ ] Differentiation recorded.
- [ ] Mobile friction recorded.
- [ ] Conversion friction recorded.

## Validation

- [ ] SERP claim compared with landing claim.
- [ ] Visible evidence separated from interpretation.
- [ ] Conversion performance not inferred.
- [ ] Operational claims not treated as verified facts.
- [ ] Stale page risk noted.
- [ ] SAFE UNKNOWN used where needed.

## Closeout

- [ ] Contradictions checked.
- [ ] Confidence impact reviewed.
- [ ] Next review trigger recorded.
