# Evidence Validation Checklist v1

## Required Fields

- [ ] Observation ID present.
- [ ] Reviewer present.
- [ ] Timestamp and timezone present.
- [ ] Evidence source present.
- [ ] Region present.
- [ ] Device present.
- [ ] Query or landing URL present.
- [ ] Screenshot reference present for visual claims.
- [ ] Contradiction notes present.
- [ ] SAFE UNKNOWN notes present.
- [ ] Confidence review present.
- [ ] Volatility review present.

## Evidence Quality

- [ ] Source is traceable.
- [ ] Observation is time-bound.
- [ ] Regional boundary is clear.
- [ ] Device boundary is clear.
- [ ] Screenshot aging risk is noted.
- [ ] SERP volatility is considered.
- [ ] Findings are human-reviewed.

## Rejection Flags

- [ ] No autonomous scraping source implied.
- [ ] No browser automation source implied.
- [ ] No telemetry source implied.
- [ ] No unsupported stable-market claim.
- [ ] No confidence increase from synthetic-only synthesis.
- [ ] No production intelligence claim without validation.

## Outcome

- [ ] Accepted.
- [ ] Accepted with limits.
- [ ] Needs more evidence.
- [ ] Contradicted.
- [ ] Stale.
- [ ] Rejected.
