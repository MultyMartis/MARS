# ORCA Direct Commander Preparation

## Purpose

This layer supports lightweight, human-supervised preparation of PPC campaign structures for possible Yandex Direct Commander import workflows.

It helps an operator organize campaigns, ad groups, keywords, geo logic, negative keywords, mobile/call priorities, and import readiness before any human-controlled platform work.

## What This Layer Is

- Campaign preparation discipline.
- Practical PPC structure guidance.
- Manual Direct Commander preparation support.
- Operator review checklist and templates.
- Lightweight import readiness thinking.

## What This Layer Is Not

- Not upload tooling.
- Not Direct API integration.
- Not runtime export generation.
- Not autonomous campaign creation.
- Not bid management.
- Not automatic optimization.
- Not a production campaign engine.

## Required Discipline

- Human review is mandatory.
- Campaign structures remain revisable.
- Semantic cleanliness matters more than scale.
- Operational simplicity matters.
- Over-segmentation is a real risk.
- ORCA does not upload, launch, manage, or optimize campaigns.
