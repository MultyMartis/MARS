# Keyword Cleanliness Rules v1

## Purpose

Keep keyword sets commercially clean before any Direct Commander import preparation.

Semantic cleanliness matters more than scale.

## Review For

- dangerous ambiguity;
- informational leakage;
- broad-intent risks;
- irrelevant equipment overlap;
- irrelevant service overlap;
- duplicate semantic intent;
- low-commercial-intent risks;
- geo mismatch;
- B2B / B2C mismatch;
- urgent vs planned-service mismatch.

## Dangerous Ambiguity

Mark a keyword as risky when it may attract a meaning the campaign cannot serve well.

Examples:

- equipment purchase instead of rental;
- job search instead of service request;
- DIY information instead of commercial demand;
- transport request instead of manipulator service;
- broad "price" research without service intent.

## Duplicate Intent

Duplicate intent is not just identical wording. It appears when several keywords compete for the same user meaning without a useful control difference.

Clean by:

- merging similar meanings;
- moving variants into one clear ad group;
- excluding weak variants;
- separating only when geo, landing, CTA, or urgency changes.

## Keyword Status

Use simple statuses:

- keep;
- review;
- split;
- exclude;
- SAFE_UNKNOWN.

## Boundary

ORCA does not generate production keyword uploads autonomously. A human must review all keyword and negative keyword decisions before platform use.
