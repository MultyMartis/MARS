# Landing Mismatch Review v1

## Use When

Use when a query, ad, or SERP promise may not match the landing page.

## Review Flow

1. Write the user intent in one sentence.
2. Compare query intent, ad promise, and first mobile screen.
3. Check whether the page answers the intent without hunting.
4. Record the mismatch as a practical PPC risk.

## Check

- Service named clearly?
- Geo or service area visible?
- CTA matches the intent stage?
- Price, terms, or proof visible when competitors make them visible?
- Page talks about the same product/service as the query?
- Mobile first screen gives a reason to continue?

## Mismatch Types

- query wants urgent action, page opens with generic branding;
- ad promises price, page hides price;
- query is local, page has weak location proof;
- search term is specific, page is broad;
- CTA asks for too much commitment too early.

## Decision Cues

- Change landing target.
- Adjust ad promise.
- Split semantic group.
- Add negative keywords.
- Ask for missing page evidence before spending more review time.

## Stop Rule

Stop once the mismatch can be stated in one sentence and tied to one human decision.
