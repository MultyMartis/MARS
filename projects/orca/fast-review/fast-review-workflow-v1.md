# Fast Review Workflow v1

## Status

Manual workflow. Not automation, orchestration, telemetry, or exhaustive research.

## Goal

Produce a short PPC review that identifies the few observations most likely to change operator action.

## Workflow

1. Set the review window before starting.
2. Scan SERP pressure first.
3. Capture only dominant CTA, trust, local, aggregator, urgency, semantic, landing, or mobile signals.
4. Ignore cosmetic or weak observations unless they create obvious PPC risk.
5. Stop when the next observation is unlikely to change a decision.

## Output Limit

A useful fast review should normally fit on one short note:

- top signals;
- PPC risk;
- evidence observed;
- operator action;
- SAFE UNKNOWN.

## Compression Rules

- Speed matters because PPC decisions often need direction, not completeness.
- Usefulness matters more than method display.
- Not every observation matters.
- Avoid documenting noise.
- Operator fatigue reduces quality.
- Over-analysis can create false confidence.

## Boundary

This workflow rejects giant audits, endless note-taking, fake completeness, theoretical perfectionism, and methodology addiction.
