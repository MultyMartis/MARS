# ORCA Fast Review Mode v1

## Purpose

Fast Review Mode supports short, human-operated PPC reviews when speed and usefulness matter more than exhaustive documentation.

It helps an operator capture only the highest-value observations across SERP, competitor, semantic, trust, landing, and mobile review.

## What This Layer Is

- Lightweight review discipline.
- Fast PPC observation capture.
- Operator fatigue reduction.
- High-signal filtering for commercial review.
- A stop rule against over-analysis.

## What This Layer Is Not

- Not a giant audit process.
- Not new intelligence architecture.
- Not automation, orchestration, telemetry, or dashboards.
- Not AI optimization.
- Not a claim of complete market understanding.

## Fast Review Priorities

Review only signals that may affect PPC usefulness:

- CTA patterns;
- trust patterns;
- local pack pressure;
- aggregator dominance;
- semantic contamination;
- landing mismatch;
- urgent-intent behavior;
- mobile friction.

## Required Discipline

- Speed matters.
- Usefulness matters.
- Not every observation matters.
- Avoid documenting noise.
- Stop before fatigue lowers judgment quality.
- Diminishing returns are real.
