# Mobile SERP Review v1

## Use When

Use for a fast phone-first check of a commercial query before changing ads, semantics, or landing expectations.

## Review Flow

1. Search the target query on mobile.
2. Note the first visible screen before scrolling.
3. Check paid ads, map/local pack, aggregators, and strong organic competitors.
4. Capture only patterns that affect PPC action.

## Check

- Are ads above organic results?
- Is there map/local pack pressure?
- Do aggregators occupy the first screen?
- Are competitors using price, urgency, warranty, same-day service, or phone-first CTAs?
- Does the SERP imply a different intent than the campaign assumes?

## Decision Cues

- Add or tighten negatives if the SERP is mixed or informational.
- Review ad copy if competitors answer a clearer intent.
- Review landing page if the SERP promises proof, price, locality, or speed that the page lacks.

## Stop Rule

Stop after the top SERP pattern is clear. Do not catalogue every result.
