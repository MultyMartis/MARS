# High-Signal Checklist v1

## Status

Manual checklist for fast review. Not automated scoring.

## Include Only If Visible And Useful

- CTA pattern is repeated or dominant.
- Trust pattern may change click or conversion confidence.
- Local pack pressure changes SERP competition.
- Aggregator dominance may intercept demand.
- Semantic contamination changes query intent.
- Landing mismatch weakens ad-to-page alignment.
- Urgent-intent behavior affects response expectations.
- Mobile friction blocks action.

## Exclude

- cosmetic observations;
- one-off weak details;
- unsupported assumptions;
- notes added only to look complete;
- findings with no likely PPC action.

## Operator Check

- Is this evidence visible?
- Is this commercially relevant?
- Would this change a PPC decision?
- Is the review still short enough to use?

## Boundary

High signal means useful, visible, and decision-relevant. It does not mean sophisticated or exhaustive.
