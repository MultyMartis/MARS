# Tasks

## Eyebrow

Что выполняем по заявкам на арматуру

## H2

Задачи по доставке арматуры и стройматериалов

## Allowed tasks

- Доставка арматуры на строительный объект
- Перевозка пачек арматуры по Краснодару и краю
- Подача строительных материалов на объект
- Разгрузка арматуры стрелой
- Доставка металлопроката
- Перевозка стройматериалов в рамках параметров машины

## Note label

## Note text

Для точного расчета заранее уточняем вес, длину арматуры, объем, адреса, условия подъезда и точку разгрузки.

## Denied title

Что не выполняем

## Denied list

- Грузы с неизвестным весом
- Негабарит без предварительного согласования
- Грузы вне параметров машины
- Опасные грузы
- Эвакуация техники
