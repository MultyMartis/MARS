# Specs — Support Capability Only

Технические параметры используются как support-блок для подтверждения выполнимости задачи, но не как главный смысл страницы.

## Support semantics

- Параметры техники показываются после use-case контекста
- Формулировки привязываются к задачам перевозки/установки бытовок
- Запрещено превращать страницу в capability-only лендинг
