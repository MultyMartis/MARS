# Factory Rules

## Factory cannot

- Превращать route в generic manipulyator page
- Убирать use-case акцент на бытовках/вагончиках
- Перегружать страницу specs-блоками
- Делать capability-first hero
- Копировать zakaz hero pressure

## Factory can

- Полировать layout и spacing
- Улучшать readable flow на mobile
- Снижать визуальный шум без потери смысловых акцентов
