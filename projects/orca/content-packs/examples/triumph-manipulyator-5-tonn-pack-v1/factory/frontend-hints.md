# Frontend Hints

## Layout hints

- Использовать Template B route layout для hero.
- Specs блок держать максимально рано и читаемо.
- Cargo cards ограничить 4-6 элементами.

## CTA hints

- Не дублировать слишком много красных CTA.
- Держать баланс form/call.

## Safety hints

- Не добавлять ценники в hero.
- Не добавлять срочность без подтвержденных SLA.
