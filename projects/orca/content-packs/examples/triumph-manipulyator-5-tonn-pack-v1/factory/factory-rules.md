# Factory Rules

## Factory can

- Адаптировать spacing
- Чинить responsive
- Полировать layout
- Снижать визуальную плотность без потери смысла

## Factory cannot

- Менять H1 intent
- Менять specs
- Удалять qualification line
- Добавлять fake fleet/fake price
- Ломать CTA hierarchy
- Переписывать смысл FAQ
- Менять denied tasks без ORCA
