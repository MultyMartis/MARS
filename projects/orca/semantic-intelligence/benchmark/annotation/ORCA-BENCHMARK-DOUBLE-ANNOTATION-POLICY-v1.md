## Purpose

Mandate **independent double annotation** for high-risk benchmark cohorts per P0-C process model.

---

## 100% double annotation (mandatory)

| Cohort | Scope |
|--------|-------|
| B0 qualification | Entire phase |
| Corvonero pilot | Entire 300–500 set |
| Blind test pack | Entire sealed pack |
| Protected strata | All records in protected intent strata |
| Hard-negative pack | Entire fixed pack |
| Adversarial difficulty | All `DIFF_ADVERSARIAL` |
