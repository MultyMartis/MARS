# Geo Evidence Policy V2

Machine-readable: `geo-evidence-policy-v2.json`

## Mandatory rule

Geography strengthens existing commercial evidence but never creates it alone.

## Strong commercial geo evidence

- Explicit provider noun + geography
- Explicit service task + geography with order/price
- Price/order modifier + service + geography
- Urgent paid problem + geography
- Product + explicit service task + geography

## Supporting evidence only

- Service noun + geography without additional signals
- Recognized commercial task + geography

## Insufficient

- Product + geography without service task
- Career + geography
- Education + geography
- Informational + geography
- Navigation + geography
- Ambiguous noun + geography

## Commercial intent vs scope fit

| Dimension | Question |
|-----------|----------|
| Commercial eligibility | Is user seeking paid service? |
| Scope fit | Does this project offer the service? |
| Ownership | Service owner or SERVICE_GAP |

Forbidden: using registry absence as proof of noncommercial intent.
