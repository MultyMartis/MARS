# ORCA Starter Core

## Purpose

Starter Core is the small live-first set of ORCA reviews for fast PPC work.

It favors speed, evidence, and low operator load over complete analysis.

## Choose One Path

- SERP unclear or mobile-heavy: `../fast-review/mobile-serp-review-v1.md`.
- Traffic intent feels wrong: `../fast-review/landing-mismatch-review-v1.md`.
- Ads or competitors push harder: `../fast-review/cta-pattern-review-v1.md`.
- Page is hard to use on phone: `../fast-review/mobile-friction-review-v1.md`.
- Need market cues: `../essential-signals/trust-patterns-v1.md`.
- Aggregators dominate: `../essential-signals/aggregator-pressure-v1.md`.
- Queries look polluted: `../essential-signals/semantic-contamination-v1.md`.

## Operating Rule

One live session should normally use one primary review and at most two signal checks.

If more is needed, split the work into another session.

## Not Included

- scheduling;
- queues;
- scoring engines;
- autonomous validators;
- campaign launch automation;
- bid or budget recommendations.
