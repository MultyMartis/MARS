# ORCA Live Pilot

## Purpose

Live Pilot is the operator entry point for short PPC review sessions.

Use it when a human is actively checking SERP, ads, search terms, landing pages, or mobile friction and needs useful next actions fast.

## Session Shape

1. Define the PPC object: query, campaign, ad group, landing page, or search-term set.
2. Pick one review path from `../starter-core/README.md`.
3. Review on mobile first when SERP or landing behavior matters.
4. Record only signals with visible evidence.
5. Convert observations into human decisions, not automated actions.
6. Stop before fatigue turns the review into noise collection.

## Output

Use `../reports/orca-live-session-report-template-v1.md`.

Minimum output:

- object reviewed;
- evidence seen;
- top 3 issues;
- decision or next manual check;
- SAFE UNKNOWN.

## Stop Rules

- No clear PPC decision is emerging.
- Evidence is too weak.
- The operator is repeating the same observation.
- The review is expanding into unrelated strategy.
- A platform action would require fresh human confirmation.
