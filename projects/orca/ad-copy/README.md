# ORCA Ad Copy Layer

## Purpose

This layer supports lightweight, human-supervised preparation of Yandex Direct search ad copy.

It helps an operator draft commercially clear, evidence-aware, local-service search ads that can later be reviewed by a human before any platform work.

## What This Layer Is

- PPC ad-structure guidance.
- Search-ad preparation discipline.
- CTA and trust message support.
- Evidence-aware copy drafting support.
- Manual ad assembly guidance.

## What This Layer Is Not

- Not autonomous copy generation.
- Not an AI copywriting engine.
- Not bulk ad generation.
- Not campaign launch tooling.
- Not Direct API integration.
- Not ad optimization automation.
- Not runtime orchestration.

## Required Discipline

- Human review is mandatory.
- Ads remain revisable.
- Unsupported claims are forbidden.
- Moderation risks exist.
- Evidence quality matters.
- Trust matters more than hype.
- Clarity matters more than creativity.
- Operational realism matters.
