# Mobile Search Copy Rules v1

## Purpose

Support mobile-readable search ads for local-service PPC.

Mobile copy should reduce cognitive load and make the next action obvious.

## Priorities

- short readability;
- CTA visibility;
- quick scanning;
- phone-first interaction;
- WhatsApp compatibility;
- clear service meaning;
- clear geo relevance;
- reduced cognitive load.

## Mobile Copy Checks

- can the service be understood quickly?
- is the CTA obvious?
- is phone or messenger behavior supported?
- is urgency clear without hype?
- does the landing make the same action easy?
- is trust visible early enough?

## Phone-First Interaction

Use phone-first copy when:

- calls are operationally supported;
- urgent intent is likely;
- price depends on details;
- the user may not want to fill a form;
- mobile SERP behavior supports call-first patterns.

## WhatsApp Compatibility

Use WhatsApp-oriented messaging when:

- messenger response is real;
- photos, location, or details help estimate;
- the landing supports WhatsApp action;
- the service context fits chat.

## Avoid

- long abstract copy;
- multiple competing CTAs;
- unsupported speed claims;
- trust claims that are not mobile-visible;
- desktop-style detail that slows scanning.

## Boundary

ORCA does not control device settings, upload ads, or optimize mobile performance. Human review is mandatory.
