# Repeatability Model v1

## Purpose

Defines how ORCA uses repeated observations to increase reliability. Repeatability strengthens evidence only when observations are comparable and traceable.

ORCA observes reality. ORCA does not define reality. Repeated evidence increases reliability; repeated weak assumptions do not.

## Repeatability Classes

- `isolated` - one observation only.
- `same_query_repeated` - same query repeated over time or snapshot.
- `cross_query` - related queries show the same pattern.
- `cross_case` - comparable cases show the same pattern.
- `cross_region` - multiple regions show the same pattern with documented boundaries.
- `cross_source` - SERP, landing, competitor, local, or client evidence supports the same pattern.
- `historical` - pattern repeats across meaningful time intervals.

## Comparability Requirements

- defined region;
- defined niche;
- known device context when relevant;
- current or comparable timestamps;
- similar query intent;
- traceable sources;
- documented SERP conditions;
- human-reviewed interpretation.

## Rules

- Repeated observations matter more than isolated findings.
- Repetition must not be counted when source context is missing.
- Repetition across unstable SERPs requires volatility notes.
- Cross-region repetition increases confidence only when regional differences are evaluated.
- Cross-case repetition requires comparable niche and commercial intent.
- Contradictions must reduce repeatability value.
- Evidence aging can reduce repeatability value.

## Boundary

This model supports evidence-backed research reliability. It is not automated pattern mining, telemetry, scraping, or autonomous learning.
