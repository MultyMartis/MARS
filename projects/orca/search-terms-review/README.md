# ORCA Search Terms Review Layer

## Purpose

This layer supports lightweight, human-supervised review of real or prepared PPC search terms.

It helps an operator detect commercial intent quality, informational leakage, semantic contamination, ambiguity, negative keyword candidates, and broad-match pollution.

## What This Layer Is

- Search-term review support.
- Commercial intent review discipline.
- Negative keyword discovery support.
- PPC cleanliness review.
- Manual semantic risk review.

## What This Layer Is Not

- Not autonomous campaign optimization.
- Not automatic negative keyword generation.
- Not a PPC intelligence engine.
- Not scraping, telemetry, dashboards, or runtime orchestration.

## Required Discipline

- Human review is mandatory.
- Search-term conclusions are contextual.
- Evidence quality matters.
- Semantic cleanliness matters.
- Over-filtering risk exists.
- False-negative risks exist.
- ORCA does not optimize campaigns autonomously.
