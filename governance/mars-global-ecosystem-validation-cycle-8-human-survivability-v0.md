## Cognitive-collapse risk patterns (hidden)

1. **Breadth-first onboarding** — topology + reality + governance README + root layout table in one session (documented anti-pattern; still likely under curiosity pressure).

2. **Factory meta-governance loop** — Core → Extended → triad siblings → taxonomy appendix → back to Forge checklist for “one more domain.”

3. **Forge triple-pack** — Gulp + Forge + Factory contracts without foundation-map anchor in chat pin.

4. **Governance + ORCA parallel chats** — Lane A/B mix without [parallel-cursor-chat-work-mode-v0.md](parallel-cursor-chat-work-mode-v0.md); PPC docs opened in Factory session.

5. **Runtime folder shock** — `mars-runtime/` directory listing before README boundaries (Path D discipline).

6. **Chat-as-SoT** — decisions in thread only; continuity master-index empty; lifecycle not updated.

7. **Validation vocabulary overload** — Factory validation-runtime language vs governance validation-chain semantics without REPORT class label.
