## 2. Zone analysis (minimum five areas)

### 2.1 Website Factory

| Signal | Collapse risk | Pack likely to overload next |
|--------|---------------|------------------------------|
| Extended governance groups (semantics, meta-governance, production) | Operators treat Extended as mandatory syllabus | **Meta-governance triads** (evolution, compression, minimalism stack) |
| Governance + taxonomy + model triads (~59 / ~34 patterns) | Fourth sibling doc without INDEX discipline | **New concern** → triad before index row |
| Pack README index (~200 lines) | Opened before OPERATIONAL-INDEX | **New v0 contracts** added to Pack index without Core Run row |

**Mitigations (lightweight):**

- Default: **one Core Run row** only; Extended = contract citation required.  
- New concern: **index row first**, governance file second — not reverse.  
- Periodic pass: dedupe Extended domain rows; merge taxonomy appendix links ([documentation-entropy-rules.md](documentation-entropy-rules.md)).
