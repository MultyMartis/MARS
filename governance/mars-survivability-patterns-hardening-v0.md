## 2. Operating rules (reinforcement, not new policy)

1. **Pick one Tier 1 router** per session (topology **or** reality **or** onboarding row **or** one governance README row).  
2. **Pack session SoT** = OPERATIONAL-INDEX **Core Run** (Factory, ORCA) — pack README = identity + search, not default scroll.  
3. **Forge silent → Gulp foundation wins** — never treat Forge README checklist catalog as daily default ([agents/mars-forge/AGENT.md](../agents/mars-forge/AGENT.md) first).  
4. **Stabilization reviews are input** — Phase 1–7 artefacts do not override Tier 0–2 without human promotion.  
5. **STOP after minimum reads** — Path A: four files + stop; ORCA: FAST PATH STOP; Factory: one Core Run row.  
6. **Registries over README prose** for identity — [registry-source-of-truth.md](registry-source-of-truth.md).  
7. **governance/ over web-gpt-sources/** on conflict until reconciled — legacy is historical input.
