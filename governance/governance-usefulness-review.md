# MARS — Governance usefulness review

**Status:** **documented** — **human** evaluation guide. **Not** a compliance program, **not** automated policy scoring.

**Purpose:** Define how **governance usefulness** should be judged so maintenance effort tracks **operational value**, not document count.

---

## 1. Posture

- **Governance exists to support operations** — clarify boundaries, reduce catastrophic ambiguity, preserve honesty about scope.
- **Governance can become noise** — when volume, duplication, or stale maps exceed reader capacity.
- **Governance can overgrow** — new layers added without retiring or merging old ones.
- **Governance must justify maintenance cost** — if nobody updates or reads it, it drifts toward mythology.

**Governance may be wrong** — audits should welcome corrections and deprecations.

---

## 2. Review dimensions

Use as a checklist; **not** all dimensions every time.

| Dimension | Questions (examples) |
|-----------|----------------------|
| **Clarity** | Can a newcomer find SoT within **minutes**? Are contradictions flagged? |
| **Operational value** | Did this doc change a real decision, prevent a mistake, or speed safe onboarding? |
| **Maintainability** | Are owners implied? Is update burden proportional to benefit? |
| **Onboarding impact** | Is this mandatory, optional, or historical—and labeled honestly? |
| **Semantic stability** | Do terms match current lanes and evidence (S2/S4 honesty)? |
| **Helper usefulness** | Do adjacent helpers reduce load—or add parallel “truth”? (S5/S6) |
| **Drift reduction** | Does this file **narrow** ambiguity—or add parallel vocabulary? |
| **Cognitive load** | Reading time vs payoff; can sections merge or link out? |

---

## 3. Outcomes (non-exhaustive)

- **Keep & stabilize** — index, trim duplication, clarify SoT.
- **Merge** — fold into fewer sources ([deprecation-and-pruning-semantics.md](deprecation-and-pruning-semantics.md)).
- **Deprecate / historical** — supersede with pointers; stop expanding.
- **Experiment isolate** — move narrative out of governance core (S7).
