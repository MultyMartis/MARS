## Operationalization levels (governance S6)

When describing helpers or bridges, use proportional labels:

| Level | Meaning |
|-------|---------|
| Documentation-only | Prose/tables only |
| Governance-described | Boundaries in governance/project doc |
| Locally executable | Operator runs script on demand |
| Operator-verified | Human recorded outcome (REPORT/log) |
| Experimentally interoperable | Bounded bridge test |
| Operationally repeatable | Human reruns documented steps |
| External-system-dependent | Needs external service/credentials |
| Runtime-scoped experimental | Demo under `mars-runtime/` — not SoT upgrade |

**Default unknown** → documentation-only or governance-described until evidence exists.
