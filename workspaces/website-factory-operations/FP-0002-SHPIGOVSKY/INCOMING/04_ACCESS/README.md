# 04_ACCESS — Access Intake

**Purpose:** Document access paths and credential **references** for project execution.

---

## Accepts

- Access request records
- Credential location pointers *(secure vault / password manager refs — not values)*
- Admin URL documentation
- FTP/SFTP/SSH access notes *(hostnames and paths — not passwords)*
- WordPress admin access procedure notes

---

## Security rule

**Never commit secrets** (passwords, API keys, private keys) to this repository.

Use external secure storage and record **where** credentials live, not the credentials themselves.
