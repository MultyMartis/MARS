Настоящая Политика Cookie-файлов (далее — Политика) описывает, какие cookie и близкие по назначению технологии используются на сайте shpigovsky.ru, принадлежащем Шпиговскому Сергею Юрьевичу (далее — Оператор), и как Пользователь может управлять соответствующими настройками.

Политика дополняет Политику конфиденциальности и применяется совместно с Согласием на обработку персональных данных. Согласие на обработку персональных данных для отправки формы и выбор аналитических cookie являются разными действиями Пользователя.

1. Что такое cookie

Cookie — это небольшие файлы, которые сайт сохраняет в браузере для поддержки базовых функций, запоминания выбора Пользователя и, при отдельном разрешении, для работы аналитических сервисов.

2. Какие технологии используются на сайте

2.1. Необходимые технологии

  • технические cookie и иные данные браузера, необходимые для работы сайта;
  • cookie fp02_cookie_consent, который запоминает выбор Пользователя по настройкам privacy/cookie;
  • технические поля защиты и маршрутизации заявок в формах сайта.

Cookie fp02_cookie_consent является first-party cookie сайта. Он используется для сохранения machine-readable записи о выборе Пользователя и, по текущей технической реализации, содержит:

  • версию записи согласия;
  • признак необходимых технологий;
  • признак разрешения или запрета аналитики;
  • дату и время принятия решения.

Этот cookie не предназначен для хранения имени, телефона, email или текста обращения.

2.2. Аналитика

На сайте используется Яндекс Метрика для аналитики посещаемости и использования сайта.

  • Если Пользователь не сделал выбор или выбрал вариант «Только необходимые», Яндекс Метрика не должна загружаться.
  • Если Пользователь разрешил аналитику, сайт может загружать Яндекс Метрику и использовать её для статистики посещений.
  • Согласие на аналитику также управляет попыткой отправки целей Метрики после успешной отправки формы.

2.3. Session Storage для UTM-меток

Сайт может сохранять в sessionStorage браузера запись fp02_utm с техническими UTM-значениями текущей сессии: utm_source, utm_medium, utm_campaign, utm_content, utm_term.

По текущей технической реализации эта запись используется для атрибуции источника обращения внутри сессии браузера и не предназначена для хранения имени, телефона, email или текста сообщения.

2.4. Карты и внешние сервисы

На странице контактов интерактивная карта не загружается автоматически как фоновый сторонний embed. Вместо этого Пользователь может по собственному запросу открыть внешнюю карту по ссылке.

3. Как Пользователь управляет выбором

При первом обращении к сайту Пользователь может:

  • разрешить аналитику;
  • оставить только необходимые технологии;
  • открыть настройки и выбрать состояние аналитики отдельно.

После первого решения настройки можно открыть повторно через ссылку «Настройки cookie» в интерфейсе сайта. Через этот же механизм Пользователь может:

  • включить аналитику позже;
  • отозвать ранее данное разрешение на аналитику.

4. Отзыв согласия на аналитику

Если Пользователь отключает аналитику через «Настройки cookie», сайт сохраняет обновлённый выбор и блокирует будущую загрузку Яндекс Метрики и будущие цели Метрики для форм. Это не заменяет порядок обращения к внешнему провайдеру по вопросам уже обработанных им данных.

5. Связь с формами сайта

Отправка формы на сайте требует отдельного подтверждения согласия на обработку персональных данных в форме. Это согласие не включает автоматического разрешения аналитических cookie.

Пользователь может отказаться от аналитики и при этом продолжать пользоваться сайтом и отправлять формы, если он отдельно подтвердил согласие на обработку персональных данных, необходимое для обработки обращения.

6. Как отключить cookie в браузере

Пользователь также может удалить или ограничить cookie через настройки своего браузера. При этом отдельные функции сайта могут работать ограниченно.

7. Изменение Политики

Оператор вправе обновлять настоящую Политику. Актуальная версия публикуется по адресу /cookie-files-policy/.

8. Контакты

По вопросам, связанным с персональными данными, privacy-настройками и использованием cookie, можно обратиться по адресу: Info@shpigovsky.ru.
