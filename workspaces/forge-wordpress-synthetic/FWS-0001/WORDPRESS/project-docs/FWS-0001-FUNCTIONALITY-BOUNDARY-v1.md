# FWS-0001 — Functionality Boundary v1

| Concern | Owner |
|---------|-------|
| CPT registration | Plugin `fws-synthetic-core` |
| Post meta / ACF fallback | Plugin |
| Template markup | Theme |
| Asset enqueue | Theme |
| Global options UI | Theme (Settings API) |
| WPilot deploy / ChangeSet | **Out of scope** |

Plugin must not output presentation markup beyond registration hooks.
