# Website Factory — реестр юридических переменных

**Версия:** v1  
**Назначение:** единый список переменных для подстановки в legal-шаблоны при production-сборке.

Использовать **только** перечисленные имена. Другие плейсхолдеры в шаблонах не допускаются.

---

## Переменные

### `{{company_name}}`

| Поле | Значение |
|------|----------|
| **Описание** | Полное наименование оператора персональных данных / администрации сайта (юрлицо или ИП). |
| **Пример** | `ООО «Пример»` |
| **Где используется** | Все четыре шаблона — определение Оператора / Администрации. |
| **Обязательность** | Обязательна при production и сборе ПДн. |

---

### `{{domain}}`

| Поле | Значение |
|------|----------|
| **Описание** | Доменное имя сайта без протокола (или с протоколом — по согласованию оператора; в шаблонах — как hostname). |
| **Пример** | `example.ru` |
| **Где используется** | Все четыре шаблона — привязка к сайту. |
| **Обязательность** | Обязательна при production. |

---

### `{{email}}`

| Поле | Значение |
|------|----------|
| **Описание** | Контактный email для обращений и отзыва согласия. |
| **Пример** | `privacy@example.ru` |
| **Где используется** | Privacy, Consent, Cookie. |
| **Обязательность** | Обязательна при сборе ПДн. |

---

### `{{phone}}`

| Поле | Значение |
|------|----------|
| **Описание** | Контактный телефон оператора (при наличии у клиента). |
| **Пример** | `+7 (000) 000-00-00` |
| **Где используется** | Не в базовых шаблонах v1; допускается расширение страниц оператором. |
| **Обязательность** | По требованию клиента / оператора. |

---

## Канонические пути (не переменные)

Внутренние ссылки в Markdown и HTML форм **фиксированы**:

| Документ | Путь |
|----------|------|
| Политика конфиденциальности | `/privacy-policy/` |
| Согласие на обработку ПДн | `/consent-personal-data/` |
| Пользовательское соглашение | `/user-agreement/` |
| Политика Cookie-файлов | `/cookie-files-policy/` |

---

## Правила подстановки

1. Перед production оператор заполняет все обязательные для проекта переменные.
2. После подстановки в каталоге `legal/` (или в сгенерированных страницах проекта) **не должно остаться** необработанных `{{...}}`, кроме явно отложенных HITL-решений.
3. Клиентские данные из incoming **не копируются** в шаблоны — только переменные.
